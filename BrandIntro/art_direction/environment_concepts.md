## 1. 为什么要重做场景

当前片子的场景是一块无限米灰地面 + 几张漂浮纸片：没有墙面、没有空间边界、没有层次，角色像被放在一个 3D 视口里。上一轮只换了角色，没有解决"世界"的问题。

这一版把场景当成一个独立设计对象，和角色同时重建。判断标准：**把角色拿掉，画面本身要像一张成熟的 3D 品牌广告；把角色放进去，它要自然成为主角。**

## 2. 三个方向

### E1 微缩建筑工作室（主方向）

- **空间**：真实的墙角——背墙 + 侧墙，背墙上开一个高窗洞，洞后是更亮的浅空间，形成第二层纵深。
- **地面**：暖白哑光，带一点反射，不做纯平无限地。
- **结构**：三级台阶式展台（0.10 / 0.16 / 0.08 递减），台面是角色真正的工作面。
- **道具**：卷起的图纸（3 卷，高度错落）、纸模型（两层体块）、一把直尺、两张纸。
- **角色**：站在最高一级台阶的纸面上，身高约为窗洞高度的 1/6——小，但看得清。
- **为什么选它**：有明确的墙、地、台阶，空间边界清楚；台阶天然分层，镜头有纵深；道具都是"创作"语义。
- **风险**：容易变成展厅模型；道具一多就杂乱。

### E2 抽象品牌摄影棚

- **空间**：2.6 m 半径的弧形墙（半开放），地面无缝延伸；没有窗、没有家具。
- **结构**：三层圆形台（半径 1.05 / 0.70 / 0.46），最高一级放角色；左侧一块 0.62 宽的白色碑体，内嵌一条橙色竖槽。
- **道具**：一张纸、一卷纸。仅此两件。
- **角色**：站在圆台中央，身后的橙色竖槽与天线尖同色，形成竖向视觉轴。
- **为什么保留它**：品牌感最强，橙色用得最克制；适合收尾。
- **风险**：容易空得没有叙事；道具少，角色动静全暴露。

### E3 创作者工作台

- **空间**：背墙 + 侧墙，一张 2.0 × 0.8 m 的工作台，石墨色桌腿。
- **结构**：墙上一条工具轨（三件工具），右侧一盏任务灯，灯下形成一束暖光池。
- **道具**：两张纸、一把直尺、一支笔、一个浅托盘。
- **角色**：站在灯池里的纸面上。
- **为什么保留它**：故事最直白——这就是"工作的地方"；灯光池天然把角色框住。
- **风险**：最接近普通桌面动画；台面木质与品牌色板需要克制。

## 3. 五个层次（所有方向共用）

| 层 | 内容 | 作用 |
| --- | --- | --- |
| 背景空间 | 米白墙面、窗洞/弧形墙、侧墙 | 建立纵深与空间边界 |
| 地面 | 暖白哑光，微反射 | 承载角色与道具 |
| 场景结构 | 台阶、展台、碑体、工具轨 | 建立画面层次与视线引导 |
| 创作道具 | 纸、图纸卷、直尺、纸模型 | 支持"发现—计算—创造"的动作 |
| 品牌装置 | 立起的纸板 / 橙色竖槽 / W | 自然完成收尾 |

## 4. 色彩与材质

| 角色 | Hex | 用法 |
| --- | --- | --- |
| 暖瓷白 | `#F3F0E8` | 墙面、纸板 |
| 石灰米 | `#D8D1C5` | 地面、次级台面 |
| 石墨灰 | `#303236` | 桌腿、工具、夹具 |
| 品牌橙 | `#E87532` | 天线尖、涟漪、曲线末端、W 电流 |
| 纸白 | `#FBFAF7` | 纸、角色外壳 |

材质：墙面哑光矿物涂层（roughness ≈0.95）；地面暖白微粗糙（≈0.78）；台面陶瓷（≈0.5）；局部石墨拉丝金属（metalness 0.3）；纸 0.0016 m 厚、有柔和接触阴影。

**不用**：无限平面、灰色视口背景、漂浮 UI 卡片、塑料高光、霓虹。

## 5. 灯光

- 主光：暖白方向光，从左上前方 45°，投影柔和（阴影半径 5，2048 贴图）。
- 补光：半球光 0.75，压住死黑。
- 轮廓光：右后方 1.0，把角色和台面分开。
- E3 额外一盏聚光灯（暖色，光锥 0.55）作为任务灯，形成光池。
- 背景比主体暗 0.5–1 档；接触阴影必须有，否则物件会浮。

## 6. 镜头与空间叙事

| 时间 | 空间任务 | 景别 |
| --- | --- | --- |
| 0–4 s | 建立世界：先给空间，再给角色 | 全景 |
| 4–8 s | 发现与接近：镜头随角色走向工作台 | 全景 → 中景 |
| 8–14 s | 创造：曲线成为空间中的对象，而不只是纸上的线 | 中景 → 近景 |
| 14–17 s | 空间转换：纸板/装置立起，成为品牌承载面 | 中景 → 全景 |
| 17–20 s | 品牌呈现：W 与 WAYNE 在同一空间里 | 全景 |

一次连续长镜头；空间通过相机、道具和结构变化参与叙事，不切场景。

## 7. 九张概念帧说明了什么

| 帧 | 读到的 | 还差的 |
| --- | --- | --- |
| atelier-wide | 墙角、窗洞、三级台阶、纵深成立 | 窗后空间太像一块白板；道具偏少；墙面阴影偏硬 |
| atelier-medium | 角色与台面的尺度关系成立 | 台面缺少材质层次；纸卷像圆柱体 |
| atelier-close | 角色细节可读 | 景深与接触阴影还要调 |
| studio-wide | 弧形墙 + 圆台 + 橙色竖槽，品牌感成立 | 碑体太薄；右侧墙有一道杂线 |
| studio-medium / close | 角色居中，橙色轴成立 | 空；需要至少一件"被创作的对象" |
| bench-wide | 工作台、工具轨、灯池，故事最直白 | 灯罩造型粗糙；桌面木质偏黄 |
| bench-medium / close | 灯池把角色框住，构图好 | 工具细节不足 |

这些帧是**体量与灯光探针**：能用来看空间是否成立，不能用来判断材质完成度。

## 8. 推荐

**主方向 E1（微缩建筑工作室），灯光与构图吸收 E2，道具设计吸收 E3。**

理由：E1 有墙、地、台阶，空间边界最清楚；E2 的弧形墙和橙色竖槽可以用来做收尾的品牌装置；E3 的灯池和工具轨可以作为工作台的局部。

最终收尾建议：**E1 的背墙窗洞立起一块纸板**（或台阶最上层翻转成品牌面），W 落在纸板上——空间自己变成品牌，而不是另外出现一块板。
