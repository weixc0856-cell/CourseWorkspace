# 材质与灯光指南

日期：2026-11-10
状态：参数是**起点值**，不是验证过的结果。Gate 1 的材质与灯光测试负责把它们调准，并把最终值写回本文件。

## 1. 色彩

只用 `shared/design-tokens/tokens.json` 的颜色，**不引入第二套色**：

| 角色 | Hex | 在 3D 里的用法 |
| --- | --- | --- |
| paper | `#FBFAF7` | 纸、卡片、角色主体、背景纸 |
| surface | `#F3F1EA` | 需要比纸略暗的平面（地面、台面） |
| ink | `#252A31` | 印刷线、孔径、结构件、W |
| muted | `#6B7280` | 极少量辅助信息，尽量不用 |
| border | `#E3E0D7` | 分隔与纸边 |
| orange | `#E8733B` | 只做"焦点"：角色边缘、电流、索引线、末端点 |

比例按职责而不是像素：**纸面负责环境，墨色负责结构，橙色负责注意力**。任一时刻只允许一个橙色焦点。

## 2. 材质族

三类，不再增加。数值为 Principled BSDF 的起点。

### 2.1 无涂布纸（主材质）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| Base Color | `#FBFAF7` | — |
| Roughness | 0.82 | 纸不反光，但也不是绝对哑光 |
| Specular IOR Level | 0.35 | 降低高光，避免塑料感 |
| Sheen Weight | 0.06 | 极轻的绒毛感，用于侧光时"发光" |
| Subsurface | 0 | 纸不透光，除非做得很薄 |
| 厚度 | 0.0006 m | 边缘要真的能接住光 |
| 边缘 | 橙色 | 只上在切口的 0.6 mm 边上，不刷正面 |

**判断标准**：近景能看见纤维与毛边；远景只剩"柔和的白"，不该出现高光斑。

### 2.2 哑光陶瓷（备选角色材质）

| 参数 | 值 |
| --- | --- |
| Base Color | `#FBFAF7` |
| Roughness | 0.58 |
| Coat Weight | 0.04 |
| Subsurface Weight | 0.03（暖白，半径 0.02） |
| IOR | 1.45 |

**判断标准**：高光是一大片柔和的渐变，不是一个小亮点。

### 2.3 金属（仅 C2 方向）

| 参数 | 铝 | 阳极氧化黑 |
| --- | --- | --- |
| Base Color | `#C9C6BE` | `#252A31` |
| Metallic | 1.0 | 1.0 |
| Roughness | 0.28 | 0.38 |
| Anisotropic | 0.4 | 0.2 |

**判断标准**：高光是长条，不是圆点；金属上不存在"纯白的过曝区"。

### 2.4 明确不做

玻璃、塑料高光、霓虹、发光贴图、程序化渐变背景、粒子、体积雾里的发光尘埃、扫描线、故障效果。

## 3. 灯光装置

```text
                [rim strip 0.4m]
                       \
   [key softbox 1.2m]    \
        \                 \
         \     (subject)    \
          \                 /
           [fill bounce 0.6m]
                        [paper floor]
```

| 灯 | 位置 | 尺寸 | 作用 |
| --- | --- | --- | --- |
| Key | 方位 45°、高度 35°，距主体 1.5 m | 1.2 × 1.2 m 柔光箱 | 主光；软阴影 |
| Fill | 与 key 相对，方位 −60° | 0.6 m 反光板 | 只补暗部，不制造第二组高光 |
| Rim | 主体后上方 30° | 0.4 × 0.1 m 条形光 | 把角色从纸面里分出来；纸的边缘靠它 |

- **比例**：key : fill ≈ 3:1；rim 只作用在轮廓，不照到正面。
- **背景**：比主体暗 1.5 档，靠光衰减实现，不靠换材质。
- **接触阴影**：必须有。没有阴影的物体在纸面上会"浮"——Gate 1 的灰盒已经验证过这个问题。
- **环境光遮蔽**：保留，强度低；不允许出现"脏"的黑边。

## 4. 摄影与输出

| 项 | 设定 |
| --- | --- |
| 色彩管理 | AgX（Blender 默认）或 ACES；固定一个，全片不改 |
| 曝光 | 固定，不随时间变化；白平衡 5500 K |
| 分辨率 | 1920 × 1080，30 fps |
| 采样 | 以噪点不可见为准；Gate 1 记录每帧耗时 |
| 景深 | 有，但焦点永远在"当前主体"上；背景虚化不等于糊 |
| 运动模糊 | 180° 快门；帧号与时间仍是唯一输入 |
| 色带 | 禁止出现（暗部渐变要留 8 bit 余量） |

## 5. Gate 1 要产出的三张测试帧

1. **材质近景**：角色 + 纸面，距离 0.3 m，看纤维、毛边、接触阴影。
2. **中景**：角色 + 一张纸 + 光柱，距离 1.2 m，看空间与层次。
3. **远景**：整张纸面 + 角色，看 1/8 缩小后的可读性。

每张都要有"通过/不通过"的具体判据，不写"感觉不错"。
