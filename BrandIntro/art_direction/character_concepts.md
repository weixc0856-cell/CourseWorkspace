# 角色概念（三个方向）

日期：2026-11-10
> **2026-11-10 修订**：C3「折」被否决——"纸片人"在中文语境里带有贬义（单薄、扁平、没有实体），不适合做品牌角色。实际采用 **C1 的实体化变体**：Blender 建的哑光陶瓷卵形体 + 内嵌面罩 + 软手臂 + 短腿 + 橙色天线尖（见 `../../CodeVideoStudio/shots/brand-intro/build_character.py`）。C2 保留为"要更冷、更工程"时的备选。

状态：概念稿。**C1 变体已建模并进入成片；C2 未建模。** 三张轮廓草图都还没有画——这份文档定义"要画什么、为什么"，不是设计定稿。

共同约束：只用 `paper / ink / orange` 三色；不出现文字；不做嘴、眉毛、腮红；不在同一条轴线上堆配件；缩到 1/8（240 px 宽画面里约 30 px 高）仍要有可辨轮廓。

## C1 「种」

**一句话**：一滴纸白色的陶瓷，立着，正面开一条缝。

| 项 | 规格 |
| --- | --- |
| 轮廓 | 竖向泪滴，高 0.42 / 宽 0.26 / 厚 0.20；顶部收窄成 0.06 的圆头；底部略平，能站稳；静止时前倾 5° |
| 面部 | 正面一条横向细缝（0.030 × 0.004），缝内一条橙色细丝；**没有眼睛、没有嘴** |
| 手 | 两侧各一个 0.040 长的圆头突起，不能抓握，只能推 |
| 材质 | 哑光陶瓷：base `#FBFAF7`、roughness 0.58、clearcoat 0.04、次表面 0.03（暖白）；缝内橙丝 emissive 0.15 |
| 表情 | 缝宽 0.4–1.2 倍、缝的倾角 ±10°、身体前倾 0–15°——只有这三个变量 |
| 动作 | 倾斜、跳、侧滚、用身体推；不能拿、不能指、不能写 |
| 绑定 | 一体网格 + 2 个变形骨骼（顶部、底部）+ 缝的形变；表情用形态键 |
| 失败条件 | 在 1/8 下只读成"一个蛋"；或任何一帧看起来像在卖萌 |

**它强在哪**：最有生命感，材质最省事，光一打就好看。
**它弱在哪**：没有手，"做事"只能靠推和撞；工程语义最弱；"可爱"和"幼稚"只隔一条缝的宽度。
**它适合回答的问题**：WAYNE 是不是一个有人味的地方？如果是，C1。

## C2 「仪」

**一句话**：一台会自己转的三脚测量仪，镜头是它的眼睛。

| 项 | 规格 |
| --- | --- |
| 轮廓 | 三脚底座（直径 0.30、脚长 0.10）+ 一个环形云台（直径 0.16、厚 0.05）+ 前置镜头（直径 0.07）；总高 0.34 |
| 面部 | 镜头即眼：光圈 0.3–1.0 开合；云台上有一道橙色索引线，指向它正在看的地方 |
| 手 | 无手；云台可外挂一个 0.20 长的细探针或一支笔，作为"手"的替身 |
| 材质 | 拉丝铝（metalness 1、roughness 0.28、各向异性 0.4）、黑色阳极氧化（roughness 0.38）、橙色索引线与刻度 |
| 表情 | 光圈开合、云台俯仰 ±25°、索引线亮度、三脚架的微蹲（压缩 0.98） |
| 动作 | 迈步（三脚交替）、云台转动、用探针触碰、在地面画一条极细的线 |
| 绑定 | 刚体层级：底座 → 云台 → 镜头；三脚用 IK 保持落地 |
| 失败条件 | 被称为"机器人"或"监控摄像头"；或需要靠"拟人化"才能表达情绪 |

**它强在哪**：工程语义最强；"观察—测量—记录"的动作天生可信；金属材质在小屏幕上最清晰。
**它弱在哪**：冷；情绪只能靠节奏和迟疑；容易被归入已有的科幻机器人形象。
**它适合回答的问题**：WAYNE 是不是一台仪器？如果是，C2。

## C3 「折」

**一句话**：三块纸板铰在一起，折着走，展开来做事。

| 项 | 规格 |
| --- | --- |
| 轮廓（折） | 0.18 × 0.12 × 0.16 的楔形，像折纸的基础形；重心低，能立在一条边上 |
| 轮廓（展） | 高 0.55；头板 0.20 × 0.14，后倾 20°；身板 0.26 × 0.20，竖直；臂板 0.22 × 0.06，可摆 |
| 面部 | 头板上印一个 0.018 × 0.003 的墨色"孔径"，随头板前倾而张开——它是一条线的开合，不是眼睛 |
| 材质 | 无涂布纸：base `#FBFAF7`、roughness 0.82、sheen 0.06、厚 0.0006；**只有切口边缘**是橙色 `#E8733B`；身板印 1 px 技术制图线 |
| 表情 | 折角（头板 0–25°）、孔径开合（0.2–1.0）、整体姿态（前倾/后仰 ±12°）、橙色边缘的受光面积 |
| 动作 | 展开、折叠、沿脊线翻滚前进、用臂板拍、用两块板夹起卡片、展开成 W 的第一笔 |
| 绑定 | 3 根骨骼 + 根骨骼；铰链用限制器，不做蒙皮；孔径用贴图遮罩 + 骨骼驱动 |
| 失败条件 | 动作读成"卡片在滑"；或展开后仍然是一个抽象几何体，看不出"头"和"手" |

**它强在哪**：最不像任何现成角色；品牌归属最强（最后可以折成 W）；纸的材质和"工程制图"的气质完全一致。
**它弱在哪**：最难做出"活"的感觉；表情最抽象；对动画节奏的要求最高。
**它适合回答的问题**：WAYNE 是不是一张会动的纸？如果是，C3。

## 对比

权重按品牌资产的优先级给，不是按制作难度：

| 维度 | 权重 | C1 种 | C2 仪 | C3 折 |
| --- | ---: | ---: | ---: | ---: |
| 品牌归属（能不能成为记号） | 25% | 4 | 5 | 5 |
| 反套路（不落入 AI 助手/机器人） | 20% | 4 | 3 | 5 |
| 表情范围 | 20% | 4 | 3 | 3 |
| 动作可信度（能不能"做事"） | 15% | 3 | 5 | 3 |
| 小尺寸可读 | 10% | 4 | 5 | 4 |
| 制作成本（Blender） | 10% | 3 | 4 | 4 |
| **加权** | | **3.75** | **4.10** | **4.10** |

C2 与 C3 同分。**C2 的优势是"动作可信"，C3 的优势是"品牌归属 + 反套路"**。对一个片头角色来说，后者更重要——它一年要出现几十次，辨识度比动作方便更值钱；而且 C3 可以直接变成 W。

## 推荐

**首选 C3「折」。备选 C2「仪」。C1 只在品牌决定要"有人味"时启动。**

理由：

1. C3 是唯一一个**角色和品牌记号是同一个东西**的方案。片头最后不需要"另外出现一个 W"，角色自己折成 W。
2. C3 的材质就是纸，和整套课程视觉（纸面、墨线、编辑排版）同源，不需要第三套材质语言。
3. C3 的风险集中在动画（"滑卡片"），而动画风险可以在 Gate 2 用 3–5 秒低成本证伪；C1 的风险集中在造型（"太可爱"），要反复建模才能判断；C2 的风险集中在概念（"又一个机器人"），无法靠打磨解决。

**如果 Gate 1 或 Gate 2 判定 C3 不成立**，按顺序退：C2（动作更可信）→ C1（更有人味）。不要三个方向的优点混在一起做第四个角色。
