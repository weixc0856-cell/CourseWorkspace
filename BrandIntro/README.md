## 1. 这一轮在解决什么

Gate 1 证明了技术链路（确定性捕获、时间轴、品牌路径复用、单长镜头），但没有证明美术。灰盒里的方块角色、灰色桌面、漂浮卡片到此为止，**不作为下一版的视觉基础**，只作为技术记录保留在 `CodeVideoStudio/shots/brand-desktop/`。

这一轮要回答的是三个美术问题，按顺序：

1. 角色是什么，为什么它有辨识度？
2. 它处在什么世界，这个世界为什么值得看？
3. 它怎么表演，表演为什么让人相信它是活的？

12 秒成片是这三件事都成立之后的结果，不是起点。

## 2. 已确定的边界

- 角色方向：**精致 3D 吉祥物**，不做可爱 AI 小助手。
- 方案 B（纯点/折线指针）**放弃**（2026-11-10，用户判断"太丑"）。
- 不复制任何现有 IP 的角色造型、标志性风格或品牌符号；只研究方法。
- 品牌色板仍然是 `paper / ink / orange`（`shared/design-tokens/tokens.json`），不引入第二套色。
- 品牌画面只出英文。
- 不改 `RemotionStudio/src/brand/`、`shared/design-tokens/brand.json`、`lesson.yaml.branding`。

## 5. Gate 规则

| Gate | 交付 | 通过标准 | 不通过怎么办 |
| --- | --- | --- | --- |
| ENV 场景 | 三套空间方向、每套全景/中景/近景实拍帧、材质与灯光对比 | 角色拿掉画面仍成立；角色放进去不突兀 | 改空间，不进入角色 |
| 0 参考 | 20 个参考（逐帧截图 + 观察点）、3 套风格方向、优缺点与适用性 | 能说清"角色是什么、在什么世界、画面为什么有吸引力" | 换参考，不写代码 |
| 1 角色 | 三视图、4 个表情、材质近远景、3 组灯光、3 个距离 | 静帧就有设计感；缩到 1/8 仍可识别；不靠动画和特效掩盖造型 | 改角色，不进入动画 |
| 2 表演 | 3–5 秒完整动作（发现→反应→预备→执行→收尾） | 有重量、惯性、节奏；不是位移和缩放 | 改绑定和表演，不做片头 |
| 3 片头 | 6–8 秒核心版 → 12 秒母版 | 角色、世界、动作、品牌符号构成一个叙事 | 回退到上一 Gate |
