## 通过标准

1. 能分别用一句话说清：**角色是什么、在什么世界、画面为什么有吸引力**。三句话不能互相替代。
2. 每套方向都有明确的"不做什么"——只写优点的方案不算。
3. 三套方向的轮廓在 240 px 宽的画面里仍可区分。
4. 能指出每套方向最容易失败的那一处，并说明 Gate 1 怎么证伪它。

## 必须做的截帧

每条参考至少截三帧：

- 一个代表镜头（构图与光）
- 一个材质近景（高光、粗糙度）
- 一个角色表演帧（姿势，不是表情）

截图存 `../art_direction/frames/<编号>-<作品>-<描述>.png`，只做内部研究，不入库、不发布。

## 决定

Gate 0 结束时只做一个决定：

> 选 C3「折」/ C2「仪」/ C1「种」中的哪一个，配 E2（主世界）+ E3（收尾）。

推荐 C3（见 `character_concepts.md` §对比），但不预设结论。如果 C3 被否，必须写明否的是哪一条判据。

## 不通过怎么办

换参考、换方向，不写代码、不建模。Gate 0 不通过就进入 Gate 1，是最贵的错误。
