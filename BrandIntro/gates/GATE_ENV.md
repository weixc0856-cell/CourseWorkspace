## 通过标准

1. **空间识别度**：不看角色，也能说出这是一个什么样的空间（工作室 / 摄影棚 / 工作台）。
2. **景别成立**：全景有纵深，中景有主体，近景有材质；三个景别不是同一张图缩放的。
3. **材质可信**：墙面、地面、台面近景能看出差别；没有塑料感、灰盒感。
4. **灯光有层次**：主光方向可辨，暗部不死黑，接触阴影让物件落地。
5. **角色融合**：角色不是"贴"上去的——它和台面有接触阴影，和道具发生关系，尺度可信。
6. **品牌收尾**：W 从空间里长出来（纸板立起 / 装置转动），不是最后叠一张图。

## 失败条件（任一即不通过）

- 背景是一块无限平面或纯色视口。
- 道具是漂浮的 UI 卡片，没有厚度和接触阴影。
- 角色靠后期贴图进入场景，脚下没有阴影。
- 品牌收尾与空间无关（另起一张卡）。
- 材质近景能看出程序纹理的平铺痕迹。

## 与角色 Gate 的关系

场景 Gate 与角色 Gate 分开验收，最后做 Integration Gate。顺序：

```text
Environment Art Gate → Character Art Gate → Integration Gate → Performance Gate → Brand Film Gate
```

先做场景，是为了避免"角色好看但放不进去"或"场景好看但角色格格不入"。
