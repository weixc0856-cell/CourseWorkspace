# GATE 2 — 角色表演验证

状态：未开始（依赖 Gate 1 通过）
目标：3–5 秒里证明这个角色是活的。**不接品牌，不做片头，不做 12 秒。**

## 测试内容（一条完整的动作）

1. **发现**：角色注意到画面外的目标（0.5–1.0 s）
2. **反应**：停顿、靠近或后撤（0.3–0.5 s）
3. **预备**：重心转移、蓄力（0.2–0.4 s）
4. **执行**：移动、触碰、展开或折起（0.5–1.5 s）
5. **收尾**：回弹、稳定、保持（0.3–0.8 s）

总长 3–5 秒，一个动作，不剪镜头。

## 交付物

- 3 条短片（不同动作：走/折、触碰、完成一个任务），30 fps，1920×1080
- 每条的关键帧接触表（每 0.2 s 一格）
- 一页表演笔记：每个阶段的帧数、重心在哪、惯性如何体现

## 通过标准

1. **有重量**：加速和减速不是线性的；着地有压缩；身体各段有滞后。
2. **有预备**：动作开始前有反向的小动作。
3. **有惯性**：停下之后还有余动，不是瞬间静止。
4. **有性格**：同一动作，换一个角色演不出来——说明表演属于这个角色。
5. **不靠缩放**：不允许用整体 scale 或位置插值冒充动作。

## 失败条件

- 动作读成"卡片在滑"或"方块在平移"。
- 需要减速/慢放才看得出意图。
- 三个阶段（预备/执行/收尾）时长一样，像机器。
- 角色在每个动作结束后立刻回到完全静止。

## 决定

通过后进入 Gate 3；不通过则回到 Gate 1 改角色或改绑定，**不要用更多动画掩盖造型问题**。
