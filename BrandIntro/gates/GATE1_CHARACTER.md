# GATE 1 — 角色美术验证

状态：未开始（依赖 Gate 0 选定方向）
目标：只验证角色本身。**不做动画，不做场景，不做片头。**

## 交付物

| # | 交付 | 规格 |
| --- | --- | --- |
| 1 | 三视图 | 正面 / 侧面 / 背面，正交相机，平光，1920×1080，白底 |
| 2 | 四个状态静帧 | 中性、好奇、思考、完成；同一机位、同一光 |
| 3 | 材质近景 / 远景 | 0.3 m 与 3.0 m 各一张，看材质与可读性 |
| 4 | 三组灯光 | 主光 + 补光 + 轮廓光分别单独开一次，看各自的贡献 |
| 5 | 三个距离的可读性 | 角色占画面 1/2、1/4、1/8 高 |
| 6 | 一页判断表 | 每组图附"通过/不通过 + 理由" |

## 通过标准

1. **静帧就有设计感**：不靠运动、不靠特效、不靠景深掩盖造型问题。
2. **1/8 仍可识别**：缩到 240 px 宽，角色不是一团色块。
3. **表情可读**：不看上下文，能区分"好奇"和"思考"。
4. **材质可信**：近景能看出纸/陶瓷/金属的差别；远景没有高光斑。
5. **没有多余件**：删掉任何一件配件，轮廓不变差——说明它本来就不该有。
6. **品牌归属**：把它和 WAYNE 的 W 放在一起，不像两个来源。

## 失败条件（任一条即不通过）

- 需要靠"可爱"来成立。
- 需要靠动画才能看懂造型。
- 缩小后只剩一个圆角方块。
- 表情只能靠贴图切换。
- 角色和 W 是两种语言（一个圆润、一个折线）。

## 方法

- 全部用同一台相机、同一组灯，只改角色与距离；否则无法比较。
- 每个判断写"证据"：哪一帧、哪一处、为什么不通过。
- 不写"感觉不错""挺可爱"。
