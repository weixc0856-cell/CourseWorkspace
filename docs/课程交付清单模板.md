## 8. 使用方式

```powershell
# 课件预览（8081）
cd CourseSlides
npm run dev
# http://localhost:8081/?lesson={{LESSON_SLUG}}

# Motion Studio（5173）
cd MotionStudio
npm run serve

# 一键构建
.\scripts\build-lesson.ps1 -Lesson {{LESSON_SLUG}}

# 只校验契约
uv run --project CourseControl course-control validate --lesson {{LESSON_SLUG}}
```

- 8080 只留给本地模型，不用于课件预览；50000 留给 CosyVoice。
- Motion Studio 没有 `npm run dev`，使用 `npm run serve` 或 `npm start`。
- 场景路径是 `MotionStudio/src/scenes/<slug>/*.tsx`，不是 `MotionStudio/scenes/*.ts`。
- 构建产物在 `build/{{LESSON_SLUG}}/`，不入库。
