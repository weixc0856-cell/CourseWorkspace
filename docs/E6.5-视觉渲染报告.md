## 1. 渲染

```powershell
uv run --project ManimSandbox manim render -r 1920,1080 --fps 30 `
  --media_dir build/manim-multi-head/e6.5/media `
  ManimSandbox/05-multi-head/multi_head.py MultiHeadScene
```


## 2. 五个 beat

| Beat | 画面 |
| --- | --- |
| B1 | 同一 `X` 4×4 进入 Head 1 / Head 2，两条箭头，标注“same X · independent weights” |
| B2 | Head 1 的 `W_Q1/W_K1/W_V1` 4×2 → `Q1/K1/V1` 4×2 → `alpha_1` 4×4 热力图 + `context1` 4×2 |
| B3 | Head 2 的 `W_Q2/W_K2/W_V2` → `Q2/K2/V2` → `alpha_2` + `context2`；底部对比 `cat` 行 |
| B4 | `context1` 与 `context2` 并排 → `concat` 4×4；`4 = 2 + 2` |
| B5 | `W_O` 4×4 与 `final` 4×4；维度链 `X 4×4 → Q/K/V 4×2 → concat 4×4 → final 4×4` |

所有矩阵与数值来自 `multi_head_math.py`，场景文件没有另写一份算例。

## 3. 抽帧核对

已从 1080p 成片抽取并检查：

- B1 结束时两条箭头指向两个 Head；
- Head 1 的 `Q1/K1/V1` 的 `cat` 行高亮；
- Head 1 的 `alpha_1` 峰值在 `The`（0.65）；
- Head 2 的 `alpha_2` 峰值在 `sat`（0.65）；
- 两个头 `cat` 行并排对比；

- `final` 4×4 显示，`cat` 行高亮；
- 底部公式与维度链无重叠。

抽帧位于 `build/manim-multi-head/e6.5/stills/`，不入库。
