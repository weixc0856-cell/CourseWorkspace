# 内容类型与音频策略

日期：2026-11-08

## 1. 结论

音频策略按内容形态区分，不做一套参数套所有视频。

| 内容类型 | 定义 | BGM | 典型声音 |
| --- | --- | --- | --- |
| 科普视频 | 单篇论文讲解、技术领域拆解、概念解释 | **允许，低音量** | 旁白为主；Serenity / Schubert 铺底；高潮段可用 We Never |
| 正式课程 | 书的一章一章讲解；MIT / Stanford / 高校或机构已有课程的解读、二次录制 | **不用 BGM** | 旁白 + 必要音效/静默；保持教室/讲座感 |
| 新闻/资讯 | 事实梳理、评论、快讯 | **不用 BGM** | 旁白为主；只在片头/转场允许极短声音标识 |

判断原则：内容是“解释一个点”还是“系统讲授一门课/陈述事实”。前者可以借音乐控制节奏，后者音乐只会干扰理解与权威感。

## 2. 科普视频的 BGM

- 默认低频铺底：Serenity（平静吉他）或 Schubert D.664（抒情钢琴）；
- 高潮/结论：We Never (Instrumental)，短暂抬起，不全程铺；
- 起始相对电平（试混值，不是生产写死值）：

| 曲目 | 旧试混 | 降低后的试混 |
| --- | ---: | ---: |
| Serenity | -21 dB | **-25 dB** |
| Schubert D.664 | -16 dB | **-20 dB** |
| We Never | -24 dB | **-28 dB** |

- sidechain 闪避 6–8 dB，attack 20 ms、release 450 ms 只是起点；
- 最终成片 -16 LUFS / TP ≤ -1 dBTP；
- 不写死 EQ；目前只做 70 Hz 高通；
- CC BY 曲目必须随片署名；We Never 商用前需补授权证据。

降低后的试混：

```text
build/bgm-audition/mix-serenity-low.mp3
build/bgm-audition/mix-schubert-low.mp3
build/bgm-audition/mix-we-never-low.mp3
```

## 3. 正式课程与新闻

- 不使用 BGM；旁白、必要的转场音效和自然停顿承担节奏；
- 需要“章节感”时，用章节卡与短暂静默，不用音乐铺满；
- 若以后确需主题音乐，先作为显式例外写入单课配置，不进入默认策略。

## 4. 与现有实现的关系

- 已实现 `course-control audio-plan`：读取 `lesson.yaml.audio`，输出 `build/<slug>/audio/audio_plan.json`；
- 校验：正式课程/新闻配置 BGM 直接 `blocked`；CC BY 缺署名、许可未知、未核实授权标成商用均 `blocked`；增益高于 -18 dB 或 ducking 高于 12 dB 给 warning；
- 尚未实现：AudioPlan 还没有被 Remotion 混音消费，BGM 仍以手工 `ffmpeg` 试混为主；下一步把 cues 写进 TimelineSpec 的音频轨。

## 5. 命令

```powershell
uv run --project CourseControl course-control audio-plan --lesson <slug>
```

## 6. 选曲边界

- 不抽电影/动画原声；
- We Never 为 `OWNER_AUTHORIZED_UNVERIFIED`，不得标成 CC0/PD；
- Keynata 旧曲目人工听感未通过，不进入生产；
- 音乐库缺 sparse ambient / pulse；需要时另行授权或委托，不将古典/民谣硬套到模拟/纪录片。
