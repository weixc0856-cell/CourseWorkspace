# 内容类型与音频策略

日期：2026-11-08（2026-11-14 修订：新闻类音乐策略作废，见 §3.2）

## 1. 结论

音频策略按内容形态区分，不做一套参数套所有视频。

旁白语言固定英文；中文只做字幕与文章版本，默认不做中文配音。

| 内容类型 | 定义 | BGM | 典型声音 |
| --- | --- | --- | --- |
| 科普视频 | 单篇论文讲解、技术领域拆解、概念解释 | **允许，低音量** | 旁白为主；Serenity / Schubert 铺底；高潮段可用 We Never |
| 正式课程 | 书的一章一章讲解；MIT / Stanford / 高校或机构已有课程的解读、二次录制 | **默认不用，可显式使用** | 旁白 + 必要音效/静默；保持教室/讲座感 |
| 新闻/资讯 | 事实梳理、评论、调查报道 | **允许，分段设计** | 旁白 + 音乐进入/让路 + 音效 + 环境声；关键证据处音乐撤掉 |

判断原则：先看内容是“解释一个点”还是“系统讲授一门课”。正式课程按讲座感处理，音乐只会干扰理解与权威感；新闻片允许音乐，但音乐必须随叙事进退、在关键证据处让路，不能全程铺满（理由见 [新闻与调查报道标准.md](新闻与调查报道标准.md) §4）。

## 2. 科普视频的 BGM

- 默认低频铺底：Serenity（平静吉他）或 Schubert D.664（抒情钢琴）；
- 高潮/结论：We Never (Instrumental)，短暂抬起，不全程铺；
- 起始相对电平（试混值，不是生产写死值）：

| 曲目 | 旧试混 | 降低后的试混 |
| --- | ---: | ---: |
| Serenity | -21 dB | **-25 dB** |
| Schubert D.664 | -16 dB | **-20 dB** |
| We Never | -24 dB | **-28 dB** |

- sidechain 闪避 6–8 dB，attack 20 ms、release 450 ms 只是起点；
- 最终成片 -16 LUFS / TP ≤ -1 dBTP；
- 不写死 EQ；目前只做 70 Hz 高通；
- CC BY 曲目必须随片署名；We Never 商用前需补授权证据。

降低后的试混：

```text
build/bgm-audition/mix-serenity-low.mp3
build/bgm-audition/mix-schubert-low.mp3
build/bgm-audition/mix-we-never-low.mp3
```

## 3. 正式课程与新闻

### 3.1 正式课程

- 默认不使用 BGM；旁白、必要的转场音效和自然停顿承担节奏。需要音乐时显式声明，代码不拦截（D-097：交付质量是唯一门禁）。
- 需要“章节感”时，用章节卡与短暂静默，不用音乐铺满；
- 确需主题音乐的，作为显式例外写入单课配置，不进入默认策略。

### 3.2 新闻 / 资讯（2026-11-14 修订）

- 取消“新闻类禁用 BGM”。新闻片默认四层声音：旁白 / 音乐 / 音效 / 环境声，见 [新闻与调查报道标准.md](新闻与调查报道标准.md) §4 与 [声音导演层.md](声音导演层.md)。
- 音乐必须分段设计（`enter` / `hold` / `duck` / `lift` / `leave` / `silence`），不许一首铺到底；关键证据、关键数字段落必须 `duck` 或 `silence`。
- 无旁白的新闻系列（`BEYOND THE HEADLINES`）只有音乐、音效与环境声；这是设计例外，在系列 bible 声明。
- 许可与署名规则不变：CC BY 必须署名，来路不明不得进混音。
- **门禁**：音乐不再按内容类型拦截（2026-11-14，D-097）。`audio-plan` 与 `sound-design` 只检查许可与电平；成片的交付质量是唯一门禁。

## 4. 与现有实现的关系

- 已实现 `course-control audio-plan`：读取 `lesson.yaml.audio`，输出 `build/<slug>/audio/audio_plan.json`；
- 校验：音乐不再按内容类型 `blocked`（D-097）；CC BY 缺署名、许可未知、未核实授权标成商用仍 `blocked`（法律与交付风险，不是风格门禁）；增益高于 -18 dB 或 ducking 高于 12 dB 给 warning。
- 尚未实现：AudioPlan 还没有被 Remotion 混音消费，BGM 仍以手工 `ffmpeg` 试混为主；下一步把 cues 写进 TimelineSpec 的音频轨。

## 5. 命令与配置

```powershell
uv run --project CourseControl course-control audio-plan --lesson <slug>
```

`lesson.yaml` 显式声明（缺省为 `formal_course`，即不允许 BGM）：

```yaml
audio:
  content_kind: popular_science
  bgm:
    - track_id: bgm_serenity_guitar
      start_s: 3
      end_s: 90
      gain_db: -25
      duck_db: 6
      license_status: cc_by
      attribution: "SERENITY by Jason Shaw (audionautix.com), CC BY 3.0 US"
      commercial_allowed: true
```

## 6. 选曲边界

- 不抽电影/动画原声；
- We Never 为 `OWNER_AUTHORIZED_UNVERIFIED`，不得标成 CC0/PD；
- Keynata 旧曲目人工听感未通过，不进入生产；
- 音乐库缺 sparse ambient / pulse；需要时另行授权或委托，不将古典/民谣硬套到模拟/纪录片。
