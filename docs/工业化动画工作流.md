# 工业化动画工作流（v1）

目标：把"像 3B1B 那样用动画讲清楚"从一次性手感，变成**可复现、可校验、可交接**的生产流程。本文是流程与门禁的权威定义；具体课程的镜头内容仍由作者在节拍表里决定。

范围：二维 Manim 动画与成片输出。Blender / Three.js 的三维质量后续单独优化；三维镜头仍走同一套节拍表、字幕安全区与验收门禁。

## 1. 3B1B 的运动语法（可操作的版本）

研究结论（来源见文末）：

1. **动画是论证**：每次变化对应当前这句旁白里的一个理解点，而不是装饰。
2. **变换优先于替换**：同一对象跨镜头存活、变形（句子行、矩阵、向量），少用整页淡出重建。
3. **相机有动机**：全景 → 推近细节 → 拉远收束；不为填时间而缩放或漂移。
4. **节奏**：单镜头 5–16 秒；开场建立，中段变化，结尾留半拍。
5. **色彩克制**：一页最多两个语义色；纸面 70%、墨色 20%、重点 10%。

这五条被编码成节拍表规则和评分卡，见下。

## 2. 产物与职责

| 产物 | 位置 | 谁写 | 作用 |
| --- | --- | --- | --- |
| 节拍表 | `lessons/<slug>/authoring/beats.yaml` | 作者/导演 | 镜头切分、每个镜头 2+ 个论证动作、长寿命对象、相机动机、配色 |
| 场景 | `ManimSandbox/<slug>/<scene>.py` | 动画工程 | 按节拍表实现；每个镜头结束调用 `check_now` |
| 配色 | `ManimSandbox/common/palettes.py` | 设计系统 | 7 组古画配色 + 当前 editorial，自动推导可访问角色 |
| 构建报告 | `build/<slug>/final/build-report.json` | `build-lesson.ps1` | 各阶段状态与 verdict |
| 媒体 QC | `build/<slug>/quality/media-qc.json` | `media-qc` | 解码/格式/响度/静音/黑帧/冻结/字幕 |
| 对齐评分 | `course-control animation-score` | 评分器 | 运动密度、连续性、节奏、相机、门禁、冻结的 0–100 分 |
| 成片 | `build/<slug>/final/course-video-mixed.mp4` | compose + audio-mix | 交付物 |

## 3. 流程（每一步都有门禁）

### 步骤 0 · 课程类型 → 配色

按 `docs/evaluations/配色方案-学科适配.md` 的矩阵选一组配色，写进 `beats.yaml` 的 `palette`。门禁：`beats-validate` 会读取配色并检查对比度（正文 ≥7:1、图形 ≥3:1、次要文字 ≥4.5:1）。

### 步骤 1 · 写节拍表

```yaml
schema_version: 1
lesson: <slug>
palette: qinglv
subtitle_safe_below: -2.2
shots:
  - id: 1a
    segment: 1
    start: 0.0
    end: 0.45
    engine: manim
    long_lived: [sentence]
    beats:
      - {at: 0.12, kind: reveal, action: 句子行出现}
      - {at: 0.55, kind: connect, action: 弧线汇入焦点词}
      - {at: 0.85, kind: highlight, action: 焦点词脉冲}
```

规则（`beats-validate`）：

- 每个旁白段落被镜头**连续、无缝隙、无重叠**覆盖；
- 单镜头 5–16 秒；
- 每镜头 ≥2 个动作，第一个在 35% 之前，任意两次动作间隔 ≤4 秒；
- 至少一半镜头声明 `long_lived`（跨镜头存活的对象）；
- 相机移动必须带 ≥8 字符的 `motive`；
- 字幕带预留：`subtitle_safe_below ≤ -1.5`。

```powershell
uv run --project CourseControl course-control beats-validate --lesson <slug>
```

### 步骤 2 · 实现场景

- 用 `common/design_system.py` 的版式与语义色；需要换配色时用 `common/palettes.py` 的角色，不直接写十六进制。
- 每个镜头结束、**淡出之前**调用 `check_now(self, "<shot id>")`。
- 对象寿命：至少把句子行/焦点 token/矩阵做成跨镜头对象，用 `Transform`/`ReplacementTransform` 交接。
- 屏幕文字：整卡/整段淡入，不用 `Create` 逐字揭示（会被看成末字截断）。

### 步骤 3 · 低清预览

```powershell
cd ManimSandbox
uv run manim render -r 640,360 --fps 10 --media_dir ../build/<slug>/tmp/preview <slug>/<scene>.py <Class>
```

预览日志门禁：`[layout]` 0 条、`overran` 0 条、时长与旁白一致。低清预览是迭代主战场，不允许直接上 1080p 试错。

### 步骤 4 · 全量构建

```powershell
.\scripts\build-lesson.ps1 -Lesson <slug>
```

`STRICT_LAYOUT=1` 下任何文字越界/重叠直接失败；版式问题必须在场景里修，不允许降低门禁。

### 步骤 5 · QC 与评分

```powershell
uv run --project CourseControl course-control media-qc --lesson <slug>
uv run --project CourseControl course-control quality-report --lesson <slug>
uv run --project CourseControl course-control animation-score --lesson <slug>
```

- `media-qc`：不允许 FAIL；`media.freeze` 允许 WARN，但冻结段必须能在节拍表里解释（例如刻意的停顿）。
- `animation-score`：**指标工具，不是发布门禁**。六项分数对应 `long_take` 档的运动语法；其他语法用 `quality-gate` 按各自 profile 判定。
- `quality-gate`：Hard（不可豁免）/ Grammar（按镜头语法，可书面豁免）/ Metrics（只报告）/ Human（发布签核）四层。**不再存在统一 85 分发布线。**
- 人工完整看一遍：字幕遮挡、语义错误、节奏，这三项自动化替代不了。

> **2026-11-10 起**：本文第 3 节的 5–16 秒、长寿命对象 ≥50%、每 4 秒一次动作，是 **`long_take` 语法档**的生产阈值，不是通用质量定义。其他语法见 `shared/grammars/visual-grammars.yaml`；短切、模拟、动态文字各自有 profile。`quality-gate` 按镜头所在 grammar 检查，`animation-score` 仅作指标。
>
> **同日起（D-071）**：这些阈值是**诊断指标，不是放行条件**。发布只看三条——把问题讲明白、把画面做好、把交付做硬；不存在"必须做满 N 秒动画"或"每 4 秒必须有一个动作"的硬约束。目前 `beats-validate` 仍按旧规则硬失败，规则调整待做（见 D-071）。

## 4. 评分卡（`long_take` 档）

| 维度 | 权重 | 目标 | 数据来源 |
| --- | --- | --- | --- |
| 运动密度 | 25 | ≥2.5 动作/10 秒 | 节拍表 |
| 连续性 | 20 | ≥60% 镜头有长寿命对象 | 节拍表 |
| 节奏 | 15 | 平均镜头 8–12 秒 | 节拍表 + 旁白 |
| 相机动机 | 10 | 每次移动都有动机 | 节拍表 |
| 门禁 | 15 | 节拍表 0 问题、构建 pass | beats-validate + build-report |
| 冻结 | 15 | ≤9 段/分钟（参考样片 9.2） | media-qc |

当前校准课（`long_take` 档）：94.7/100（运动 25、连续 20、节奏 15、相机 10、门禁 15、冻结 9.7）。冻结仍是相对弱项，但已与自家参考样片同量级。

冻结目标的校准：本项目 2 分钟 3B1B 风格样片（`build/attention-3b1b/attention.mp4`）实测 19 段 / 123 秒 ≈ 9.2 段/分钟；评分卡以 **9 段/分钟为满分线、20 段/分钟为 0 分线**，即“追平自家参考样片”。沙德森的原片会有更快的镜头运动；本指标衡量的是与本项目参考样片的距离，不是与原作者的距离。

## 5. 为什么这样能停止"一轮一轮调"

- 空闲镜头、覆盖漏洞、字幕遮挡在**写节拍表时**就被拦下，不用等渲染。
- 配色对比度在**选型时**被程序校验，不靠肉眼。
- 连续性、运动密度、冻结是**评分项**，每次构建都能对比，不会悄悄退化。
- 低清预览 + 严格版式 + 单镜头检查，把返工限制在分钟级，而不是整片重渲。

## 6. 已知边界

- 评分卡是代理指标：它奖励"动作多、对象长寿"，但不能判断某个动作是否**讲对了**。语义正确性仍由人工与来源证据负责。
- 3B1B 的资产层（光晕、景深、手绘抖动、向量场）与音频层（音效、词级对齐）尚未沉淀，评分卡不覆盖。
- 三维镜头暂用同一门禁，但三维的构图/光照质量需要单独规范。
