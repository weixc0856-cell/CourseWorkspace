## 2. 验证内容

脚本由实际矩阵和公式计算，不包含手工填写的预期数值作为验证依据。检查项：

| 类别 | 检查 |
| --- | --- |
| 形状 | `X 4×4`、`Q/K/V 4×2`、`scores/alpha 4×4`、`context 4×2`、`concat 4×4`、`final 4×4` |
| 维度关系 | `h·d_k = 2·2 = d_model = 4`；`concat width = 2+2 = 4` |
| 归一化 | 两个头共 8 行 alpha，每行和 = 1 |
| 头差异 | `max |alpha_1 - alpha_2| = 0.489785 > 0.4` |
| 教学焦点 | `cat` 在 Head 1 关注 `The`，在 Head 2 关注 `sat` |
| 拼接 | `concat[i] == [context_1[i] | context_2[i]]` |
| 输出投影 | `final != concat`，`W_O` 确实混合两个头 |
