# 运镜与剪辑（Still Motion）

日期：2026-11-08
参考：Bilibili《Claude 背后的 Anthropic：掌握核心科技的邪教》
代码：`CourseControl/src/course_control/motion.py`、`RemotionStudio/src/components/MotionImage.tsx`

## 1. 参考片拆解

34:07 / 2560×1440，主要手法：

- 电影感 AI 静帧（黑白、石像、戏剧光）；
- 静帧缓慢推拉/平移（Ken Burns），没有大量矢量动画；
- 粗体编辑大字 + 章回卡（`CHAPTER I / 教主 / THE PROPHET`）；
- 黑、白、红三色，强对比；
- 旁白 + 音乐/音效 + 烧录字幕。

## 2. 我们借鉴什么

只借鉴**制作手法**，不复制题材、影像与配色：

| 手法 | 是否采用 | 落点 |
| --- | --- | --- |
| 静帧慢推/平移 | 采用 | `MotionPolicy` + Remotion `MotionImage` |
| 强编辑排版/章节卡 | 部分采用 | 版式模板 + 章节标题；独立章节卡后续 |
| 硬切/淡入节奏 | 保持现有 cut；dissolve 待做 | Remotion 时间线 |
| 电影级 AI 静帧 | 采用（仅静帧） | 本地 FLUX.3 生图，见 [本地图像生成-FLUX3.md](本地图像生成-FLUX3.md)；不能生成视频 |
| 音乐/音效 | 不采用 | 需要授权曲库；后续单独做音频层 |
| 黑白红高对比主题 | 不采用 | 课程默认浅色编辑主题 |

## 3. MotionPolicy

`lesson.yaml`：

```yaml
motion:
  slides: ken_burns   # 或 static
  scale: 1.06         # 1.0 < scale <= 1.15
  pan_percent: 1.2    # 0..4，百分比
```

默认 `ken_burns`、`scale=1.05`、`pan_percent=1.2`。`01-transformer-demo` 显式设为 1.06。

`motion.slide_motion(index, policy)` 生成 4 种交替路径：

| index % 4 | 缩放 | 平移 |
| --- | --- | --- |
| 1 | 1.04 → scale | 纵向 +pan → -pan |
| 2 | scale → 1.04 | 横向 -pan → +pan |
| 3 | 1.04 → scale+0.02 | 横向 +pan → -pan |
| 4 | scale+0.02 → 1.04 | 纵向 -pan → +pan |

安全约束：缩放最小 1.04，平移不超过 1.2%，避免露出画布边缘；所有运动在镜头时长内线性完成，不做速度突变。

## 4. 链路

```text
lesson.yaml.motion
  → collect / TimelineSpec.video[].metadata.legacy_motion
  → Remotion CourseTimeline
  → MotionImage: translate(pan%) scale(scale)
```

- 只作用于 `kind=slide` 的底图；视频镜头、Manim/Blender 插入不受影响。
- 静态页面仍有版式模板与安全区；运镜不改变文字位置，只改变取景。
- `static` 时完全回到原来的静态幻灯片。

## 5. 测试与验证

- `CourseControl/tests/test_motion.py`：policy 解析、4 种路径确定性、缩放/平移边界。
- `RemotionStudio`: `./node_modules/.bin/tsc --noEmit` 通过。
- 时间线元数据：`TimelineSpec.video[].metadata.legacy_motion` 只在 slide 镜头出现。

## 6. 不做与下一步

- **音乐/音效**：无授权素材，不写死参数；后续做 `AudioPlan`（bed、ducking、SFX、响度）。
- **生图**：ComfyUI 8188 已部署，FLUX.3 可出静帧（约 2 分钟/张）。只做静帧素材与 2.5D 平板，不能生成视频；用法见 [本地图像生成-FLUX3.md](本地图像生成-FLUX3.md)。
- **章节卡**：参考片的 `CHAPTER I` 卡片还没进入时间线；下一步可以作为独立 shot 类型生成。
- **dissolve**：当前底图是 cut；真正的交叉溶解需要序列重叠，时间线要支持重叠窗口。
- 宽高比：参考片 2K；课程默认 1080p，可在 `lesson.outputs.resolution` 配到 2560×1440。
