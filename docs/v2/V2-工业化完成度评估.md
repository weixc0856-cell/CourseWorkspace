## 5. 提案原则 vs 代码

| 提案原则 | 代码事实 | 判定 |
| --- | --- | --- |
| 时间、镜头数不是质量闸门 | `storyboard.schema.json` 对 `duration_s` 无上下限；时长只是课程自己声明的窗口（`content/duration.py`） | 符合 |
| Animatic 可反复改，不因次数判失败 | 片段缓存按输入哈希；`--shot` 只重编受影响段 | 符合 |
| Lock 是版本管理，不是禁令 | `lock-status` 只报漂移与下游，不阻断（唯一强制点是字幕脚本哈希） | 符合 |
| 声音与画面独立生产、精确同步 | 两条链共用 `narration.meta.json` 与时间线，缓存键分开 | 符合 |
| 程序 / 课程物理分离 | 内容根 `D:/CourseContent`，仓库只剩程序与夹具 | 符合 |
| 自动化程度 ≠ 课程质量 | `quality-gate` 五维仍要人审，Q1/Q2/Q5 不自动通过 | 符合 |

这一层不需要改动；也没有出现"为过关而加门禁"的迹象，80 个命令无功能重复。
