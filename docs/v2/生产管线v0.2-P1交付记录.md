JSON spec 仍是版本化输入；`blends/` 是构建产物。

### 1.2 构建模式

`scripts/build_asset_scene.py` 新增：

```text
--build auto          # 默认：环境 spec → environment；shot spec 有 env blend → shot；否则 inline
--build environment   # 构建 blends/environments/<place>.blend
--build shot          # 链接 environment blend，构建 blends/shots/<shot>.blend 并渲染
--build inline        # 旧兼容：把 environment 合并进 shot 后再渲染
```

`scripts/render-asset-shot.ps1` 增加 `-Build`。

### 1.3 Environment `.blend`

Environment 文件包含：

- `ENV`：Terrain、Atmosphere、Water；
- `ENV_ASSETS`：导入的模型/布景；
- `ENV_LIGHTS`：环境灯光与目标空物体；
- `AssetWorld`：HDRI 世界；
- **没有** shot 相机，没有 shot 动画。

保存时使用 Blender 的库路径重映射，shot 文件以相对路径引用 environment。

### 1.4 Shot `.blend`

Shot 文件：

- 通过 `bpy.data.libraries.load(..., link=True)` 链接 `ENV`、`ENV_ASSETS`、`ENV_LIGHTS` 和 `AssetWorld`；
- 自有 `cam_<shot>` 相机与目标；
- 自有 shot 灯光（如果有）；
- 保存后再渲染。

当前没有使用 Library Overrides：需要局部修改链接对象时，先以“新增 shot 灯光/相机”解决；改链接对象本身仍未实现。这是 P1 的明确缺口。

### 1.5 Manifest

Shot manifest 的 `inputs` 增加 `environment_blend` 哈希；`build_kind` 区分 `environment` / `shot` / `inline`。environment blend 一变，引用它的 shot 缓存键就失效。

## 4. 已知限制

- **Library Overrides 未实现**：当前只能新增 shot 相机/灯光，不能覆盖链接的地形材质或环境灯参数。
- `auto` 在 env blend 不存在时回退 `inline`，保证旧 shot 命令仍可运行；显式 `-Build shot` 才强制链接。
- 只构建了 a1/a4 的 shot blend；a2/a3 仍可用 inline 或后续补建。
- 环境世界对象名固定为 `AssetWorld`；改名会破坏链接，需要在构建时校验。
- Blender linking 的自动化测试还没有；目前是构建脚本 + 手工 inspect 证据。
