## 3. 六阶段全自动课程编译管线（Curriculum Compiler Pipeline）

1. **Stage 1: 结构化解析与证据链提取**
   - Docling 结构化提取原书 Markdown、LaTeX 公式、图表锚点与高清图片资产。
2. **Stage 2: 原子知识图谱蒸馏 (Atom Map)**
   - 全书蒸馏为 ~450–550 个 Atom 知识元，标定 `concept_type`、`cognitive_load`（1–5 分）、`estimated_minutes` 与前置依赖 `prerequisites`。
3. **Stage 3: 拓扑排课与认知预算装箱 (Reduce)**
   - 建立 DAG 拓扑排序，按 9.5±1.0 分钟装箱（Bin-packing），形成严格 180 节无超前引用课表。
4. **Stage 4: 双轨内容生成 (Deck + 口播提词稿)**
   - 注入动态 SQLite 状态账本（`symbol_registry` + `covered_ledger` + `forward_guard`），强制四段式教学脚手架（Hook -> Intuition -> Derivation -> Takeaway），生成全英文 Slide 与中英双语口播提词稿。
5. **Stage 5: 确定性五重 QA 门禁 (QA Gate)**
   - 字数卡控（1,150–1,450 词）、跨课语义去重（余弦相似度 ≤ 0.82）、废话比例控制（≤ 12%）、符号一致性、双轨页码 1:1 对齐。
6. **Stage 6: 视觉与音视频资产渲染**
   - 独立 Manim 机制动画脚本与 TTS 音频对齐，输出工业级交付包。

## 4. 核心工程状态机规范

### 4.1 SQLite 状态表设计

- **`symbol_registry`**：全局物理量符号圣经。记录符号、LaTeX 表达式、标准英文/中文术语、量纲单位及首次引入课程。
- **`covered_ledger`**：已讲知识点台账。记录第 1 到 $N-1$ 课的核心定理、一句话结论与公式引用。当前课若涉及仅允许一句话引用，严禁重复推导。
- **`forward_guard`**：前向防剧透锁。标记后续课程拥有的专属知识点与核心公式，禁止前序课程越权剧透。

### 4.2 强制四段式教学脚手架（9.5 分钟黄金结构）

1. **Hook & Pain Point（1.5 分钟 / ~200 词）**：
   - 抛出具体工程失效或反直觉现象，严禁套话寒暄，0.1 秒进入物理矛盾。
2. **Physical Intuition & Geometry（2.5 分钟 / ~350 词）**：
   - 建立几何拓扑与极限状态直觉（如 $Re \to 0$ 与 $Re \to \infty$），禁止堆砌复杂公式。
3. **Formal Derivation & Mechanics（4.0 分钟 / ~550 词）**：
   - 严格单步推导核心公式，每一步交代物理项意义，严禁跳步。
4. **Engineering Takeaway & Boundary（1.5 分钟 / ~200 词）**：
   - 给出有效边界条件与工程标定准则（风洞、CFD、造型平衡）。
