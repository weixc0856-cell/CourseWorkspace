## 1. Visual Grammar

### 1.1 注册表

- 人读：`shared/grammars/style-presets.yaml`
- 机器读：`shared/grammars/style-presets.json`（Builder 使用）
- 四套 preset 均为 `version: "1.0"`：
  - `cinematic_realism@1.0`
  - `scientific_visualization@1.0`
  - `stylized_diorama@1.0`
  - `technical_cutaway@1.0`

每套增加 `builder` 块，Builder 只消费它能执行的字段：

```yaml
builder:
  color_management: agx
  look: AgX - Medium High Contrast
  exposure: 0.0
  world_strength: 0.35
  atmosphere_density: 0.00006
  lens_default: 45
  motion_blur_shutter: 0.5
  grain: subtle
  typography: editorial
```

### 1.2 Spec 引用

Environment/Shot 增加可选：

```json
"visual_grammar": "cinematic_realism@1.0"
```

Validator 检查：

- 必须写成 `id@version`；
- preset 存在；
- registry 版本一致。

三个 environment 已声明 `cinematic_realism@1.0`，shot 继承 environment；需要覆盖时在 shot 写自己的 `visual_grammar`。

### 1.3 Builder 消费

Builder 应用：

- 色彩管理：`AgX` / `Standard`；
- look 与 exposure；
- 未显式指定时的 world strength；
- 未显式指定时的 camera 默认焦段；
- motion blur shutter；
- 写出 `<output>.look.json`，供 Remotion/后期读取 grain/typography/composition/sound 默认值。

显式 spec 值优先于 grammar 默认值。Grammar 不覆盖镜头自己的设计。

证据：

```text
projects/fengshui/experiments/ab-2026-11/a/p3/
├── a1-grammar.png
├── a1-grammar.look.json
└── manifests/
```

`look.json` 记录 `cinematic_realism@1.0` 与 Builder 实际使用的参数。

## 2. QC 集成

### 2.1 release-check

`course-control release-check` 增加：

```powershell
--shot-review-dir <review-root>
```

`review-root` 下每个 `<shot>/qc.json` 成为一个 `shot_review` 步骤：

- `PASS` / `WARN` → 不阻塞；WARN 写明细；
- `FAIL` → 整个 release-check `FAIL`；
- 缺 Review Package → `INCOMPLETE`，除非有有效人工豁免；
- 有效豁免 → 步骤 `exempt`，整体 `pass_with_exemption`，与 PASS 明确区分；
- `delivery_allowed` 仅在 `pass` 或 `pass_with_exemption` 为 true。

### 2.2 人工豁免审计

`<shot>/exemption.json` 必须包含：

```json
{
  "object": "a1 review package",
  "reason": "shot is a technical blockout; no review package generated",
  "operator": "owner",
  "time": "2026-11-14T23:00:00+08:00",
  "missing_checks": ["shot_review"],
  "delivery_version": "p2-blockout"
}
```

缺字段的豁免视为无效，整体回到 `INCOMPLETE`；豁免不会把 `FAIL` 洗成 PASS。

### 2.3 实测

```text

```

## 4. 已知限制

- Grammar 仅提供默认值；显式 spec 优先，不做强制覆盖。
- `release-check` 需要显式 `--shot-review-dir`；尚未从 `project.yaml` 自动推导。
- `shot_review` 步骤只检查存在的包；缺整个 shot 目录需要靠调用方提供预期清单，暂未实现。
- `look.json` 已导出，但 Remotion 端还没有消费 grain/typography；P4 或后续接入。
- 豁免是人工审计记录，不是自动审批流。
