## 1. 已实现

### 1.1 Review Package

新增 `CourseControl/src/course_control/review/`：

- `shot_review.py`：为一个已渲染镜头生成完整 Review Package。
- `compare.py`：同一镜头的多版本首/中/尾帧并排对比。
- `cli/review.py`：`shot-review`、`shot-review-compare`。

每包输出：

```text
review/<shot>/
├── first.png
├── middle.png
├── last.png
├── contact-sheet.jpg
├── preview.mp4
├── metadata.json
├── qc.json
├── review.md
└── logs.txt
```

- 首/中/尾帧：ffmpeg 按时间抽取。
- Contact Sheet：默认 9 帧，3×3；竖屏用 180×320 单元，横屏用 320×180。
- Preview：短边 480；原始小于 480 时直接复制。
- Metadata：分辨率、帧率、时长、sha256、manifest build_id/profile/engine/samples。
- QC：解码、视频流、黑帧、冻结、音频、manifest 分辨率/帧率对比。
- Review：人工勾选构图/运动/灯光/关掉旁白是否成立；不写自动审美分。
- Logs：manifest 对应构建日志尾部 200 行。

### 1.2 QC 状态

- 黑帧 → `FAIL`。
- 冻结 → `WARN`（可能是有意 hold）。
- 无音频 → `WARN`（blockout/hero 视频本身无音频，音频在成片阶段加入）。
- 缺 manifest → `INCOMPLETE`，不冒充 PASS。
- 其余通过 → `PASS`。

### 1.3 命令

```powershell
# 生成单个镜头的 Review Package
course-control shot-review `
  --shot a1 --video <a1.mp4> `
  --manifest-dir <manifests> `
  --out <review/a1>

# 自动发现同目录 manifests/；也可显式 --manifest
# A/B 并排对比
course-control shot-review-compare --shot a1 `
  --take "v001-blockout=<a1-blockout.mp4>" `
  --take "v002-hero=<a1-hero.mp4>" `
  --out <review/a1-compare.jpg>
```

`scripts/render-asset-shot.ps1` 在 `-Out` 是视频时默认构建后自动跑 `shot-review`；用 `-Review:$false` 关闭。环境构建不跑。

## 4. 已知限制

- `review.md` 目前是英文模板；若需要中文审核表，改模板即可，不影响数据。
- 音频 QC 只检查有无音轨与响度；blockout/hero 视频无音轨，所以显示 WARN，这是预期。
- 冻结只报 WARN，因为 hold-dolly-hold 的首尾停顿是设计。
- 没有自动审美评分，也不应该加。
- 未接入 `release-check`；P3 做。
- 自动 Review 只在 wrapper 提供 `-Out` 视频时触发；直接调 Blender 不会自动跑。
