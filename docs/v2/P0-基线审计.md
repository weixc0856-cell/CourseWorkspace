## 4. 生产数据权威链（现状）

代码里已经写死了一条权威链，而且有注释为证：

  ├─ compose.mode=deck|scene → storyboard.yaml            （人工权威）

        ▼
Remotion（CourseTimeline / ScenePage / CourseVideo）→ FFmpeg
