# 教育内容视觉设计体系与视觉叙事规范 (Educational Visual Design System)

- **状态**：现行规范 (Active Standard)
- **版本**：v1.0
- **核心定位**：打破“左文右图”的机械 Word 搬运式课件，确立**“知识决定视觉形式，视觉形式服务知识表达”**的工业级长线课程视觉叙事标准。

---

## 一、 核心哲学：课件不等于排版，而是视觉叙事 (Visual Narrative)

很多 AI 自动化课件的通病是：**标题在顶部、文字在左侧、图片在右侧**。每个元素单独看都没错，但拼在一起就像把 Word 文档切碎铺在画布上，信息扁平、缺乏张力，观众连续看 3 页就会产生严重的认知疲劳。

在高质量工程与硬核科技课程中，一张优秀的幻灯片必须建立**清晰的三层认知阶梯**：

```mermaid
flowchart LR
    A["<b>1. Headline (认知入口)</b><br>告诉观众思考什么<br>提出矛盾 / 观点 / 物理问题"] --> B["<b>2. Visual (直观事实)</b><br>让观众看见讨论的实体<br>风洞试验 / CFD云图 / 结构透视"]
    B --> C["<b>3. Text & Callouts (因果闭环)</b><br>解释背后的动力学机制<br>解剖流动结构 / 提取数学规律"]
    C --> D["<b>观众形成物理直觉</b>"]
```

1. **Headline（标题）**：**必须是观点、问题或核心矛盾**，绝不是冷冰冰的教材目录章节名（例如：用《为什么 120 km/h 巡航时，70% 以上的功率都在对抗空气？》取代《1.1 汽车阻力概述》）；
2. **Visual（主体视觉）**：**承担证明、展示、解剖物理现象的核心任务**，图片本身就是知识的核心载体，而不是空白区域的装饰贴纸；
3. **Text & Annotation（文字与标注）**：**用于建立因果关系、指出流动机制**，是图片的解说员，坚决不照搬口播稿的全部逐字句子，文字高度克制、凝练、带有物理导向。

## 二、 六大异构视觉表达方式 (The Six Expression Archetypes)

长线工业课程必须根据**知识属性**动态选用六种不同的视觉构图，杜绝同一套排版跑通全场的审美疲劳：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       六大视觉表达方式与知识场景矩阵                         │
├──────────────────────┬──────────────────────────────────────────────────────┤
│ 1. Hero Visual       │ 引入核心矛盾、全新章节入口、典型震撼工程案例         │
│    (大图主导型)      │ 主图占 60%–80%，大留白，极简有力标题，少文字         │
├──────────────────────┼──────────────────────────────────────────────────────┤
│ 2. Editorial Layout  │ 概念机理阐释、瑞士国际主义网格、非对称多列阅读节律   │
│    (图文融合型)      │ 图片跨越主体，标题嵌入留白，精炼小标与短句编号       │
├──────────────────────┼──────────────────────────────────────────────────────┤
│ 3. Annotated Visual  │ 核心涡系解剖、CFD 尾流分离、风洞烟流局部放大标定     │
│    (物理注释型)      │ 真实流场图 + 物理分离线/特征涡箭头标注 + 局部放大框   │
├──────────────────────┼──────────────────────────────────────────────────────┤
│ 4. Comparison        │ Baseline vs Modified、同雷诺数流动形态、设计改型对标 │
│    (同构对比型)      │ 严格对齐视角、比例、云商标尺，第一眼看出物理差异     │
├──────────────────────┼──────────────────────────────────────────────────────┤
│ 5. Process / Flow    │ 涡脱落演化历程、逆压梯度边界层分离步骤、工程开发流程 │
│    (流动机理型)      │ 时间/空间多阶段切片连续排布，方向性箭头构建时间流     │
├──────────────────────┼──────────────────────────────────────────────────────┤
│ 6. Data-driven       │ 阻力-速度三次方曲线、雷诺数敏感度、风洞与CFD对标     │
│    (专业图表型)      │ 经济学人/自然期刊级图表，坐标清晰、单位完整、工况严谨 │
└──────────────────────┴──────────────────────────────────────────────────────┘
```

### 1. Hero Visual（大图主导型）
* **视觉重心**：强烈的真实工程沉浸感（如保时捷 911 在斯图加特风洞中的烟流测力实景、极具张力的超跑底盘气动扩散器）。
* **版式原则**：主画面占据页面 65%–80% 面积，文字压缩至 2–3 句核心论断，为观众建立直观的兴趣与敬畏感。

### 2. Editorial Layout（图文融合型）
* **视觉重心**：瑞士国际主义风格（Swiss Style），运用清晰的无衬线字体层级与严谨的不对称网格。
* **版式原则**：主图与文字有机穿插，标题嵌入图片的负空间区域，采用 `01 / 02 / 03` 结构化短语引导视线流动，是中篇机理讲解的中坚骨架。

### 3. Annotated Visual（物理注释型 · 汽车空气动力学核心主轴）
* **视觉重心**：**“图片本身就是讲解过程”**。一张高质量的后视镜或整车尾流 CFD 云图，直接叠加专业标注。
* **版式原则**：
  * 用细线引出气动特征：`Separation Bubble (分离泡)`、`A-Pillar Vortex (A柱涡)`、`Dead Water Region (死水区)`；
  * 提供局部 Detail Zoom 放大圆框/方框展示涡核内部剪切层；
  * **红线警示**：所有箭头与区域必须忠实反映真实流体力学机制，严禁为了美观随意涂画不符合 NS 方程的虚假流线。

### 4. Comparison（同构对比型）
* **视觉重心**：差异的可视化跳跃。
* **版式原则**：
  * 左侧 Baseline（基准构型）vs 右侧 Optimized（优化构型）；
  * **严格物理同构**：两图必须锁定完全相同的相机焦距、视点角度、网格雷诺数与 $C_p$ 压力标尺颜色区间；
  * 下方仅用两行指标（如 $\Delta C_D = -0.018$、能耗下降 3.2%）定量收敛。

### 5. Process / Mechanism（流动机理型）
* **视觉重心**：时间流逝或空间推移下的流动状态突变（例如：边界层由层流附着 $\rightarrow$ 逆压梯度减速 $\rightarrow$ 壁面剪应力归零 $\rightarrow$ 彻底分离脱体涡）。
* **版式原则**：3 步或 4 步水平卡片式推进，带指向性步进箭头，让观众理解因果链条的演变。

### 6. Data-driven（专业图表型）
* **视觉重心**：严谨工程杂志（Nature / SAE International / The Economist）图表风范。
* **版式原则**：
  * 杜绝花哨 3D 柱状图或缺乏量纲的商业概念图；
  * 坐标轴带完整的物理单位（$v$ [km/h], $P_{aero}$ [kW], $C_D$ [-]）；
  * 关键拐点（如 Ahmed 体斜背角 30° 阻力突跃）使用强调色（McKinsey Orange）醒目标注并引出原因解释。

## 三、 单节课的视觉叙事弧 (Visual Narrative Arc)

一节 9–11 分钟的标准视频课程（以 5–6 页幻灯片为例），页与页之间不是孤立的信息岛屿，而是一条步步紧扣的物理探索链路：

```text
[Slide 01: 核心矛盾] ──> [Slide 02: 物理现象] ──> [Slide 03: 机理解剖] ──> [Slide 04: 数学建模] ──> [Slide 05: 工程闭环]
 (Hero Visual)        (Editorial)          (Annotated)          (Data-driven)        (Comparison)
 提出宏观矛盾          揭示表面压力分布      剖析逆压梯度与分离    建立阻力方程量化      整车造型工程折中
```

## 四、 编译管线新阶段：增加 `Visual Concept` 契约

在工业化课程生成器（`course_compiler.py`）中，**严禁从讲稿直接直出 PPT Markdown**。在生成最终幻灯片之前，必须先产出每页的 **Visual Concept（视觉概念设计元数据）**：

```yaml
# Visual Concept Specification (单页视觉意图契约)
slide_index: 3
core_message: "尾部流动分离形成的死水回流区是产生压差阻力的根源"
headline: "Flow Separation Creates the Low-Pressure Wake"
visual_type: "annotated_visual"   # hero | editorial | annotated | comparison | process | data
main_visual_anchor:
  asset_type: "cfd_streamline_vector"
  uri: "assets/aero/ahmed_wake_cfd.png"
  focus_area: "rear_slant_and_wake"
supporting_text:
  - point: "Adverse Pressure Gradient"
    desc: "车身尾部收缩导致静压升高，边界层动量耗尽。"
  - point: "Recirculation Bubble"
    desc: "气流脱体形成低压死水区，吸拽车辆向后。"
composition:
  layout: "split_asymmetric_annotated"
  image_span: "60%"
  callout_anchors:
    - { label: "Shear Layer Separation", x: 0.42, y: 0.35 }
    - { label: "Low-Pressure Wake Core", x: 0.75, y: 0.55 }
visual_focus: "尾部逆向回流涡核"
physical_evidence: "Hucho 5th ed. Ch.4 §4.2; Ahmed et al. SAE 840300"
```

## 五、 T1-01 样板黄金五页（Golden Sample）全景示范

以课程首讲 **T1-01《汽车为什么本质上是钝体流动问题？》** 为基准，完整落地五大视觉范式：

* **Page 1（Hero Visual 大图主导型）**：
  * *标题*：Why Does Air Resist a Moving Vehicle?
  * *画面*：现代高速电动轿跑在暗调全尺寸气动声学风洞中的真实烟流实拍（占比 75%）。
  * *论点*：120 km/h 巡航时，整车超过 70% 的有效输出功率用于克服空气阻力。

* **Page 2（Editorial Layout 图文融合型）**：
  * *标题*：Streamlined Bodies vs. Bluff Bodies
  * *画面*：流线型机翼（95% 摩擦阻力）与近地面地面车辆（90% 压差阻力）的不对称排版。
  * *论点*：汽车不是空中水滴，必须承载乘客并贴近路面，底盘与尾部的剧烈几何断裂强制诱发流动分离。

* **Page 3（Annotated Visual 物理注释型）**：
  * *标题*：Separation Lines Dictate Surface Pressure
  * *画面*：三维轿车尾部流场 CFD 云图，带精准物理标线与引线标注。
  * *论点*：标明 A 柱分离涡、车顶过渡区逆压梯度点、以及 C 柱下洗涡，解释压差阻力（Form Drag）的物理成因。

* **Page 4（Data-driven 专业图表型）**：
  * *标题*：The Cubic Power Law of Aerodynamics
  * *画面*：阻力 $F_D = \frac{1}{2}\rho v^2 C_D A$ 与功率 $P \propto v^3$ 曲线，标注 80 / 100 / 120 / 140 km/h 耗能阶跃。
  * *论点*：为什么车速每提升 20%，能耗需求激增接近 50%？

* **Page 5（Comparison 同构对比型）**：
  * *标题*：Three Archetypes: Notchback, Fastback, and Squareback
  * *画面*：相同比例三视点：三厢车（阶背）、溜背轿跑（快背）、两厢车（平头两厢）的尾流对比。
  * *论点*：不同的分离线拓扑结构对阻力敏感度与乘员后排头部空间的系统工程折中。
