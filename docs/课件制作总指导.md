# 课件制作总指导（v4 生产闭环版）

**三条硬规则**

1. `slides.md` 是观众视图，屏幕上出现什么，文件里就写什么。口播、时长、导播提示、动画切口一律不进这个文件。
2. 动画不嵌入幻灯片。视频是独立文件，由 `RemotionStudio` 合成或录屏后人工对位。
3. 所有生成物进 `build/<slug>/`。工程不互相写目录，产物路径由契约定义。

调用生成器时使用的技能名是 `tech-course-deck-studio-v3`（旧名 `tech-course-slide-generator` 已废弃）。

---

## 零、分层与生产闭环

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 内容层 | `lessons/<slug>/` | `slides.md`、`lecture_notes.md`、`lesson.yaml`、`storyboard.yaml`、`assets/` |
| 展示层 | `CourseSlides/` | 读取课程内容，输出 Reveal 页面 |
| 动画层 | `MotionStudio/`、`ManimSandbox/`、`BlenderStudio/` | 各自产出独立视频 |
| 合成层 | `RemotionStudio/` | 按 `shots.json` 合成最终视频 |
| 控制层 | `CourseControl/` | 校验、调度、收集、报告 |
| 共享层 | `shared/` | JSON Schema、设计令牌 |
| 产物层 | `build/<slug>/` | 截图、成片、时间线、日志、报告 |

```text
lessons/ → validate → capture_slides → render:* → collect → compose → verify
                                                       │
                                                       └─ build/<slug>/final/build-report.json
```

课程内容生产仍是四个阶段；自动构建与验收是叠在四阶段之后的闭环。

```text
阶段一  大纲与前提核查        云端
阶段二  分批双文件交付        云端 → 落盘
阶段三  动画脚本（按需）      云端生成 → 本地渲染
阶段四  旁白、录制与剪辑      本地
```

## 一、文件契约

### 1.1 `slides.md`：只给观众看

允许：页标题、英文论点、公式/图表/代码、`.zh-sub` 中文对照。

禁止：`Notes:` 或任何口播稿、时间预算、导播提示（"停 2 秒""指向右侧"）、`[ANIMATION: ...]` 之类的插桩标记、视频标签。

```markdown
## Scaled dot-product attention

<figure><img class="diagram diagram--full" src="/lessons/01-transformer-demo/assets/attention-flow.svg" alt="..."></figure>

<div class="equation">Attention(Q, K, V) = softmax( QK<sup>T</sup> / √d<sub>k</sub> ) V</div>

<div class="zh-sub"><p>每个 token 先投影为 Q、K、V，点积给出相关性，softmax 归一化后对 V 加权求和。除以 √d<sub>k</sub> 控制方差，避免 softmax 过早饱和。</p></div>
```

数学排版：本工程没有 MathJax，**禁止 `$...$` 与 `$$...$$`**。一律用 `.equation` 容器配 `<sub>/<sup>` 与 Unicode 符号。外部生成的 LaTeX 公式需要手工转写。

### 1.2 `lecture_notes.md`：只给讲者看

与 `slides.md` 同目录，平行存在。每页一个块，固定四要素：

```markdown
### Slide 2: Scaled Dot-Product Attention（方差推导与缩放）

- **时长预算**：90 秒
- **动画切入**：第 45 秒切入 Motion Studio 场景 `variance_drift`
- **技术核查**：必须先声明 q_i、k_i 独立同分布且单位方差，再讲方差随维度线性增长；脱离前提就是错的

#### 逐字口播

各位工程师朋友，看屏幕上的公式。这一页解决论文里最精巧的一个工程细节：为什么注意力必须除以根号 dk……
```

规则：

- 编号必须与 `slides.md` 的页序一致，封面算第 1 页；`--` 垂直子页记为 `3b`。
- 「动画切入」写清**引擎 + 场景名 + 秒点**，没有动画就写"无"。
- 「技术核查」写本页最容易讲错的前提，方便讲前自查。
- 逐字稿按 150~180 字/分钟估算，与「时长预算」对得上。

### 1.3 机器契约

`lesson.yaml`：课程元数据、画布、引擎、编排模式、旁白/字幕开关、验收容差。
`storyboard.yaml`：把「动画切入」结构化，声明镜头、页码、引擎、场景、切入秒点。

字段与路径基准见 [数据契约](ARCHITECTURE.md#4-数据契约)。关键点：

- 课程 YAML 由 `CourseControl` 解析；Blender 只接收 JSON 任务。
- 路径按字段登记基准，不按文件统一。
- 所有路径相对、正斜杠、禁止 `..`。

### 1.4 为什么拆成两个文件

提词器、平板、第二块屏幕打开 `lecture_notes.md` 就能讲，主屏按 `F` 全屏只剩幻灯片本身。两边的编辑互不干扰：改台词不会碰排版，改排版不会碰台词。

## 二、四阶段内容生产

### 阶段一：大纲与前提核查（云端）

```text
调用 tech-course-deck-studio-v3，规划一期课件大纲。

【课件主题】（例如：《Attention Is All You Need》单头注意力数学推导与根号缩放）
【预计时长】（例如：6~8 分钟试制切片 / 20 分钟完整课）
【受众群体】（例如：初中级算法工程师 / 流体工程师）
【核心技术重点】
1. （例如：点积方差发散的前提假设）
2. （例如：缩放因子的量纲与方差归一化证明）
3. （例如：Softmax 饱和区的数值稳定性危机）
```

**交付标准**，两样先给全，再动笔：

1. **技术假设与事实前置审查表**：模型宽度、分布假设、因果掩码、自回归解耦边界、数据或论文版本来源。凡是后面推导要用的前提，先在这里钉死。
2. **大纲表**：页码 | 主标题 | 核心命题 | 视觉元素 | 预计时长 | 动画需求（引擎 + 场景名）。

### 阶段二：分批双文件交付（云端）

每批 4~6 页，要求输出**两个互不混杂的文本块**：

```text
大纲已确认，请输出第 [X] 页到第 [Y] 页。分两个独立的块交付。

【文本块 A：slides.md】
1. 只含观众能看到的内容：页标题、英文主内容、.zh-sub 中文对照。
2. 禁止任何 Notes:、口播稿、时长、导播提示、动画标记、<video>。
3. 分页用独占一行的 ---；垂直子页用独占一行的 --。
4. 公式用 .equation + <sub>/<sup> + Unicode，禁止 $...$。
5. 图片用根路径 /lessons/<slug>/assets/xxx.svg。
6. 只用主题里已有的 CSS 类，不写内联样式。

【文本块 B：lecture_notes.md】
1. 按 Slide N 编号，与 A 块页序一一对应。
2. 每页四要素：时长预算、动画切入（引擎 + 场景名 + 秒点）、技术核查、逐字口播。
3. 口播按 150~180 字/分钟，与时长对得上；包含现场设问与到下一页的过渡句。
4. 涉及动画的页面，在动画切入里给出场景名，后续按名索取代码。
```

落盘顺序：`slides.md` 追加 A 块，`lecture_notes.md` 追加 B 块。两个文件都不需要构建，`live-server` 直接读 Markdown。

### 阶段三：动画脚本（按需）

只在 `lecture_notes.md` 里标了动画切入的页面才做，按下面的路由选引擎：

| 看到什么 | 用哪个 | 例子 |
| --- | --- | --- |
| 盒子、箭头、序列、卡片、流程 | Motion Studio | Token 流动、多头拆分、数据管道、因果网络 |
| 坐标轴、投影、曲率、连续变换 | Manim Sandbox | 点积投影、边界层剖面、复变映射、相图 |
| 真实 3D 空间、模型、材质、灯光 | Blender Studio | 设备结构、空间关系、三维示意 |

Motion Canvas 请求：

```text
请为 Slide 2 的《variance_drift》生成 Motion Canvas 独立脚本。
要求：麦肯锡橙白配色（白底 #FFFFFF、主文 #1A1A1A、强调 #EB6100），1920×1080，时长 10 秒。
场景存入 src/scenes/<slug>/variance_drift.tsx，并注册进 src/project.ts。
```

Manim 请求：

```text
请为 Slide 5 的《projection_geometry》生成 Manim 独立脚本，10~15 秒，2D。
场景存入 <slug>/projection_geometry.py，类名 PascalCase，白底橙黑配色。
```

Blender 请求：

```text
请为 Slide 8 的《device_layout》生成 Blender 后台渲染任务。
场景存入 BlenderStudio/scenes/<slug>/device_layout.blend，
任务写入 BlenderStudio/tasks/<slug>/device_layout.json，
输出 1920×1080、30fps、5~15 秒，产物写 build/<slug>/blender/。
```

### 阶段四：旁白、录制与剪辑（本地）

1. **旁白（可选）**：用 `<AI_ROOT>\VoxCPM-Runtime`（VoxCPM2）按 `lecture_notes.md` 的逐字稿合成 WAV，放入 `build/<slug>/narration/`，并在 `lesson.yaml` 打开 `narration.enabled`。
2. **录制（可选）**：主屏浏览器打开 `http://localhost:8081/?lesson=<slug>`，按 `F` 全屏；副屏或平板打开 `lecture_notes.md` 当提词器；关闭系统通知。
3. **合成或剪辑**：优先运行 `.\scripts\build-lesson.ps1 -Lesson <slug>`，由 Remotion 按 `shots.json` 合成；也可以保留人工录屏 + 剪辑流程，把引擎成片作为插片。

动画先出高清版再进合成：Motion Studio 用 1.0x 缩放导出，Manim 由控制层按 1920×1080 / 30fps 渲染，Blender 任务显式写分辨率与帧率。

## 三、动画执行

### 3.1 Motion Studio

```powershell
cd CourseWorkspace\MotionStudio
npm run serve        # http://localhost:5173，时间轴预览
```

编辑器右下角 **RENDER** 导出。用于构建时，请导出到：

```text
build/<slug>/animation/<scene-stem>.mp4
```

例如 `src/scenes/01-shell-for-ai-era/gui_vs_cli_paths.tsx` →
`build/01-shell-for-ai-era/animation/gui_vs_cli_paths.mp4`。

新增场景要同时改两处：`src/scenes/<slug>/<scene>.tsx` 和 `src/project.ts` 的 `scenes` 数组。

Motion Canvas 3.17.2 没有 CLI 渲染入口，R4/R5 采用人工导出基线；未导出时构建状态为 `skipped`，最终 `incomplete`。见 [DECISIONS.md](DECISIONS.md) D-004。

### 3.2 Manim Sandbox

```powershell
cd CourseWorkspace\ManimSandbox
uv run manim -pql <slug>/<scene>.py <SceneClass>   # 预览
uv run manim -r 1920,1080 --fps 30 <slug>/<scene>.py <SceneClass>   # 构建画质
```

控制层会传：

```text
--media_dir build/<slug>/tmp/manim-media
```

渲染完成后复制到 `build/<slug>/animation/<scene-stem>.mp4`。不要依赖 `ManimSandbox/media/` 作为构建产物。

### 3.3 Blender Studio

```powershell
.\scripts\blender-render.ps1 -Lesson <slug> `
  -Task BlenderStudio/tasks/<slug>/<shot>.json
```

- 可执行文件固定在 `config/tools.yaml`，不在 PATH。
- 默认引擎 `BLENDER_EEVEE`；`CYCLES` 仅显式选择。
- 任务文件为 JSON；Blender 内置 Python 不依赖 PyYAML。
- 产物只写 `build/<slug>/blender/`。

### 3.4 配色与时长

三个引擎共用一套令牌：白底 `#FFFFFF`、主文 `#1A1A1A`、次要 `#595959`、强调 `#EB6100`、分隔 `#E5E5E5`。屏上只出现英文；单个机制 5~15 秒，超过 20 秒先拆场景。

## 四、旁白与字幕

### 4.1 旁白

旁白是可选输入。推荐流程：

1. 从 `lecture_notes.md` 按页提取逐字稿。
2. 调用 `<AI_ROOT>\VoxCPM-Runtime`（VoxCPM2）合成 WAV（零样本克隆；无预置音色）。
3. 放到 `build/<slug>/narration/<file>.wav`。
4. 在 `lesson.yaml` 设置：

```yaml
narration:
  enabled: true
  source: narration.wav
```

构建时 `collect` 会探测音频时长并写入 `shots.json`，Remotion 负责混音，`verify` 用 V-15 检查音画时长差 ≤ 0.5 秒。

母带建议另行备份到 `assets/audio/<slug>/` 或外部存储；`build/` 不入库。

### 4.2 字幕

字幕是可选输入，不做自动语音识别：

1. 把 SRT 放到 `lessons/<slug>/subtitles.srt`。
2. 在 `lesson.yaml` 设置 `subtitles.enabled: true` 和 `content.subtitles: subtitles.srt`。
3. 构建时复制到 `build/<slug>/subtitles.srt`，Remotion 读取并渲染，V-16 检查 cue 数。

### 4.3 服务地址

- VoxCPM2：`http://127.0.0.1:50000`，CPU-only，唯一实例；必须提供参考音，没有预置音色。
- 本地大模型：`http://127.0.0.1:8080/v1`。
- 详细模型、音色与接口见 [本地模型与配音工作流](本地模型与配音工作流.md)。

## 五、自动构建与验收

### 5.1 命令

```powershell
# 全量构建
.\scripts\build-lesson.ps1 -Lesson <slug>

# 夹具
.\scripts\build-lesson.ps1 -Lesson lesson-smoke `
  -LessonDir CourseControl/tests/fixtures

# 分阶段跳过
.\scripts\build-lesson.ps1 -Lesson <slug> -SkipRender
.\scripts\build-lesson.ps1 -Lesson <slug> -SkipCompose

# 只校验契约 / 只校验产物
uv run --project CourseControl course-control validate --lesson <slug>
uv run --project CourseControl course-control verify --lesson <slug>
```

### 5.2 阶段

| 阶段 | 何时执行 | 产物 |
| --- | --- | --- |
| `validate` | 总是 | 契约校验结果 |
| `capture_slides` | `compose.mode=deck` | `build/<slug>/slides/` |
| `render:motion_canvas` | 使用 Motion Canvas | 人工导出文件校验 |
| `render:manim` | 使用 Manim | `build/<slug>/animation/` |
| `render:blender` | 使用 Blender | `build/<slug>/blender/` |
| `collect` | 上游通过 | `build/<slug>/shots.json` |
| `compose` | 上游通过 | `final/course-video.mp4` |
| `verify` | 合成通过 | `checks[]`、`build-report.json` |

### 5.3 状态

`pass` / `fail` / `skipped` / `not_run` / `not_applicable`。

- 未使用的引擎 → `not_applicable`
- 人工导出缺失、CLI 跳过 → `skipped` / `not_run`
- 任一阶段失败 → `fail`，下游 `not_run`
- 只有全部必需阶段为 `pass` 才是 `pass`；否则 `incomplete`

**不得把 `incomplete` 当成 `pass`。** 报告在 `build/<slug>/final/build-report.json`，日志在 `build/<slug>/logs/`。

### 5.4 验收

核心检查：文件存在、路径合法、分辨率/帧率一致、时间线连续、成片时长、音画同步、字幕、报告一致性、适用性。完整定义见 [验收文档](ACCEPTANCE.md)。

## 六、本地模型

本机实际路径不写入仓库；`<AI_ROOT>` 的值见本地 `config/local-paths.yaml`（已忽略）。

本地模型是外部内容生产节点，不参与控制执行与验收判定；构建只消费已审核落盘的文件。

本地大模型用于单页润色、参数微调与离线检查；不替代云端的事实核对与推导。

```powershell
<AI_ROOT>\start_server.bat
# 后端回车默认 SYCL → 模型 [3] Qwen3-30B-A3B-Instruct-2507 → 档位 [3] 16K
```

| 项目 | 值 |
| --- | --- |
| 接口 | `http://127.0.0.1:8080/v1/chat/completions`，OpenAI 兼容，别名 `default` |
| 上下文 | 16384（可切换档位） |
| 硬件 | Intel Arc A750 8 GB（SYCL0），48 层 MoE 专家放 CPU |
| 模型目录 | `<AI_ROOT>\models\` |

**可以交给它**：单页措辞润色、中英语气调整、动画时长与坐标参数、`<div class="zh-sub">` 闭合检查、单页口播改写。

**不要交给它**：整份 `slides.md` 重构（16K 上下文会丢分页符）、从零写 Motion/Manim/Blender 脚本（会编 API）、数学推导与论文细节（会一本正经地错）。

分工：阶段 1–2 在云端（事实核对、大纲、推导、骨架），阶段 3 在本地环境（落盘、渲染、抽帧验收），阶段 4 用本地模型与 VoxCPM2 做局部微调和旁白。

端口约定：`8080` 固定留给本地模型；`8081` 课件预览；`50000` VoxCPM2；`3000` Remotion Studio；`5173` Motion Studio。

## 八、验收清单

**`slides.md`**

- [ ] 全文件搜不到 `Notes:`、时长、"停 2 秒" 这类文字。
- [ ] 每页（封面除外）都有英文主内容与 `.zh-sub`。
- [ ] 分页符独立成行，没有空页。
- [ ] 图片路径都是 `/lessons/<slug>/assets/...`。
- [ ] 没有裸露的 `$`，公式都在 `.equation` 里。
- [ ] 1280×720 与 1600×900 下逐页翻看，无裁切。

**`lecture_notes.md`**

- [ ] 页数与 `slides.md` 一致，编号对得上（含 `3b` 这类子页）。
- [ ] 每页都有时长预算、动画切入、技术核查、逐字口播。
- [ ] 所有动画场景名都能在动画仓里找到同名文件。
- [ ] 技术核查里的前提，与正文推导用的是同一套假设。

**动画与构建**

- [ ] 白底、橙黑配色，屏上只有英文。
- [ ] 输出的是高清成片，不是预览档。

## 九、常见问题

- **生成器把口播塞进了 `slides.md`**：退回重发，明确"文本块 A 禁止任何 Notes 与时长"。
- **公式原样显示**：用了 `$...$`。本工程没有 MathJax，改成 `.equation`。
- **Motion Studio 起不来，报 `motionCanvas is not a function`**：`package.json` 不能有 `"type": "module"`，`vite` 必须 4.x。
- **tsc 报找不到 `Callback`**：缺 `src/motion-canvas.d.ts`。
- **Manim 里中文变方块**：屏上只写英文。
- **Manim 产物是 480p**：构建时不能只用 `-ql`；控制层使用 `-r 1920,1080 --fps 30`。
- **Blender 报 `enum "FFMPEG" not found`**：Blender 5.2 必须先设 `image_settings.media_type = "VIDEO"`。
- **构建 `incomplete`**：检查 Motion 人工导出是否缺失；这是预期状态，不是通过。
- **Remotion 读不到 `build/` 文件**：必须先 staging；直接绝对路径会被 Chromium 拒绝。
- **`start_server.bat` 报端口占用**：8080 被其他进程占用；用 `netstat -ano | findstr :8080` 排查。
- **VoxCPM2 起不来**：50000 端口同一时刻只能有一个实例；`loading` 超过 120 秒查日志与内存。
- **不知道动画用哪个引擎**：盒子箭头用 Motion，坐标轴曲率用 Manim，真实 3D 用 Blender；拿不准选 Motion。

## R1 增量：英文口播、时长与双语字幕（2026-11-07）

1. **口播语言**：默认英文。`lecture_notes.md` 的四个中文小标题保留，`逐字口播` 正文为英文；英文稿必须与 `narration.script.json` 的 segment 拼接结果一致。
2. **情绪提示**：只写在 `narration.script.json` 的 `style` 字段，如 `(warm, measured pace)`；不得进入讲稿正文或字幕。
3. **时长**：`lesson.yaml.duration` 声明目标/窗口；`lecture_notes.md` 的 `时长预算` 是计划值，实测旁白后以 `narration.meta.json` 为准；不得用重复或停顿凑时长。
4. **字幕**：英文在上、简体中文在下；先出计划版草稿供审阅，跑完旁白后必须用实测版重排。
5. **动画**：内容决定引擎；Manim 负责数学/二维结构，Blender 负责三维，Remotion 负责编排/字幕/合成，Motion Canvas 只保留既有资产。
6. **批准门**：AI 草稿写入 `build/<slug>/authoring/candidates/`，人工 `author-accept` 后才进入 `lessons/<slug>/`。
