# 课程视觉风格指南（v0.1）

适用于 Manim / Remotion / Web 镜头。目标不是“好看”，而是**同一门课看起来像一个系统**。

## 1. 色板

| 角色 | Hex | 用途 |
| --- | --- | --- |
| Ink | `#14213D` | 主文字、车身剪影 |
| Muted | `#5C677D` | 次要文字、辅助线 |
| Accent | `#0077B6` | 主强调、流线、公式 |
| Warm | `#E76F51` | 压力/阻力/警示 |
| Green | `#2A9D8F` | 恢复/通过/正向 |
| Paper | `#FFFFFF` | 背景（当前课程） |
| Dark | `#0B1220` | 深色镜头背景（可选） |

每门课最多一个 accent + 一个 warm；不要每页换色。

## 2. 字体与字号（1920×1080）

| 层级 | 字号 | 字重 |
| --- | --- | --- |
| 镜头标题 | 46–56 | 600/700 |
| 页面标题 | 56–72 | 700 |
| 正文 | 30–36 | 400/500 |
| 注释/标签 | 24–28 | 400 |
| 角标/来源 | 18–22 | 400 |

- 英文：Arial / Inter / 系统无衬线。
- 中文：Microsoft YaHei / Noto Sans SC。
- 正文不得小于 24 px；标题不得小于 56 px（成片 1080p）。

## 3. 版式

- 安全边距 ≥ 96 px。
- 每页只保留**一个主张**；项目符号不超过 5 条。
- 公式居中，变量用斜体；单位用正体。
- 图表必须有轴标签/单位；无来源的数据不上屏。
- 参考页放最后，最多 4–6 条；完整列表放描述/`references.md`。

## 4. Manim 约定

- `config.background_color = "#FFFFFF"`（当前课程）。
- 线宽：主结构 3–4，辅助 2，网格 1。
- 动画：`Create`/`FadeIn`/`Transform`；同一镜头不超过 3 种转场。
- 字幕/标签不要压在运动物体上；先留白，再出现。
- 单镜头 8–12 秒；超过 15 秒必须有第二次视觉变化。

## 5. 合成

- `deck` 模式：幻灯片 + 镜头插入；当前课程使用。
- 目标 `scene` 模式：全屏镜头，幻灯片只做章节卡/数据页/参考页。
- 字幕：英上中下；底部安全区 ≥ 64 px；不与主体重叠。
- 音乐：-28 到 -22 LUFS，人声出现时 duck 6–10 dB；无音乐时不要用音效填满。

## 6. QC

- 完整播放成片，按时间点记录问题；自动化只做黑帧/定格、响度/真峰值等技术检测。
- 检查：文字裁切/重叠、字号、对比度、字幕遮挡、镜头节奏。
- 时长以实测旁白为准；页面预算只作计划。
- 缺证据写 `blocked`/`not_run`，不写 pass。
