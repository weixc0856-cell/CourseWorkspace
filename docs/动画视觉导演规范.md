# 动画视觉导演规范（v0.1）

- **目标**：动画不是“让元素动起来”，而是用空间、连续性和镜头完成教学解释。
- **结论**：不再扩充工具链。缺的是 **视觉导演层**：设计意图、镜头、构图、运动语法、连续性、验收标准；Manim/Blender/Remotion 只在设计确定后执行。

## 1. 参考模式

| 模式 | 代表 | 可借鉴 | 不照搬 |
| --- | --- | --- | --- |
| 数学直觉 | 3Blue1Brown | 一个概念一个连续变换；标签后置；保留对象身份 | 不复制具体镜头 |
| 算法执行 | Reducible | 状态机逐步推进；每一步可追踪 | 不做冗长代码朗读 |
| 模拟系统 | Primer | 规则/粒子/统计状态 | 不把课程都做成模拟 |
| 工程实拍 | Sebastian Lague | 实时反馈、参数探索 | 不追求炫技 |

本项目当前只验证 **数学直觉 + 工程图解**；模拟/三维后置。

## 2. 视觉导演层

每个镜头先写 `AnimationDirection`，再写渲染代码：

```json
{
  "shot_id": "s3_addition",
  "start_s": 28,
  "end_s": 52,
  "learning_intent": "Addition is placing b's tail at a's tip.",
  "visual_metaphor": "A pencil travels to the first tip; the resultant closes the triangle.",
  "composition": "Triangle grows right; formula in lower-right negative space.",
  "focus": "The moving tail, then the green resultant.",
  "camera": "Pan right and widen slightly.",
  "motion": ["draw b", "translate b copy", "draw parallelogram ghost", "draw resultant"],
  "continuity": "a stays fixed; same grid/origin.",
  "on_screen_text": ["a+b=(4,5)"],
  "reference": "3Blue1Brown vector series",
  "acceptance": ["no arrow-label overlap", "formula clear of axes"]
}
```

校验：`uv run --project CourseControl course-control direction-validate --spec direction.json`。
Schema：`shared/schemas/animation-direction.schema.json`。

## 3. 动画语法

允许的原语，不要每次从零发明：

| 原语 | 用途 | 约束 |
| --- | --- | --- |
| draw / grow | 对象首次出现 | 从起点到终点，不用随机 |
| trace | 展示路径/投影/分量 | 虚线辅助，保持低对比 |
| transform | 保持对象身份的连续变化 | 不用淡入替换冒充变换 |
| camera push / pan | 引导注意 | 一镜最多一次主运动 |
| hold | 让观众读结果 | 只在“结果”后，不在每个动作后 |
| highlight | 当前变量/关系 | 一次只强调一个 |

禁止：每个元素都发光、每个镜头都缩放、无意义粒子/装饰、用淡入替代变换。

## 4. 构图与节奏

- 一个镜头一个视觉中心；公式放在负空间，不压主体。
- 网格/坐标是背景，不是主角；对比度低于主体。
- 标签不压箭头；公式不与轴线/箭头重叠。
- 镜头运动服务注意力：push-in 用于聚焦，pan 用于跟随，pull-back 用于收束。
- 90 秒竖切片允许 4–5 个镜头；每个镜头 8–25 秒；不要塞 20 个知识点。

## 5. 角色与验收

| 角色 | 本项目落点 |
| --- | --- |
| 视觉导演 | `AnimationDirection` + 本规范 |
| 分镜师 | shot 的 start/end、composition、focus |
| 摄影 | camera 字段；Manim `MovingCameraScene` / Blender camera |
| 动效 | motion 原语；Manim `Transform`/`Create` |
| 科学可视化 | Manim/Matplotlib；公式走 FormulaSpec |
| 艺术指导 | 看完整成片（必要时定位单帧）：构图、层次、节奏、一致性、克制 |

两道门：
1. **设计门**：direction 校验通过，镜头意图/参考/验收齐全，才写代码。
2. **视觉门**：完整看成片，检查构图、标签、公式、连续性与节奏；必要时按时间点定位单帧；不能只看渲染成功。
