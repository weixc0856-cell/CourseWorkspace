# 本地 3D 资产库

- **日期**：2026-11-14
- **位置**：`<内容根>/assets/3d/`
- **索引**：`<内容根>/assets/3d/library.json`
- **查询**：`uv run --project CourseControl python scripts/asset_library.py`
- **原则**：**能用现成模型/材质/HDRI，就不自己建；能复制，就不重复造轮子。**

## 1. 目录

```text
<内容根>/assets/3d/
├── library.json          # 检索索引：id / kind / license / path / tags / dimensions
├── LICENSES.md           # 来源、许可、署名、下载日期
├── hdri/                 # .hdr / .exr 天空与环境光
├── models/               # glTF / FBX / .blend 模型
│   └── <asset_id>/
└── textures/             # PBR 贴图组（diffuse / normal / roughness / displacement / arm）
    └── <asset_id>/
```

资产文件不进仓库；仓库只保留 `scripts/asset_library.py` 与文档。换机器时资产需要重新同步或从备份恢复，`library.json` 可以直接复用。

## 2. library.json

每条资产至少记录：

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一 id，例如 `model.rock_07` |
| `name` | 可读名称 |
| `kind` | `model` / `texture` / `hdri` |
| `source` / `source_url` | 来源与页面 |
| `license` | 例如 `CC0-1.0` |
| `path` | 相对 `assets/3d/` 的路径 |
| `format` / `resolution` | glTF/FBX/blend；1k/2k/4k/8k |
| `dimensions_m` | 模型包围盒（米），用于 Blender 放置 |
| `polycount` | 面数，用于 8 GB GPU 预算 |
| `tags` | 检索标签：rock / terrain / grass / sky / background |
| `used_in` | 已用在哪一集/实验 |

## 3. 查询

```powershell
# 所有岩石类资产
uv run --project CourseControl python scripts/asset_library.py --tag rock

# 只要模型，输出 JSON
uv run --project CourseControl python scripts/asset_library.py --kind model --json

# 搜索名称/标签
uv run --project CourseControl python scripts/asset_library.py --query mountain

# 检查每条 path 是否存在
uv run --project CourseControl python scripts/asset_library.py --check
```

`--check` 失败时输出缺失清单，不重新下载；先确认是路径变了还是文件被删。

## 4. 新增资产

1. 下载到 `assets/3d/{models,textures,hdri}/<asset_id>/`。
2. 在 `library.json` 增加条目：id、来源、许可、path、尺寸、面数、tags、used_in。
3. 在 `LICENSES.md` 登记来源与许可。
4. 跑 `asset_library.py --check`。
5. 在 Blender 里用 glTF/HDRI/PBR 导入；先用单帧 hero frame 验证，再进动画。

## 5. Blender 用法

- **模型**：`bpy.ops.import_scene.gltf(filepath=...)`；Poly Haven 模型单位是米，直接按 `dimensions_m` 放置。
- **HDRI**：World → Environment Texture → `hdri/*.hdr`；强度先 1.0，再按画面调。
- **PBR 地形**：大 grid + Displace（displacement 贴图） + Diffuse/Normal/Roughness 贴图；贴图用 UV 或 Box 投影，注意平铺尺度。
- **放置**：用 `scene.ray_cast` 从上方打到地形，取表面 z，避免石块/草漂浮。
- **渲染**：写实用 Cycles 64–128 samples + denoise；预览可用 EEVEE。8 GB A750 优先 2K 贴图、实例化、限制 bounces。
- **后期**：Blender Compositor 或 DaVinci；先做 hero frame，再扩 12 s。

## 6. 与 Scene IR 的关系

- **Scene IR v2** 适合科学示意、剖面、流程图、简单几何；不适合写真山谷。
- **写真 3D 场景**用“资产库 + Blender 场景脚本/.blend”，Scene IR 只做装配记录与镜头参数，不用表达式生成主地形。
- 两条路都通过现有 `blender-render.ps1` / 预览/发布流程接入，不新建第二套渲染系统。
