# 本地 3D 资产库

- **日期**：2026-11-14
- **位置**：`<内容根>/assets/3d/`
- **索引**：`<内容根>/assets/3d/library.json`
- **查询**：`uv run --project CourseControl python scripts/asset_library.py`
- **原则**：**能用现成模型/材质/HDRI，就不自己建；能复制，就不重复造轮子。**

## 1. 目录

```text
<内容根>/assets/3d/
├── library.json          # 检索索引：id / kind / license / path / tags / dimensions
├── LICENSES.md           # 来源、许可、署名、下载日期
├── hdri/                 # .hdr / .exr 天空与环境光
├── models/               # glTF / FBX / .blend 模型
│   └── <asset_id>/
└── textures/             # PBR 贴图组（diffuse / normal / roughness / displacement / arm）
    └── <asset_id>/
```

资产文件不进仓库；仓库只保留 `scripts/asset_library.py` 与文档。换机器时资产需要重新同步或从备份恢复，`library.json` 可以直接复用。

## 2. library.json

每条资产至少记录：

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一 id，例如 `model.rock_07` |
| `name` | 可读名称 |
| `kind` | `model` / `texture` / `hdri` |
| `source` / `source_url` | 来源与页面 |
| `license` | 例如 `CC0-1.0` |
| `path` | 相对 `assets/3d/` 的路径 |
| `format` / `resolution` | glTF/FBX/blend；1k/2k/4k/8k |
| `dimensions_m` | 模型包围盒（米），用于 Blender 放置 |
| `polycount` | 面数，用于 8 GB GPU 预算 |
| `tags` | 检索标签：rock / terrain / grass / sky / background |
| `used_in` | 已用在哪一集/实验 |
| `version` | 资产版本，默认 1 |
| `quality_level` | `proxy` / `standard` / `hero`，用于预算而不是门禁 |
| `dependencies` | 依赖的其他资产 id；空数组表示无 |
| `preview` | 可选缩略图路径；没有就省略 |

## 3. 查询

```powershell
# 所有岩石类资产
uv run --project CourseControl python scripts/asset_library.py --tag rock

# 只要模型，输出 JSON
uv run --project CourseControl python scripts/asset_library.py --kind model --json

# 搜索名称/标签
uv run --project CourseControl python scripts/asset_library.py --query mountain

# 只要 hero 档
uv run --project CourseControl python scripts/asset_library.py --quality hero

# 检查每条 path、依赖和 preview 是否存在
uv run --project CourseControl python scripts/asset_library.py --check
```

`--check` 失败时输出缺失清单，不重新下载；先确认是路径变了还是文件被删。

## 4. 新增资产

1. 下载到 `assets/3d/{models,textures,hdri}/<asset_id>/`。
2. 在 `library.json` 增加条目：id、来源、许可、path、尺寸、面数、tags、used_in。
3. 在 `LICENSES.md` 登记来源与许可。
4. 跑 `asset_library.py --check`。
5. 在 Blender 里用 glTF/HDRI/PBR 导入；先用单帧 hero frame 验证，再进动画。

## 5. Blender 用法

- **模型**：`bpy.ops.import_scene.gltf(filepath=...)`；Poly Haven 模型单位是米，直接按 `dimensions_m` 放置。
- **HDRI**：World → Environment Texture → `hdri/*.hdr`；强度先 1.0，再按画面调。
- **PBR 地形**：大 grid + Displace（displacement 贴图） + Diffuse/Normal/Roughness 贴图；贴图用 UV 或 Box 投影，注意平铺尺度。
- **放置**：用 `scene.ray_cast` 从上方打到地形，取表面 z，避免石块/草漂浮。
- **渲染**：写实用 Cycles 64–128 samples + denoise；预览可用 EEVEE。8 GB A750 优先 2K 贴图、实例化、限制 bounces。
- **后期**：Blender Compositor 或 DaVinci；先做 hero frame，再扩 12 s。

## 6. 与 Scene IR 的关系

- **Scene IR v2** 适合科学示意、剖面、流程图、简单几何；不适合写真山谷。
- **写真 3D 场景**用“资产库 + Blender 场景脚本/.blend”，Scene IR 只做装配记录与镜头参数，不用表达式生成主地形。
- 两条路都通过现有 `blender-render.ps1` / 预览/发布流程接入，不新建第二套渲染系统。

## 7. 环境 / 镜头（排列组合层）

资产库只解决“有什么”；环境解决“这个地点长什么样”，镜头解决“怎么拍”。

```text
Level 1  assets/3d/library.json
Level 2  assets/3d/kits/<series>/environments/<place>.json
Level 3  assets/3d/kits/<series>/shots/<shot>.json
```

环境 spec 字段：

| 字段 | 含义 |
| --- | --- |
| `kind` | 固定为 `environment` |
| `id` | 环境 id，例如 `fengshui.ridge` |
| `asset_root` | 资产根目录（通常 `<内容根>/assets/3d`） |
| `hdri` | library.json 里的 HDRI id |
| `world_strength` | 环境光强度 |
| `terrain` | heightmap id/path、网格大小、细分、位移高度、PBR 材质 id、UV 平铺 |
| `objects` | 布景资产 id、x/y、scale、rotation、是否贴地 |
| `atmosphere` | 体积雾：size、location、density、color、anisotropy |
| `water` | 水面：size、location/z、颜色、粗糙度、透射、bump |
| `lights` | 三点光列表：`sun` / `rim` / `fill`，各含 location、target、energy、color |
| `camera` | 默认机位（可被 shot 覆盖） |
| `render` | 默认渲染参数（可被 shot 覆盖） |
| `visual_grammar` | 风格 preset，写成 `id@version`，例如 `cinematic_realism@1.0` |

镜头 spec 字段：

| 字段 | 含义 |
| --- | --- |
| `kind` | 固定为 `shot` |
| `environment` | 相对路径指向 environment spec |
| `camera` | `template` + 参数，或显式 `keyframes` |
| `render` | `profile`（blockout/preview/hero）、engine、samples、resolution、frames、fps、output、passes |
| `duration_s` | 声明时长；与 frames/fps 不一致时给 warning，不是硬门禁 |
| `visual_grammar` | 可选；覆盖 environment 的风格 preset |
| `objects` / `lights` / `water` | 可选；只在镜头需要局部覆盖时使用 |

构建：

```powershell
# 校验（资产存在、相机参数完整、pass 词汇合法）
uv run --project CourseControl course-control asset-scene-validate `
  --spec <content_root>/assets/3d/kits/fengshui/shots/a1.json --json

# blockout / preview / hero
blender --background --factory-startup `
  --python scripts/build_asset_scene.py -- `
  --spec <content_root>/assets/3d/kits/fengshui/shots/a1.json `
  --profile blockout

# 构建可复用 environment .blend
... --build environment

# 构建链接 environment 的 shot .blend 并渲染
... --build shot

# 指定 manifest 目录；默认写到输出目录的 manifests/
... --manifest-dir <content_root>/.../a/p0/manifests

# 强制重建（忽略缓存）
... --no-cache

# 生成 Review Package（首/中/尾帧、contact sheet、480p 预览、QC）
uv run --project CourseControl course-control shot-review `
  --shot a1 --video <shot>.mp4 --manifest-dir <manifests> --out <review/a1>

# 只出一帧检查构图
blender --background --factory-startup `
  --python scripts/build_asset_scene.py -- `
  --spec <content_root>/assets/3d/kits/fengshui/shots/a1.json `
  --profile blockout --frames 1 --out <content_root>/.../check.png
```

`--recipe` 仍然兼容旧的单文件场景配方；新场景优先写 environment + shot。

**原则**：spec 只引用 library.json 里的资产，不在 spec 里造模型、写几何表达式。要新模型就先进资产库。AI 只写 JSON，不逐镜头写 Blender Python。

**相机模板**：`static_hold`、`dolly_in`、`dolly_out`、`pan`、`tilt`、`crane`、`orbit`、`tracking`、`parallax`。默认 hold → 匀速 → hold；也可写显式 `keyframes` 和逐帧 `easing`。

**构建证据**：每次构建写 `manifests/<shot>-<build-id>.json` 与 `.log`，记录输入哈希、版本、render 参数与状态；相同输入默认命中缓存，打印 `ASSET_SCENE_CACHED`。详见 `docs/v2/生产管线v0.2-P0交付记录.md`。

**渲染 passes**：`render.passes` 可选 `beauty/ao/depth/mist/normal/emission/cryptomatte`，输出 multilayer EXR 到 `render.pass_dir`（默认输出目录下 `passes/`）。预览仍是 H.264。

**契约**：`shared/scene-specs/` 下的 JSON Schema 与 `capabilities.json`；`docs/3D动画生产流程.md` §2.1。
