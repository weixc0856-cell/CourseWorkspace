## 3. 与视频形态的匹配

| 视频形态 | 推荐 | 不推荐 |
| --- | --- | --- |
| 浅色技术课程（排版 / Manim / 模拟讲解） | Serenity 或 Schubert，低音量 + ducking | Mozart K.525 / K.330：主题太熟、会抢注意力 |
| 技术原理长段（Transformer、CFD） | Schubert D.664；需要更“电子”时留白或另购授权 ambient | Grieg：情绪推进过强 |
| 纪录片/观点长片（Primer 式） | 现有库不合适；保持静音或另行授权 sparse ambient / pulse | 古典与民谣吉他与冷色模拟世界不匹配 |
| 30 秒模拟 POC | 无 BGM，或 Serenity 极低音量 | 不要用《晨曲》这类有明显旋律弧线的曲子 |
| 课程高潮/结论 | **We Never (Instrumental)**；可短暂抬起，不必全程铺 | 不要在长段推导下持续播放 |

## 4. 授权与署名

- Public domain：无需署名；发布说明仍建议注明演奏者/来源。
- CC BY 3.0 US 必须随片署名：
  - `GREEN LEAVES by Jason Shaw (audionautix.com), CC BY 3.0 US`
  - `SERENITY by Jason Shaw (audionautix.com), CC BY 3.0 US`
- `We Never (Instrumental) — ZHENLOE`：来源与许可未核实，**不得标为 CC0/PD**；2026-11-08 项目所有者明确授权用于课程高潮段。商用/公开发布前必须补来源与授权证据（manifest `commercial_allowed=false`）。
- 不抽取电影/动画原声；商业影片配乐不在可用范围。

## 5. 混音参数（试混，不是固定规范）

- 旁白优先；BGM 先压到人声之下，再用 sidechain 做 6–8 dB 闪避；
- Serenity 本身较响，试混用 `volume=-21dB`；Schubert 用 `-16dB`；
- 最终 `loudnorm=I=-16:TP=-1.5:LRA=11`；成片目标 -16 LUFS、TP ≤ -1 dBTP；
- 不写死 EQ；当前只做 70 Hz 高通，避免与人声低频冲突；
- We Never 原始峰值 +1.1 dBFS，试混先 `volume=-24dB` + `alimiter=0.9`，再 sidechain；高潮无人声时可单独抬起。

## 6. 边界

- 本轮只做盘点、试听与两版试混，**没有把 BGM 接进 CourseControl 时间线**；
- 还没有 `AudioPlan`（bed、ducking 点、SFX、静默策略）和授权 manifest 的流水线消费；
- 试听结论需要人工确认；manifest 的 `review_status` 仍是 `ACCEPTED_PENDING_FINAL`。
