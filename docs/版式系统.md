# 版式系统（Layout System）

日期：2026-11-08
代码：`CourseControl/src/course_control/layout/`
命令：`course-control layout-templates` / `layout-validate`

## 1. 定位

版式是导演职责，不是动画完成后的美化。导演在写场景之前先选模板、定区域；引擎只能在这些区域内作画。

三层资产：

1. `DesignSystem`：颜色、字号、安全边距、画布。
2. `LayoutLibrary`：8 个经过校验的页面模板。
3. `LayoutValidator`：安全区、重叠、视觉权重、标题/正文容量、字幕保留带。

## 2. DesignSystem

画布 1920×1080，安全边距 96 px。颜色取值见 [配色规范](配色规范.md)，只保留一个主 accent 和一个 warm：

| 角色 | 值 | 用途 |
| --- | --- | --- |
| background | `#FBFAF7` | 暖白纸面 |
| surface | `#F3F1EA` | 代码/图表底 |
| ink | `#252A31` | 标题、结构线 |
| body | `#2E3338` | 正文 |
| muted | `#6B7280` | 次要标签 |
| accent | `#E8733B` | 品牌重点、当前焦点、attention |
| blue | `#4A82B8` | 输入、query |
| teal | `#42A69A` | 处理、key、target |
| purple | `#7A6FB0` | 输出、value |
| red | `#C75B55` | 误差、loss |
| navy | `#12324A` | 可选强权威标题 |
| divider | `#E3E0D7` | 分隔线 |

颜色语义与对比度见 [配色规范](配色规范.md)。

字号阶（px）：display 60 / heading_1 52 / heading_2 40 / body 30 / label 24 / caption 20。Manim 场景用 `ManimSandbox/common/design_system.py` 中的对应字号，二者保持同一层级。

## 3. 模板库

| id | 内容类型 | 主视觉占画布 | 用途 |
| --- | --- | ---: | --- |
| `title_intro` | title | 20% | 标题引入、核心问题 |
| `two_column` | comparison | 23% | 传统 vs 新方法、优劣 |
| `process_flow` | process | 48% | 流程、系统结构、数据流 |
| `principle_diagram` | principle | 34% | 原理解释、矩阵 |
| `formula_derivation` | formula | 27% | 公式推导 |
| `data_chart` | chart | 34% | 数据图、实验结果 |
| `code_demo` | code | 34% | 代码 + 结果 |
| `summary` | summary | 28% | 总结、结论 |

### 3.1 EVDS 六大视觉表达原型映射 (Educational Visual Design System)

针对汽车空气动力学等工业硬核长线课程，必须按 [docs/教育内容视觉设计体系与视觉叙事规范.md](教育内容视觉设计体系与视觉叙事规范.md) 将页面对齐至六大异构表达原型，杜绝千篇一律的左右机械分栏：

1. **`slide--hero`（大图主导型）**：主视觉占 65%–80%，大留白，极简标题，用于引入核心物理冲突与风洞实景；
2. **`slide--editorial`（图文融合型）**：瑞士国际主义风格，非对称多列网格，图片跨越主体，右侧 `01/02/03` 结构化小标短句；
3. **`slide--annotated`（物理注释型）**：**流体力学课件核心原型**。CFD 表面云图与流线 + 精确物理标引线（驻点、分离线、涡核、死水区）+ 局部细节放大；
4. **`slide--comparison`（同构对比型）**：Baseline vs Modified，锁定完全一致的视角、比例与云图标尺，第一眼看出流动差异；
5. **`slide--process`（流动机理型）**：多阶段连续切片拓扑，水平时间流推进；
6. **`slide--data`（专业图表型）**：经济学人/自然期刊级图表，坐标与量纲严谨，突出三次方定律与工程 Takeaway。

区域用归一化坐标（左下原点）表示，例如 `process_flow`：

```text
title        x .06  y .80  w .88  h .10
main_visual  x .06  y .20  w .88  h .54
caption      x .06  y .09  w .88  h .07
```

字幕保留带固定为底部 8%，任何内容区不得进入。

## 4. 校验规则

`layout-validate` 与导演层共用：

- 所有区域在 96 px 安全边距内；
- 区域之间不重叠；
- 主视觉面积不低于模板下限（`process_flow` 48%、`principle_diagram` 34%）；
- 标题带高度 ≥ 8%；
- 内容不进入字幕保留带；
- 字号阶严格递减；
- 标题/正文容量按区域面积与字号估算，超容量报错；
- 项目符号超过 4 条只告警。

## 5. 导演集成

`ShotPlan` 增加：

- `layout_template`：模板 id；
- `layout_regions`：role → `[x, y, w, h]`。

`director-plan` 按 `visual_kind` / `animation` 选模板：

| 场景 | 模板 |
| --- | --- |
| 标题 | `title_intro` |
| 双栏对比 | `two_column` |
| 流程/三区叙事（cross-attention、loss、residual） | `process_flow` |
| 原理/矩阵 | `principle_diagram` |
| 公式 | `formula_derivation` |
| 图表 | `data_chart` |
| 总结/recap | `summary` |

导出的 direction 文件把模板与区域写进 `style.layout`，引擎按区域排版。导演层新增 `layout.unknown_template`、`layout.overlap`、`layout.visual_area`、`layout.safe_margin`、`layout.title_capacity` 等闸门。

## 6. 第一轮 POC

以 `01-transformer-demo` 的 12 镜头为例，全部获得模板：1 个 `title_intro`、3 个 `process_flow`、5 个 `principle_diagram`、1 个 `data_chart`、2 个 `summary`。

按评审意见重做了两个镜头：

- `CrossAttentionFlowScene`：主体整体放大，编码器/解码器横向铺满 12.4 单位；标题、主体、说明三级分离；说明文字改为 body 色 24 pt；输出 `thanks` 不再贴边。
- `LossBackpropScene`：改为三个连续区域 `01 input + model → 02 prediction → 03 loss`；柱状图与 target 放大；loss 独立成第三区；回传虚线走主视觉下方，不再穿过图形。

前后对比合辑：`build/01-transformer-demo/review/layout-before-after.mp4`（39.9 s）。

新版时长：cross-attention 8.5 s，loss 8.6 s。

## 7. 边界

- 静态校验覆盖区域、容量、安全区；运行时新增 `ManimSandbox/common/scene_checks.py`：检查最终文本是否越出安全区、文本之间是否重叠，并检查所有顶层图形是否越出画面边界。`STRICT_LAYOUT=1` 时直接让渲染失败，默认只打印。
- 已接入 5 个 Transformer 旧镜头（qkv/row_trace/head_split/position/residual）；图形之间的遮挡与字幕保留带仍未自动检测。
- 4 个早期 Manim 插入已统一到纸白底与语义色，导演层不再报 `style.background_mismatch`。
- 区域是归一化设计约束，Manim/Blender/Remotion 各自负责把元素放进区域；没有跨引擎的布局执行器。
- 模板选择目前是规则映射，不是 LLM 自主选择；这样保证可复现。

## 9. 落地取值（2026-11-20 并入自《课程视觉风格指南》）

色板以 [配色规范](配色规范.md) 的 Color Tokens 为唯一源；本文 §2 的 DesignSystem 是其在画布上的角色映射。

### 9.1 字体与字号（1920×1080）

| 层级 | 字号 | 字重 |
| --- | --- | --- |
| 镜头标题 | 46–56 | 600/700 |
| 页面标题 | 56–72 | 700 |
| 正文 | 30–36 | 400/500 |
| 注释/标签 | 24–28 | 400 |
| 角标/来源 | 18–22 | 400 |

- 英文：Arial / Inter / 系统无衬线；中文：Microsoft YaHei / Noto Sans SC。
- 正文不得小于 24 px；标题不得小于 56 px（成片 1080p）。
- **排版加固（2026-11-22 外部 Skill 评审，D-122）**：
  - 标题字距（tracking）-0.02 ~ -0.04 em，字号越大越收紧；两个字母相碰即为过紧，回退。
  - 正文行高 1.5–1.65；标题行高 1.0–1.15。
  - 英文正文每行 45–75 字符（measure）；超宽就分栏或收窄文本区，不靠缩小字号塞满。中文正文行宽按模板区域宽度控制，不逐字换算。
  - 来源：Nutlope/hallmark `references/craft.md` §1、pbakaus/impeccable `skill/reference/typeset.md`。

### 9.2 版式规则

- 安全边距 ≥ 96 px；每页只保留**一个主张**；项目符号不超过 5 条。
- 公式居中，变量用斜体；单位用正体。
- 图表必须有轴标签/单位；无来源的数据不上屏。
- 参考页放最后，最多 4–6 条；完整列表放描述/`references.md`。

### 9.3 Manim 约定

- `config.background_color = "#FBFAF7"`（暖白纸面）。
- 线宽：主结构 3–4，辅助 2，网格 1。
- 动画：`Create`/`FadeIn`/`Transform`；同一镜头不超过 3 种转场。
- 字幕/标签不要压在运动物体上；先留白，再出现。
- 单镜头通常 8–12 秒；超过 15 秒应有第二次视觉变化。这是节奏建议，不是验收条件（D-071）。
- 静帧运镜（Ken Burns / MotionPolicy）见 [动画视觉导演规范](动画视觉导演规范.md) §9。

### 9.4 合成与 QC

- `deck` 模式：幻灯片 + 镜头插入；`scene` 模式：全屏镜头，幻灯片只做章节卡/数据页/参考页。
- 画面文字与旁白英文；字幕英文在上、中文在下；底部安全区 ≥ 64 px；不与主体重叠。
- 音乐 -28 到 -22 LUFS，人声出现时 duck 6–10 dB；无音乐时不要用音效填满。
- 完整播放成片按时间点记录问题；自动化只做黑帧/定格、响度/真峰值等技术检测。
- 时长以实测旁白为准；页面预算只作计划。缺证据写 `blocked`/`not_run`，不写 pass。
