# 版式系统（Layout System）

日期：2026-11-08
代码：`CourseControl/src/course_control/layout/`
命令：`course-control layout-templates` / `layout-validate`

## 1. 定位

版式是导演职责，不是动画完成后的美化。导演在写场景之前先选模板、定区域；引擎只能在这些区域内作画。

三层资产：

1. `DesignSystem`：颜色、字号、安全边距、画布。
2. `LayoutLibrary`：8 个经过校验的页面模板。
3. `LayoutValidator`：安全区、重叠、视觉权重、标题/正文容量、字幕保留带。

## 2. DesignSystem

画布 1920×1080，安全边距 96 px。颜色沿用课程视觉规范，只保留一个主 accent 和一个 warm：

| 角色 | 值 | 用途 |
| --- | --- | --- |
| background | `#FBFAF7` | 暖白纸面 |
| surface | `#F3F1EA` | 代码/图表底 |
| ink | `#252A31` | 标题、结构线 |
| body | `#2E3338` | 正文 |
| muted | `#6B7280` | 次要标签 |
| accent | `#E8733B` | 品牌重点、当前焦点、attention |
| blue | `#4A82B8` | 输入、query |
| teal | `#42A69A` | 处理、key、target |
| purple | `#7A6FB0` | 输出、value |
| red | `#C75B55` | 误差、loss |
| navy | `#12324A` | 可选强权威标题 |
| divider | `#E3E0D7` | 分隔线 |

颜色语义与对比度见 [配色规范](配色规范.md)。

字号阶（px）：display 60 / heading_1 52 / heading_2 40 / body 30 / label 24 / caption 20。Manim 场景用 `ManimSandbox/common/design_system.py` 中的对应字号，二者保持同一层级。

## 3. 模板库

| id | 内容类型 | 主视觉占画布 | 用途 |
| --- | --- | ---: | --- |
| `title_intro` | title | 20% | 标题引入、核心问题 |
| `two_column` | comparison | 23% | 传统 vs 新方法、优劣 |
| `process_flow` | process | 48% | 流程、系统结构、数据流 |
| `principle_diagram` | principle | 34% | 原理解释、矩阵 |
| `formula_derivation` | formula | 27% | 公式推导 |
| `data_chart` | chart | 34% | 数据图、实验结果 |
| `code_demo` | code | 34% | 代码 + 结果 |
| `summary` | summary | 28% | 总结、结论 |

区域用归一化坐标（左下原点）表示，例如 `process_flow`：

```text
title        x .06  y .80  w .88  h .10
main_visual  x .06  y .20  w .88  h .54
caption      x .06  y .09  w .88  h .07
```

字幕保留带固定为底部 8%，任何内容区不得进入。

## 4. 校验规则

`layout-validate` 与导演层共用：

- 所有区域在 96 px 安全边距内；
- 区域之间不重叠；
- 主视觉面积不低于模板下限（`process_flow` 48%、`principle_diagram` 34%）；
- 标题带高度 ≥ 8%；
- 内容不进入字幕保留带；
- 字号阶严格递减；
- 标题/正文容量按区域面积与字号估算，超容量报错；
- 项目符号超过 4 条只告警。

## 5. 导演集成

`ShotPlan` 增加：

- `layout_template`：模板 id；
- `layout_regions`：role → `[x, y, w, h]`。

`director-plan` 按 `visual_kind` / `animation` 选模板：

| 场景 | 模板 |
| --- | --- |
| 标题 | `title_intro` |
| 双栏对比 | `two_column` |
| 流程/三区叙事（cross-attention、loss、residual） | `process_flow` |
| 原理/矩阵 | `principle_diagram` |
| 公式 | `formula_derivation` |
| 图表 | `data_chart` |
| 总结/recap | `summary` |

导出的 direction 文件把模板与区域写进 `style.layout`，引擎按区域排版。导演层新增 `layout.unknown_template`、`layout.overlap`、`layout.visual_area`、`layout.safe_margin`、`layout.title_capacity` 等闸门。

## 6. 第一轮 POC

以 `01-transformer-demo` 的 12 镜头为例，全部获得模板：1 个 `title_intro`、3 个 `process_flow`、5 个 `principle_diagram`、1 个 `data_chart`、2 个 `summary`。

按评审意见重做了两个镜头：

- `CrossAttentionFlowScene`：主体整体放大，编码器/解码器横向铺满 12.4 单位；标题、主体、说明三级分离；说明文字改为 body 色 24 pt；输出 `thanks` 不再贴边。
- `LossBackpropScene`：改为三个连续区域 `01 input + model → 02 prediction → 03 loss`；柱状图与 target 放大；loss 独立成第三区；回传虚线走主视觉下方，不再穿过图形。

前后对比合辑：`build/01-transformer-demo/review/layout-before-after.mp4`（39.9 s）。

新版时长：cross-attention 8.5 s，loss 8.6 s。

## 7. 边界

- 静态校验覆盖区域、容量、安全区；运行时新增 `ManimSandbox/common/scene_checks.py`：检查最终文本是否越出安全区、文本之间是否重叠。`STRICT_LAYOUT=1` 时直接让渲染失败，默认只打印。
- 已接入 5 个 Transformer 旧镜头（qkv/row_trace/head_split/position/residual）；图形与字幕保留带的运行时遮挡仍未自动检测。
- 4 个早期 Manim 插入已统一到纸白底与语义色，导演层不再报 `style.background_mismatch`。
- 区域是归一化设计约束，Manim/Blender/Remotion 各自负责把元素放进区域；没有跨引擎的布局执行器。
- 模板选择目前是规则映射，不是 LLM 自主选择；这样保证可复现。
