# verticals/ — 垂直领域（知识系列）

本目录存放**领域级内容方案**：一个学科或知识领域怎么接进 CourseWorkspace，第一季讲什么，用什么资产，谁审。

- 规则源：[知识系列课程生产总纲](知识系列课程生产总纲.md)。领域方案只写内容，不改引擎、语法、门禁、品牌。
- 每个领域一份方案，按总纲 §13 的十二项清单填写；缺项视为草案，不得据以排期。
- 领域方案不是 PRD 增量：不新增 `FR-*` / `NFR-*`，不进入 `TRACEABILITY.md`。
- 状态只认证据：没有真实成片与人工签字的领域，写作“设计”而不是“已支持”。
