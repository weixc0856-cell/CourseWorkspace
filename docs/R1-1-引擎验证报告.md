# R1-1 引擎独立渲染验证报告

- **日期**：2026-11-07
- **范围**：Manim / Blender / Remotion 各一个最小示例真实出片；Motion Canvas 导出能力核实
- **结论**：三个引擎均可独立真实渲染；Motion Canvas 无官方 headless CLI，仍只能编辑器导出

## 4. Motion Canvas

| 项 | 结论 |
| --- | --- |
| 版本 | `@motion-canvas/core` / `@motion-canvas/2d` 3.17.2；`@motion-canvas/ffmpeg` ^1.1.0 |
| CLI | `node_modules/.bin` 中无 Motion Canvas 渲染命令；`@motion-canvas/ffmpeg` 是 Vite 插件（`lib/server/index.js`），不是 headless CLI |
| 官方路径 | 编辑器 **RENDER** 输出图像序列或 FFmpeg 视频 |
| 现有场景 | `MotionStudio/src/scenes/01-transformer-demo/attention-flow.tsx` 已注册 |
| 结论 | **只能编辑器人工导出**；本轮不新增生产依赖，不把“配置存在”写成“已导出” |
| 影响 | Motion Canvas 不作为 R1 自动化阻塞点；新动画走 Manim / Blender / Remotion |

## 6. 复现

```powershell
uv run --project ManimSandbox manim render -r 1920,1080 --fps 30 --media_dir build/r1/manim ManimSandbox/00-r1-smoke/smoke_scene.py SmokeScene
.\scripts\blender-render.ps1 -Lesson r1-smoke -Smoke -Engine BLENDER_EEVEE
cd RemotionStudio; npx remotion render src/index.ts R1Smoke ../build/r1/remotion/smoke.mp4
ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate,nb_frames -of default=nw=1 build/r1/remotion/smoke.mp4
```
