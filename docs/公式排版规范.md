# 公式排版与 Formula Pipeline（v0.1）

- **日期**：2026-11-08
- **定位**：公式是课程生产的一等资产，不是装饰性文本。本文件定义唯一公式源、静态/动态渲染分工、验证状态与 QC 门。
- **结论**：统一 **LaTeX 源**；静态公式用 **KaTeX**（HTML + PNG）；数学动画用 **Manim MathTex**；最终由 **Remotion** 合成；**FFmpeg** 输出与成片检查。不要让 AI 生成公式图片，也不要让每个引擎各自维护一份公式。

## 1. 为什么不是“换字体/换插件”

公式问题分三层，必须分开验收：

| 层 | 问题 | 负责 |
| --- | --- | --- |
| 数学正确性 | 符号、上下标、等式、量纲、隐含条件 | 来源 + 人工/SymPy 辅助 |
| 数学排版 | 变量斜体、函数/单位/微分正体、向量粗体 | LaTeX + KaTeX/Manim |
| 视频呈现 | 模糊、变形、裁切、字体缺失、遮挡、闪烁 | Remotion + FFmpeg + 成片检查 |

编译成功 ≠ 数学正确；画面好看 ≠ 公式正确。`latex_compile`、`mathematical_review`、`dimensional_check`、`visual_review` 必须分别记录。

## 2. 唯一源：FormulaSpec

```json
{
  "schema_version": 1,
  "formula_id": "CFD-001",
  "latex": "C_{\\mathrm D}=\\frac{F_{\\mathrm D}}{\\frac{1}{2}\\rho U_\\infty^2 A}",
  "display": "block",
  "meaning": "阻力系数定义",
  "symbols": {
    "C_D": "阻力系数，无量纲",
    "F_D": "阻力，N",
    "rho": "流体密度，kg/m³",
    "U_inf": "来流速度，m/s",
    "A": "参考面积，m²"
  },
  "source": {
    "document": "Hucho, Aerodynamics of Road Vehicles, 4th ed.",
    "locator": "Ch. 4",
    "url": null
  },
  "validation": {
    "latex_compile": "pass",
    "mathematical_review": "pending",
    "dimensional_check": "pending",
    "visual_review": "pass"
  },
  "font_size": 48,
  "color": "#14213D"
}
```

- `latex` 只放数学主体，**不要**带 `$...$`、`\[...\]`、`\documentclass`、`\usepackage`。
- 百分号必须写 `\%`；未转义的 `%` 会把后面内容变成注释。
- `source` 必填；`symbols` 为空会给出 warning。
- `validation` 默认全部 `pending`；渲染器只把 `latex_compile` / `visual_review` 置为 `pass`，数学与量纲必须人工确认。

Schema：`shared/schemas/formula.schema.json`。

## 3. 数学排版规范

| 内容 | 规范 | LaTeX |
| --- | --- | --- |
| 普通变量 | 数学斜体 | `F=ma` |
| 希腊变量 | 数学斜体 | `\rho,\ \mu,\ \alpha` |
| 函数名 | 正体 | `\sin(x),\ \log(x)` |
| 单位 | 正体，与数值留薄空格 | `25\,\mathrm{m/s}` |
| 微分算子 d | 正体 | `\frac{\mathrm{d}y}{\mathrm{d}x}` |
| 向量/矩阵 | 粗体（按课程符号规范） | `\mathbf{F}=m\mathbf{a}` |
| 描述性下标 | 正体 | `C_{\mathrm D}`、`F_{\mathrm D}` |
| 数字/运算符/括号 | 正体，由引擎自动排版 | `80\%`、`\left( \right)` |
| 百分号 | 转义 | `80\%` |
| 公式编号 | 正体，统一位置 | 由容器/模板控制 |

字体：
- KaTeX 使用自带的 Computer Modern 数学字体（CSS + woff2），不要给公式容器加 `font-style: italic`。
- Manim 使用系统 LaTeX（`MathTex`/`Tex`），需确保 LaTeX 与字体可用。
- 候选数学字体：Latin Modern Math、STIX Two Math、KaTeX 默认字体；正式课程固定一种。

## 4. 架构

```text
FormulaSpec (LaTeX)
   │
   ├─ source checks (% / braces / delimiters / forbidden commands)
   │
   ├─ 静态：KaTeX → formula.html + formula.png
   │        └─ Remotion <Formula latex=.../> → 最终合成
   │
   ├─ 动态：Manim MathTex → 公式动画镜头
   │        └─ Remotion overlay → 最终合成
   │
   └─ 审计：formula.audit.json + 最终成片检查
```

- **KaTeX**：静态公式优先；HTML/PNG；适合 Remotion/网页。
- **MathJax**：仅在 KaTeX 不支持某命令时作为备用，不作为第二套生产源。
- **Manim**：需要公式变换、逐项高亮、推导动画时使用；LaTeX 源与 FormulaSpec 一致。
- **Remotion**：统一合成；`Formula` 组件负责 KaTeX 渲染与安全边距。
- **FFmpeg**：输出 + 成片检查；公式 QC 看最终编码帧（必要时定位单帧），不看 HTML 预览。

## 5. 验证流程（四道门）

### G1 源检查（自动，必须）

- 未转义 `%` → error
- 大括号不平衡 → error
- `$` 定界符 → error（由渲染器负责）
- `\documentclass` / `\usepackage` / `\begin{document}` / `\input` → error
- `symbols` 为空 → warning

### G2 编译检查（自动，必须）

- KaTeX `throwOnError: true`、`strict: "error"`。
- 输出 `formula.html`、`formula.png`；PNG 宽高 > 4 px；无 `katex-error`。
- Manim 公式镜头另跑一次真实渲染，检查帧数与首帧。

### G3 数学检查（半自动，不能冒充）

- 简单等式可用 SymPy `parse_latex` + `simplify` 做恒等检查；失败只给 warning，不自动 pass。
- 量纲、变量定义、隐含条件、来源页码必须人工/source review。
- `mathematical_review` / `dimensional_check` 保持 `pending`，直到有人签字或来源证据匹配。

### G4 视觉/视频检查（自动 + 人工）

- PNG：非空、宽高、无错误字形。
- 最终成片：检查清晰度、字体、上下标、希腊字母、百分号、裁切、字幕遮挡、动画中的符号错位（必要时定位单帧）。
- 任何一项失败：`formula.audit.json` 记 error，不得进入最终成片。

## 6. 命令

```powershell
# 只做源检查
uv run --project CourseControl course-control formula-validate --spec formula.json

# KaTeX 渲染 HTML + PNG
uv run --project CourseControl course-control formula-render --spec formula.json --out build/formulas/CFD-001

# 完整审计（源 + 编译 + 可选符号检查 + 视觉）
uv run --project CourseControl course-control formula-audit --spec formula.json --out build/formulas/CFD-001
```

Remotion 组件：

```tsx
import {Formula} from './components/Formula';
<Formula latex={r"C_{\mathrm D}=\frac{F_{\mathrm D}}{\frac12\rho U_\infty^2 A}"} fontSize={64} />
```

Manim：

```python
from manim import MathTex
MathTex(r"C_{\mathrm D}=\frac{F_{\mathrm D}}{\frac12\rho U_\infty^2 A}")
```

## 7. 测试集（必须覆盖）

- `80\%`：百分号不吞内容
- `C_{\mathrm D}` / `F_{\mathrm D}`：描述性下标正体
- `\rho,\ \mu,\ \alpha,\ \beta,\ \omega`：希腊字母
- `\frac{1}{2}\rho U_\infty^2 A`：分式 + 上下标
- `\mathbf{F}=m\mathbf{a}`：向量粗体
- `\sin(x)+\log(x)`：函数正体
- 未转义 `%`、未闭合 `{`、`\documentclass`：必须失败
- 1080p 最终帧：公式不被字幕/边缘裁切

## 9. 硬门

1. 所有公式必须能追溯到唯一 `formula_id` + LaTeX 源 + 来源。
2. 未通过 G1/G2 的公式不得进入视频。
3. 不允许用普通文字字体模拟公式。
4. 未转义 `%` 等截断问题必须在源头失败。
5. 数学正确性与视觉正确性分别验收，不能互相替代。
6. 最终成片必须检查实际编码帧（必要时定位单帧）。
