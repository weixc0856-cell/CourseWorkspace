# 评审：81.6 秒《Vector addition》动画

- **被评审文件**：`build/vector-addition/vector-addition.mp4`
- **规格**：1920×1080 / 30 fps / 2448 帧 / 81.6 s / 无音轨
- **评审方式**：完整播放成片，按时间戳记录问题。历史记录中的抽帧结论只作为定位线索。
- **结论**：**技术原型通过；专业动画验收不通过。** 当前是“基础 Manim 对象运动 + 暗色网格 + 颜色区分”，不是 3Blue1Brown 级视觉叙事。

## 2. 五个专业视角

### 导演
- 叙事是“两个箭头 → 三角形 → 公式”，但没有**问题—动作—结果**的戏剧结构。
- 18 s 前缺少“我们要解决什么”的视觉提问；60 s 的交换律没有“换一条路”的明确提示。
- 镜头运动只是跟随对象，没有“为什么现在动”。

### 摄影
- 只有 push/pan/pull，没有景别变化（特写/中景/全景）和焦点转移。
- 网格与主体对比度接近，缺少前景/中景/背景层次。
- 画面长期左重右空，构图没有随信息重心重新组织。

### Motion Design
- 运动曲线单一，几乎所有动作都是同一套缓动；没有加速—减速—停顿的节奏设计。
- 对象身份保持做得对（a 不变、b 平移），但缺少跟随、拖尾、残影、形变等动态语法。
- 每个动作后都有较长静止，节奏像“演示步骤”，不是连续叙事。

### Art Director
- 深色网格 + 蓝橙绿是安全但通用的技术演示配色；没有材质、光感、版式系统。
- 字号层级弱：标题/标签/公式大小接近，缺少主次。
- 大量负空间没有被设计，画面显得空而不是“留白”。

### 数学可视化
- 加法的空间关系正确；但“为什么 b 可以平移”没有视觉解释。
- 交换律的终点一致性是数学关键，当前只靠公式说明，没有视觉强调。
- 没有把“向量 = 位移”这一核心隐喻贯穿到镜头语言中。

**结论**：不需要 Blender。当前问题主要是**分镜、构图、节奏、标签时机**，不是三维能力。

## 4. 八个问题的回答

1. **主要差距**：不是渲染器，是镜头设计、视觉层级、运动节奏和教学提示。
2. **是否只是基础 Manim 图形动画**：是。对象运动正确，但没有形成视觉语言。
3. **是否有镜头语言**：只有机械 push/pan/pull，没有景别、焦点转移和镜头动机。
4. **是否有空间层次/构图变化**：几乎没有；网格和主体同一平面，构图长期左重右空。
5. **运动是否有节奏**：没有；动作与静止均匀分布，缺少加速/减速/停顿设计。
6. **是否需要 Blender**：不需要。二维 Manim 足够；先解决设计。
7. **问题归属**：约 70% 视觉设计/分镜，20% 动画节奏，10% 工具实现；工具不是瓶颈。
8. **应建立的资产**：镜头模板（特写/中景/全景）、标签时机规则、路径/尾迹/残影原语、公式卡片、构图网格、关键帧评审表。

## 6. 通过/不通过标准

**通过**：
- 0.3 s 内有可识别主体；无空场、无裁切文字。
- 每个动作只有一个视觉中心；标签不压主体。
- 至少一次特写 + 一次全景；镜头运动有明确动机。
- 每个数学关系在画面内有空间对应，不靠字幕解释。
- 最后一帧可独立作为封面/结论。

**不通过**：
- 标题/标签裁切；动作对象身份不清。
- 镜头只是机械缩放/平移；构图长期失衡。
- 公式与图形脱节；过时提示未清理。
- 抽帧无法在 1 秒内指出主体。

## 7. 评审结论

- 作为**技术原型**：通过。对象运动、颜色区分、基础镜头和数学关系都成立。
- 作为**专业动画**：不通过。当前是“会动的工程示意图”，不是成熟的数学可视化叙事。
- 下一步：按第 5 节分镜重做 80 秒，直接看成片验收，再扩展 3 分钟；不引入 Blender/新库。
