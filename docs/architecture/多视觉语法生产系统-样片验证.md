## 2. 每支样片证明了什么

### 2.1 长镜头几何演化
- 连续旋转变换、实时计算的角度弧与投影虚线、单次有动机的推近，全部在 Manim 内完成。
- 说明“长镜头语法”本来就能生产，问题只在它被写成了**唯一**语法。

### 2.2 短切动态文字
- 3 秒硬切、逐词出现、高亮扫过、播放头、对勾；每镜首动作 ≤ 0.33 s。
- **同一个 t 两次捕获 SHA-256 完全一致**：高密度短切与确定性不冲突。
- 关键反证：`freezedetect=n=0.002` 在这支明显有运动的片上报了 4 段冻结。现有冻结检测不能作为文字/矢量片的通用门禁。

### 2.3 群体模拟
- 240 个体 SIR、固定种子、感染/恢复规则、顶栏计数与底部曲线全部来自同一份逐帧状态。
- 说明“模拟语法”需要的是状态一致性检查，而不是长镜头连续性检查。

### 2.4 混合叙事
- 一条 12 秒时间线里混用 4 种语法、3 个渲染器（CodeVideo / Manim / CodeVideo），每段独立可重渲。
- 说明现有渲染能力足以支撑“多语法一条片”，缺的只是镜头级契约和按语法分档的验收。

## 3. 与参考视频的差距（只谈可测项）

参考视频：亚里《AI 配音怎么选？》12:28，故事板每 5 秒一帧。

| 指标 | 参考 | 我们（样片） | 判定 |
|---|---|---|---|
| 切镜节奏 | 约 5 s/画面 | 3 s/切（样片 2/4） | 可达到，且更快 |
| 画面构成 | 纸感底 + 大字 + 图标 + UI 卡 | 同 | 可达到 |
| 逐词字幕 | 有 | **未做消费端**（时间戳已在 ASR 报告里） | 待接入 |
| 录屏段落 | 有 | 未做浏览器录屏接线 | 待接入 |
| 12 分钟整片 | 有 | 样片 8–12 s | 长片捕获与编排待验证 |
| 确定性 | 未知 | 两次捕获逐字节一致 | 我们更强 |
| 机器 QC | 未知 | 分辨率/帧率/编码/黑帧/冻结/确定性 | 我们更强 |

**结论**：形态可以复刻；差距集中在“逐词字幕消费端 + 浏览器录屏 + 长片编排”，不在渲染器、不在模型、不在语言。

## 5. 人工验收清单（每支样片）

- [ ] 第一秒是否抓住注意力？
- [ ] 大字在 1080p 下是否可读？手机尺寸是否可读？
- [ ] 是否有无意义的动效？
- [ ] 切点是否服务表达，而不是为了动而动？
- [ ] 画面是否出现 AI 廉价感（通用渐变、无意义粒子、过度发光）？
- [ ] 观众能否在不看字幕时理解主要信息？
- [ ] 与目标参考片并排看，是否在同一档？

**自动 QC 不能替代这一节。** 样片是否“好”，最终由人签。
