## 1. 问题定义

当前系统把三件事焊在一起：

1. **内容组织**（页 / 笔记 / 大纲）
2. **镜头组织**（时间线 / 镜头 / 转场）
3. **质量判定**（技术正确 + 运动语法 + 艺术偏好）

结果是：换一种视觉语法，不是“新增能力”，而是“违反规则”。目标架构要把三者拆开：

- 内容可以按页组织，也可以不按页；
- 镜头是生产、渲染、验收、重渲的第一等公民；
- 质量分三层：硬约束、语法约束、人工审美，互不冒充。

## 2. 四层架构

```
┌─ L1 内容表达目标 ─────────────────────────────────────────────┐
│ explain · demonstrate · simulate · compare · narrate · emote  │
│ orient · summarize                                            │
└───────────────────────────────────────────────────────────────┘
                │ 每个 Shot 声明 purpose
┌─ L2 视觉语法（可组合，逐镜头）────────────────────────────────┐
│ long_take · kinetic_edit · montage · geometric · simulation    │
│ camera_move · kinetic_type · data_viz · 2d/3d                  │
│ techniques 是开放集合，不穷举                                    │
└───────────────────────────────────────────────────────────────┘
                │ 每个 Shot 声明 grammar + techniques[]
┌─ L3 视觉表现能力（渲染器）─────────────────────────────────────┐
│ CodeVideo(HTML/Canvas/SVG) · Manim · Motion Canvas · Blender   │
│ Remotion（合成/字幕/叠加）                                      │
└───────────────────────────────────────────────────────────────┘
                │ 每个 Shot 声明 renderer
┌─ L4 质量验收（三层分离）───────────────────────────────────────┐
│ Hard Constraints（不可豁免）                                   │
│ Grammar Constraints（按语法，可豁免但须书面理由）                │
│ Metrics（报告，不直接否决）                                     │
│ Human Creative Review（发布决定）                               │
└───────────────────────────────────────────────────────────────┘
```

一条影片可以同时包含：3 秒快切、8 秒连续变换、5 秒粒子模拟、4 秒逐词字幕、6 秒空间镜头。**语法是镜头的属性，不是整片的分档。**

## 3. 三份契约

### 3.1 Production Contract（生产契约）

描述“一个镜头如何被生产”，不描述艺术风格，不描述质量。

```yaml
schema_version: 1
lesson: attention-geometry
sequences:
  - id: seq-01
    title: 为什么需要注意力
    shots:
      - id: shot-001
        duration_s: 3.5
        purpose: orient
        visual_type: kinetic_typography
        grammar: kinetic_edit
        techniques: [hard_cut, word_highlight]
        renderer: code_video
        source: CodeVideoStudio/shots/attention-hook
        transition: {in: hard_cut, out: hard_cut}
        camera: {movement: static}
        objects: []
        actions: []
        audio: {narration_segment: p1-s1, sfx: []}
        captions: {mode: none}

      - id: shot-002
        duration_s: 8.0
        purpose: explain
        visual_type: geometric_transform
        grammar: long_take
        techniques: [transform, camera_push]
        renderer: manim
        source: ManimSandbox/attention-geometry/geometry.py
        transition: {in: match_cut, out: hard_cut}
        camera: {movement: push_in, motive: "跟住被投影的向量"}
        objects: [query_vector, key_vector, plane]
        actions:
          - {type: create, target: plane, at: 0.05}
          - {type: transform, target: query_vector, at: 0.35}
          - {type: highlight, target: similarity_angle, at: 0.72}
        audio: {narration_segment: p1-s2}
        captions: {mode: events}

      - id: shot-003
        duration_s: 10.0
        purpose: simulate
        visual_type: population_simulation
        grammar: simulation
        techniques: [spawn, move, collide, state_change]
        renderer: code_video
        source: CodeVideoStudio/shots/epidemic
        transition: {in: hard_cut, out: dissolve}
        camera: {movement: static}
        objects: [agents, infection_curve]
        actions:
          - {type: module, target: sir_model, at: 0.0}
        audio: {narration_segment: p2-s1}
        captions: {mode: events}
```

**规则**

- 时间只有一个权威：镜头 `duration_s` 累加；Sequence 只分组，不携带时间。
- `purpose`、`grammar`、`renderer` 是必填；`techniques`、`objects`、`actions` 可空。
- `actions[].type` 是开放字符串；专门的模拟模块通过 `type: module` 调用，不塞进动作 DSL。
- 镜头可以跨页、脱离页；`Page` 只在 deck/scene 模式存在。
- 镜头级音频、字幕事件、转场、渲染参数都是契约字段。

### 3.2 Style Profile（风格配置）

只描述视觉语言，不规定镜头长度、不规定每镜必有什么动作。

```yaml
id: warm_editorial
composition: {density: medium, hierarchy: strong, whitespace: balanced}
palette: {mode: light, family: ancient_paper, accent: "#D97757"}
typography: {display: "Noto Serif SC", body: "Noto Sans SC", emphasis: kinetic}
motion: {easing: natural, pacing: adaptive}
rendering: {preferred: [code_video, manim, remotion]}
```

Style Profile 可以逐片选择，也可以逐 Sequence 覆盖；**它不是质量门禁**，只是给导演和渲染器的输入。

### 3.3 Quality Profile（质量标准）

统一质量要求，按语法选择检测方式。

```yaml
hard:
  - media.readable
  - media.resolution_fps
  - media.audio_stream
  - timeline.contiguous
  - subtitles.timing
  - render.determinism
  - text.safe_area
  - assets.complete
profiles:
  long_take:
    checks: [continuity.transform, camera.motive, action.gap]
    thresholds: {shot_seconds: [5, 16], action_gap_s: 4.0, long_lived_ratio: 0.5}
  kinetic_edit:
    checks: [cut.logic, copy.reading_time, action.density]
    thresholds: {shot_seconds: [1.5, 8.0], min_words_per_second: 3.0}
  simulation:
    checks: [state.transitions, determinism.seed, data.curve_matches_state]
    thresholds: {min_agents: 20}
  typography:
    checks: [reading_speed, emphasis.timing, line_breaks]
    thresholds: {cps_max: 9.0}
metrics:
  - motion_energy
  - cut_rate
  - freeze_rate
  - action_density
human_review: required
```

**发布规则**

1. `hard` 全过；任一失败即不可发布，无豁免。
2. 每个镜头按 `grammar` 跑对应 `profiles`；失败可豁免，但必须写下镜头、时间点、理由与批准人。
3. `metrics` 只进报告，不产生 pass/fail。
4. 人工审美验收是发布决定；自动 QC 不冒充艺术总监。
5. **不再存在统一的 85 分发布线。**

## 4. 数据模型

### 4.1 Python（`course_control/production.py`）

```python
Purpose = Literal["explain","demonstrate","simulate","compare","narrate","emote","orient","summarize"]

class Transition(StrictModel):
    in_: Literal["hard_cut","fade","dissolve","match_cut","wipe"] = Field("hard_cut", alias="in")
    out: Literal["hard_cut","fade","dissolve","match_cut","wipe"] = "hard_cut"

class CameraPlan(StrictModel):
    movement: Literal["static","pan","push_in","pull_out","orbit","handheld"] = "static"
    motive: str | None = None

class ActionPlan(StrictModel):
    type: str
    target: str | None = None
    at: float = Field(0.0, ge=0.0, le=1.0)
    note: str | None = None

class ShotPlan(StrictModel):
    id: str
    duration_s: float = Field(gt=0)
    purpose: Purpose
    visual_type: str
    grammar: str
    techniques: list[str] = Field(default_factory=list)
    renderer: Literal["code_video","manim","motion_canvas","blender","remotion"]
    source: str | None = None
    transition: Transition = Transition()
    camera: CameraPlan = CameraPlan()
    objects: list[str] = Field(default_factory=list)
    actions: list[ActionPlan] = Field(default_factory=list)
    audio: dict = Field(default_factory=dict)
    captions: dict = Field(default_factory=dict)
    notes: str | None = None

class Sequence(StrictModel):
    id: str
    title: str
    shots: list[ShotPlan] = Field(min_length=1)

class ProductionPlan(StrictModel):
    schema_version: Literal[1] = 1
    lesson: str
    style: str | None = None
    quality: str | None = None
    sequences: list[Sequence] = Field(min_length=1)
```

派生规则：`start_s` 由镜头顺序累加；Sequence 的起止由首末镜头派生；`total_duration_s = sum(duration_s)`。

### 4.2 Timeline 映射

## 5. Renderer Adapter

### 5.1 接口

```python
class RenderContext(StrictModel):
    workspace: Path
    build_root: Path
    fps: int
    resolution: tuple[int, int]

class RendererAdapter(Protocol):
    name: str
    capabilities: frozenset[str]

    def missing_capabilities(self, shot: ShotPlan) -> list[str]: ...
    def render(self, shot: ShotPlan, ctx: RenderContext) -> RenderArtifact: ...
```

### 5.2 能力矩阵（设计值）

| 能力 | code_video | manim | motion_canvas | blender | remotion |
|---|---|---|---|---|---|
| 2d_vector | ✓ | ✓ | ✓ | ✓ | ✓ |
| html_ui | ✓ | ✗ | ✗ | ✗ | ✓ |
| kinetic_type | ✓ | ✓ | ✓ | ✗ | ✓ |
| particles | ✓ | ✓ | ✓ | ✓ | ✓ |
| population | ✓ | ✓ | ✓ | ✓ | ✗ |
| 3d_scene | ✓（three.js） | ✗ | ✗ | ✓ | ✗ |
| camera_move | ✓ | ✓ | ✓ | ✓ | ✗ |
| deterministic | ✓ | ✓ | ✓ | ✓ | ✓ |
| long_sequence | 分块 | ✓ | ✓ | ✓ | ✓ |

`missing_capabilities` 非空 = 该镜头不可由该渲染器生产，**失败为 blocked，不静默换引擎**。

### 5.3 调度

```
ShotPlan.renderer -> RendererRegistry -> adapter.render(shot)
```

现有 `adapters.manim.run` / `code_video.run` 等保留批量入口；新增 `render_one` 适配，内部复用现有实现，不改引擎内部模型。

### 5.4 长序列

- `capture.mjs` 已有 `--start/--frames`；编排层按 30–60 秒分块，逐块校验 sha256，再无损拼接。
- 拼接后必须通过 `V-10/V-12/V-13` 与逐帧确定性抽检。
- 在长序列修复前，长镜头的生产上限为已验证的约 145 秒（Primer POC），不作为通用能力宣传。

## 6. Quality Gate 重构

### 6.1 分层

| 层 | 例子 | 结果 | 豁免 |
|---|---|---|---|
| Hard | 文件不可读、丢帧、黑帧、音画不同步、字幕越界、渲染不确定 | pass/fail | 否 |
| Grammar | 长镜头连续性、快切逻辑、模拟状态一致、文字阅读速度 | pass/fail | 可，须书面理由 + 批准人 |
| Metrics | 运动能量、切镜率、冻结率、动作密度 | 数值 + 趋势 | 不适用 |
| Human | 高级感、AI 廉价感、运动是否自然、观众能否理解 | 发布决定 | 不适用 |

### 6.2 现有组件去向

| 现有 | 去向 |
|---|---|
| `verify.py` V-10/V-12/V-13/V-15/V-16/V-31/V-36 | **Hard**，原样保留 |
| `media_qc.py` 解码/格式/响度/静音/黑帧 | **Hard**，保留 |
| `media_qc.py` 冻结 | 降为 **Metric**（不再因 WARN 扣分） |
| `animation_score.py` | 拆成 grammar constraints + metrics；CLI 保留 `--profile`，默认 `long_take` 输出与今日一致 |
| `beats.py` | 增加 `grammar` 字段与 profile 化阈值；默认 `long_take`，现有节拍表行为不变 |
| 85 分发布线 | 废止；替换为 Hard + Grammar + 人工签核 |

### 6.3 新 CLI（设计）

```powershell
course-control grammar-list
course-control production-validate --lesson <slug>
course-control quality-gate --lesson <slug> --profile <grammar>
course-control quality-gate --lesson <slug> --waive <shot>:<check> --reason "..."
```

| 维度 | 旧 | 新 | 兼容 |

## 8. 兼容性与迁移

### 8.1 兼容原则

1. **旧模式不动**：`compose.mode=deck/scene/recording` 的行为与校验保持现状。
2. **旧节拍表不动**：`beats.yaml` 不写 `grammar` 时按 `long_take` 解释，分数与今日一致。
3. **旧字幕不动**：`subtitles.render=remotion` 与 SRT 路径保持。
4. **新增能力全部可选**：不写 `production.yaml` 的课程完全不受影响。
5. **失败显式**：未知 grammar / renderer / capability 缺口一律 blocked，不静默降级。

### 8.2 迁移步骤

1. 新增 `production.yaml` 与 `compose.mode=shots`；`collect()` 增加分支。
2. 新 CLI `production-validate`，先只校验不构建。
3. 选择一门真实课程（如 `05-transformer-5min`）做影子转换：旧路径与新路径各生成一次 `shots.json`，逐字段 diff，必须一致。
4. 旧路径保留至少一个发布周期；`animation-score` 输出标注 “metric, not release gate”。
5. 新质量门禁与旧 `quality-report` 并行运行，差异必须解释。

### 8.3 回归门禁

- `check.ps1` 必须保持 `check ok`。
- 现有 421 用例全部保持。
- 新增用例覆盖：production 解析、grammar profile、quality gate、transition 序列化。

## 11. 风险、技术债务与回滚

| 风险 | 影响 | 缓解 | 回滚 |
|---|---|---|---|
| 双时间权威（页 + 镜头） | 时间线漂移 | shots 模式只认镜头累加；页只做分组 | 删除 shots 分支，回到 deck/scene |
| 旧节拍表被误判 | 现有课程无法发布 | `grammar` 缺省 long_take，阈值不变 | 回退 `beats.py` 常量 |
| 评分器拆分会改变既有报告 | 历史对比断裂 | 保留 `animation-score` 原输出，新增字段 | 保留旧模块版本 |
| 转场改变合成时长 | 音画错位 | 转场只做视觉叠加，不改时间基 | `transition` 缺省 fade |
| 长片捕获仍失败 | 高密度片无法整段渲染 | 分块 + sha 校验；先按 ≤145 秒验证 | 退回逐镜独立渲染 |
| 逐词字幕与配音时间漂移 | 字幕错位 | 以 ASR 词时间为准，人工抽检 | 关闭 word 模式，回 cue 级 |
| 过度放开导致质量下滑 | 廉价感 | Hard 不放开；Grammar 可豁免但留痕；人工签核 | 提高 Grammar 阈值或恢复 85 线作为参考 |

**技术债（必须记录，不得隐藏）**

1. 冻结检测 `n=0.002` 对矢量图形误报，尚未重标定。
2. 长序列捕获 180 秒失败原因未定位。
3. `collect()` 的页面假设仍会存在于 deck/scene 模式，短期不消除。
4. 现有 `animation-score` 的历史 94.7/100 与新参考样片校准线，在新体系下只作 metric 基线，不再作发布线。
5. 中文词级对齐尚未实测（模型与耗时）。
