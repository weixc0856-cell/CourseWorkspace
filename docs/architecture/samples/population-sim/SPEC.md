# Sample 3 · 群体模拟（simulation）

- 格式：1920×1080 · 30 fps · 12 s · 无音轨
- 渲染器：CodeVideo（HTML + Canvas 2D）
- 语法：`simulation`
- 目标：证明人群状态模拟、状态计数、曲线与个体运动来自同一份确定性数据。

## 固定事实
- SIR 模型，240 个个体，固定种子 `20261109`。
- 初始 3 名感染者，感染半径 34 px，感染概率 0.18/接触帧，恢复 110 帧。
- 画面上的计数与曲线均由逐帧状态统计得出，不是手写的装饰数字。

## Must-haves
1. 个体运动连续，不瞬移。
2. 感染只发生在接触半径内。
3. 顶栏 S/I/R 计数等于当前帧状态统计。
4. 底部曲线与当前帧感染比例一致。
5. 同一 t 两次捕获逐字节一致。

## 失败条件
- 个体瞬移，或感染发生在接触半径之外。
- 计数/曲线与当前帧状态不一致。
- 两次捕获哈希不一致。
