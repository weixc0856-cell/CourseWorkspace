# Sample 2 · 短切动态文字（kinetic_edit）

- 格式：1920×1080 · 30 fps · 12 s · 无音轨
- 渲染器：CodeVideo（HTML + Canvas 2D，`seek(t)` 纯函数）
- 语法：`kinetic_edit`
- 目标：证明 3 秒硬切、逐词出现、逐词高亮、无长寿命对象，仍能保持设计与可读性。

## 结构
| 镜头 | 时间 | 画面 |
|---|---|---|
| 01 | 0–3 s | 配音 / 是 / 整条视频的 / 时钟（逐词出现 + 下划线 + 表盘刻度） |
| 02 | 3–6 s | 每一个字，都有它自己的时间（逐字出现 + 高亮块扫过） |
| 03 | 6–9 s | 画面 / 卡在词上（大字脉冲 + 播放头横扫） |
| 04 | 9–12 s | 所以不会错位（三条对齐条 + 勾） |

## 固定文案
- 01：配音 是 整条视频的 时钟
- 02：每一个字，都有它自己的时间
- 03：画面 卡在词上
- 04：所以不会错位

## Must-haves
1. 切点在 3.0 / 6.0 / 9.0 s，硬切，无交叉淡化。
2. 每镜首动作 ≤ 0.5 s。
3. 每镜至少一次构图变化（不只是透明度）。
4. 文字不压边、不出安全区。
5. 同一 t 两次捕获逐字节一致。

## 失败条件
- 切点不在 3.0 / 6.0 / 9.0，或出现交叉淡化。
- 任一镜首动作晚于 0.5 s，或只有透明度变化没有构图变化。
- 文字压边、出安全区，或两次捕获哈希不一致。
