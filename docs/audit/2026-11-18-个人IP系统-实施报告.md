## 5. 只到接口 / 没做

- **语义级图文一致性**：没有自动判断“旁白机制 ↔ 画面机制”的能力。现有检查只保证 claim 绑定、资产存在、时间覆盖；语义错配仍靠人工。
- **Blender 品牌令牌**：Blender 场景颜色是光照与材质决策，没有接入品牌令牌，也没有做同帧对比。
- **产品层回溯到存量课程**：20 条存量 lesson 没有声明 `product_tier`；声明后 release-check 会要求视觉事件计划，因此没有批量改。
- **长视频完整 20 分钟重渲**：只渲了 12 分钟窗口来证明窗口与 production 路径；没有重跑 20.6 分钟全片。
- **样片完整交付包**：样片产物在 `build/_shared/ip-samples/`，没有走 `package` 生成 `deliver/<slug>/`。
- **跨平台自动导出**：竖屏是重新构图渲染，不是一条母版自动多平台导出。

## 6. 已知问题

1. **全量回归的本地前置**：首轮 `check.ps1` 在 `frame audit` 失败，原因是 `RemotionStudio/public/staging/t1-01-why-aerodynamics/` 缺 3 个本地测试资产（404）。已从归档恢复；这是环境缺口，不是代码回归。
2. **`test_release_chain` 的导入路径**：从仓库根跑 `unittest discover` 会报 `No module named 'tests'`；从 `CourseControl/` 跑正常。`check.ps1` 使用后者。
3. **样片音频复用**：短视频音频来自既有成片音轨（含音乐），不是干净旁白 stem；用于组件验证可以，正式交付应使用 narration 分段与独立混音。
4. **图 1.3 分辨率 628×536**：只用于组件证明，不满足正式素材 ≥2K 的规格。

## 8. 怎么用

```powershell
# 产品层
course-control product-check --lesson <slug>          # 写 build/<slug>/product.json
# 视觉事件
course-control visual-events --lesson <slug>          # 写 build/<slug>/contracts/visual-events.json
course-control visual-events-check --lesson <slug>
# 短视频 JSON
course-control short-validate --path RemotionStudio/src/short/sample-base-rate.json
# 品牌令牌一致性
course-control theme-check --workspace .
# 渲染短视频样片
cd RemotionStudio
npx remotion render src/index.ts ShortStoryboard <out.mp4> --codec=h264 --crf=18
npx remotion render src/index.ts ShortComponentGallery <out.mp4> --props=src/short/gallery.json
npx remotion render src/index.ts ShortStoryboard <vertical.mp4> --props=src/short/gallery-vertical.json
```

`lesson.yaml` 声明产品层：

```yaml
product_tier: short_explainer   # micro_explainer | short_explainer | research_brief | deep_lecture | course_series
```

声明后 `preflight` 与 `product-check` 按时长窗口、纵横比、叙事模块检查；未声明保持旧行为，报告 `NOT_DECLARED`，不算通过。
