# 课程生产交付物与归档规范

- **日期**：2026-11-07
- **来源**：结合 `Aaryan-Kapoor/video-production-skill` 的 job workspace / manifest / QC / archive 纪律，以及本项目现有 `build/<slug>/` 临时区、`deliver/<slug>/` 交付包、`build-report.json`、`CodeVideoStudio/` 产物。
- **原则**：CourseControl 仍是唯一编排层；本规范只定义“交付什么、放在哪、如何验收与归档”。

## 1. 课程交付包

最终交付只有一个位置：`deliver/<slug>/`。`build/<slug>/` 是临时区，可删除、可重建，不承载最终交付。

```text
deliver/<slug>/
├── final/
│   ├── master.mp4              # 母版
│   ├── captioned.mp4           # 字幕版（存在则复制）
│   └── subtitles.srt|ass|vtt   # 英上中下
├── build-report.json
├── narration.meta.json
├── evidence/media-qc.json
├── review/
│   ├── review.json
│   └── decisions.json
├── logs/*.log
├── metadata.json
├── manifest.json
└── delivery-checklist.md
```

| 交付物 | 路径 | 说明 |
| --- | --- | --- |
| 干净母版 | `final/master.mp4` | 无字幕 |
| 字幕版 | `final/captioned.mp4` | 存在则复制；不存在记 `not_applicable` |
| 字幕文件 | `final/subtitles.srt`、`.ass`、`.vtt` | 英上中下 |
| 构建报告 | `build-report.json` | stages / checks / artifacts / verdict |
| 媒体 QC | `evidence/media-qc.json` | 解码、响度、黑帧、冻结、字幕 |
| 旁白证据 | `narration.meta.json` | 分段、哈希、页跨度、TTS 版本 |
| 审查报告 | `review/review.json` | 内容审查候选意见（默认 Claude Code） |
| 发布元数据 | `metadata.json` | 标题、时长、分辨率、帧率、语言 |
| 哈希清单 | `manifest.json` | 每个文件的 bytes 与 SHA-256 |
| 交付清单 | `delivery-checklist.md` | 人工可读状态 |

## 2. 临时工作区约定（`build/<slug>/`）

```text
build/
├── _engine-cache/          # 引擎缓存：remotion-staging / manim-media / code-video / motion-output
├── _audit/                 # 证据与路径审计输出
└── <slug>/
    ├── slides/             # 截图/录屏
    ├── animation/          # 动画镜头 MP4
    ├── blender/            # 三维产物
    ├── narration/          # 分段 WAV、narration.wav、meta
    ├── subtitles/          # 双语草稿与 manifest
    ├── contracts/          # shots.json / timeline.spec.json
    ├── timeline/           # page-plan.json
    ├── review/             # ContentQA 候选
    ├── final/              # 渲染输出：成片、字幕、报告、burn.json
    ├── producer/           # 制片清单：manifest.json、README.md
    ├── tmp/                # 引擎中间产物、预览、缓存
    ├── logs/
    └── manifest.json       # 构建索引（可选）
```

- 每个阶段只写自己的目录；不互相覆盖。
- `build/<slug>/final/` 是渲染输出，不是最终交付；只有 `course-control package` 复制到 `deliver/<slug>/` 后，才算交付。
- 引擎缓存统一在 `build/_engine-cache/`；Remotion 的 `public/staging` 是渲染器要求的临时镜像，构建结束后清理。
- 任何 `skipped` / `not_run` / `blocked` 必须出现在 `build-report.json` 与交付清单。

## 3. 交付 manifest

`deliver/<slug>/manifest.json`（或 `build-report.json` 的 artifacts 汇总）至少记录：

```json
{
  "lesson": "01-transformer-demo",
  "run_id": "20261107T140000Z-1a2b3c4d",
  "verdict": "pass",
  "duration_s": 1200.0,
  "outputs": {
    "clean": "final/master.mp4",
    "captioned": "final/captioned.mp4",
    "subtitles": ["final/subtitles.srt", "final/subtitles.ass", "final/subtitles.vtt"]
  },
  "hashes": {"final/master.mp4": "sha256:..."},
  "toolchain": {"python": "3.12", "node": "24", "ffmpeg": "8.1"},
  "sources": ["authoring/source-digest.json"],
  "approvals": ["authoring/approval.json"]
}
```

## 4. QC 门

交付前至少通过：

1. **画面**：抽帧/Contact Sheet；文字不裁切、无重叠、关键主体可辨认。
2. **音频**：存在音轨；响度归一；音画时长差 ≤0.5 s；无削波。
3. **字幕**：条数与音频段一致；中文 ≤15 字/行、英文 ≤42 字符/行、最多 2 行；CPS ≤9；1–6 s/条。
4. **时长**：最终视频在 `lesson.yaml.duration` 窗口内。
5. **编码**：H.264 / yuv420p / 目标分辨率与帧率 / faststart。
6. **证据**：`deliver/<slug>/build-report.json` 无 `fail`；`skipped` 必须有原因；`blocked` 必须可读回。
7. **校验**：`course-control package-verify --package deliver/<slug>` 输出 `package ok`。
8. **归档**：`deliver/<slug>/` 复制到备份目录；不要把唯一副本留在临时区。

## 5. 归档

- 本地归档目录由 `config/local-paths.yaml` 指定（放仓库外，或 `deliver/` 之外的备份位置；不回写 `build/`）。
- 归档文件名包含 lesson、日期、run_id、verdict。
- 归档前复核 sha256；归档后回读文件存在与大小。
- 课程正文、模型权重、凭据不进入远程仓库。
