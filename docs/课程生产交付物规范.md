# 课程生产交付物与归档规范

- **日期**：2026-11-07
- **来源**：结合 `Aaryan-Kapoor/video-production-skill` 的 job workspace / manifest / QC / archive 纪律，以及本项目现有 `build/<slug>/`、`build-report.json`、`CodeVideoStudio/` 产物。
- **原则**：CourseControl 仍是唯一编排层；本规范只定义“交付什么、放在哪、如何验收与归档”。

## 1. 课程交付包

每门课程最终交付包至少包含：

| 交付物 | 路径 | 说明 |
| --- | --- | --- |
| 干净母版 | `build/<slug>/final/course-video.mp4` | 无字幕 |
| 字幕版 | `build/<slug>/final/course-video-captioned.mp4` | ASS 烧录 |
| 字幕文件 | `final/subtitles.srt`、`.ass`、`.vtt` | 英上中下 |
| 构建报告 | `final/build-report.json` | stages / checks / artifacts / verdict |
| 烧录记录 | `final/burn.json` | 编码器、回退、时长、哈希 |
| 交付清单 | `build/<slug>/delivery-checklist.md` | 人工可读状态 |
| 发布元数据 | `build/<slug>/metadata.json` | 标题、简介、标签、时长 |
| 旁白证据 | `narration/narration.meta.json` | 分段、哈希、页跨度、TTS 版本 |
| 审查报告 | `review/review.json` | 在线审查候选意见 |
| 镜头证据 | `animation/*.mp4`、`code-video/*/VERIFY.md` | 每个镜头可追溯 |
| 日志 | `logs/*.log` | 每阶段命令与输出 |

## 2. Job workspace 约定

```text
build/<slug>/
├── slides/                 # 截图/录屏
├── animation/              # 动画镜头 MP4
├── blender/                # 三维产物
├── narration/              # 分段 WAV、narration.wav、meta
├── subtitles/              # 双语草稿与 manifest
├── contracts/              # shots.json / timeline.spec.json
├── timeline/               # page-plan.json
├── review/                 # ContentQA
├── final/                  # 成片、字幕、报告、burn.json
├── logs/
└── manifest.json           # 本课程交付索引（可选，由报告汇总）
```

- 每个阶段只写自己的目录；不互相覆盖。
- 最终成片不能只存在于临时目录；`final/` 是唯一交付位置。
- 任何 `skipped` / `not_run` / `blocked` 必须出现在 `build-report.json` 与交付清单。

## 3. 交付 manifest

`build/<slug>/manifest.json`（或 `build-report.json` 的 artifacts 汇总）至少记录：

```json
{
  "lesson": "01-transformer-demo",
  "run_id": "20261107T140000Z-1a2b3c4d",
  "verdict": "pass",
  "duration_s": 1200.0,
  "outputs": {
    "clean": "final/course-video.mp4",
    "captioned": "final/course-video-captioned.mp4",
    "subtitles": ["final/subtitles.srt", "final/subtitles.ass", "final/subtitles.vtt"]
  },
  "hashes": {"final/course-video.mp4": "sha256:..."},
  "toolchain": {"python": "3.12", "node": "24", "ffmpeg": "8.1"},
  "sources": ["authoring/source-digest.json"],
  "approvals": ["authoring/approval.json"]
}
```

## 4. QC 门

交付前至少通过：

1. **画面**：抽帧/Contact Sheet；文字不裁切、无重叠、关键主体可辨认。
2. **音频**：存在音轨；响度归一；音画时长差 ≤0.5 s；无削波。
3. **字幕**：条数与音频段一致；中文 ≤15 字/行、英文 ≤42 字符/行、最多 2 行；CPS ≤9；1–6 s/条。
4. **时长**：最终视频在 `lesson.yaml.duration` 窗口内。
5. **编码**：H.264 / yuv420p / 目标分辨率与帧率 / faststart。
6. **证据**：`build-report.json` 无 `fail`；`skipped` 必须有原因；`blocked` 必须可读回。
7. **归档**：最终包复制到备份目录；不要把唯一副本留在临时目录。

## 5. 归档

- 本地归档目录由 `config/local-paths.yaml` 指定（默认 `build/<slug>/exports/` 或仓库外）。
- 归档文件名包含 lesson、日期、run_id、verdict。
- 归档前复核 sha256；归档后回读文件存在与大小。
- 课程正文、模型权重、凭据不进入远程仓库。
