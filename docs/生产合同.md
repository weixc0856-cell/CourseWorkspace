- **版本**：v1.0（2026-11-15）
- **状态**：现行。所有课程/主题视频开工前先读本文件；未填合同不进入构建。
- **上位**：`PRD.md`、`ARCHITECTURE.md`、`课程质量模型.md`、`知识视频质量基准.md`。
- **相关**：`课程页面系统.md`、`evaluations/复盘-T1-01视觉生产.md`、`混合动效生产流程.md`（G0–G7 原始定义）。

---

## 1. 目标与非目标

**目标**：内容讲明白；画面成立；交付可查；90 集可复用、可回归、可估工期。

**非目标**：不引入 LangGraph 或新渲染引擎；不追求无人化；不先铺 90 集。

## 2. 四份合同

| 合同 | 位置 | 作用 |
| --- | --- | --- |
| episode spec | `lessons/<slug>/authoring/episode.spec.yaml` | 核心问题、claims/source、六段 beats、cut list、assets、voice/rights |
| quality rubric | `lessons/<slug>/authoring/quality.rubric.yaml` | 四维权重、hard fail、pass 阈值 |
| book index | `<内容根>/runtime/course-content/<系列>/book/index.json` | concept ID、章节/图/公式/页码、前置、常见误解 |
| component registry | `RemotionStudio/src/components/registry.json` | 组件 props、golden frame、QC 清单、最大时长 |

`course-control preflight --lesson <slug>` 校验前两份；缺项即 fail。

## 3. 流水线（G0–G7）

| 门 | 产物 | 自动化检查 | 退出条件 |
| --- | --- | --- | --- |
| G0 规格 | episode spec + rubric | preflight：schema、source、时长、voice/rights、DrivAer 仅 render_only | 你签“精华/cut”一次 |
| G1 镜头表 | storyboard：每镜 claim、视觉语法、时长预算 | claim 引用、六段覆盖 | 不过回 G0 |
| G2 骨架 | 组件装配 + 截帧 | frame-audit：重叠/出框/溢出/对比/整页文字/模板转场/字幕安全区 | 不过回 G2 |
| G3 旁白/animatic | 实测旁白、切点 | audio-check：时长、静音、响度、字幕覆盖 | 不过回 G3 |
| G4 代表镜头 | 3–5 个 hero 帧/片段 | golden 对比 + 机制复述 | 你看一次 golden |
| G5 批量 | 按段渲染 | 每段 QC、同帧一致性 | 只重渲失败段 |
| G6 字幕 | 双语 SRT/ASS | 换行、时间轴、术语 | 不过回 G6 |
| G7 交付 | 成片 + package | media-qc、hash、manifest | 你终审/抽样 |

## 4. 自动化与人工

**自动化**：preflight、checks（typed auto/review）、构建与打包、report。

**检查格式**：`quality.rubric.yaml` 的 `checks` 是带类型的条目，不再用自由文本：
- `kind: auto` + `rule`：执行器直接判定；未实现的规则不许标 auto。
- `kind: review` + `prompt`：只进异常队列，由人处理。
- 输出：`build/<slug>/quality/exceptions.json`；`not_run` 不算 pass。
- 当前 `frames_present` / `subtitles_present` / `audio_present` 只检查“存在”；在 spec→timeline 编译落地前，可能读到旧产物。timeline 落地后，检查必须按 timeline 的 entry/asset 绑定，不接受“目录里有文件”即通过。
- `claim_source_coverage` 必须传 `--book-index <book/index.json>` 才算执行；未传或索引缺失记 `not_run`，不得默认通过。
- 命令：`course-control checks --lesson <slug> --stage <stage> [--book-index <path>]`。
- 同一工作区同时只允许一个全量回归。`check.ps1` 在内容根 `runtime/locks/check.<hash>.lock` 拿工作区锁（pid + 开始时间）；拿不到立即失败并打印持锁 pid 与开始时间，不排队、不静默等待；残留超过 30 分钟才允许强制接管。

**人工只保留三次治理点**
1. 专题精华/cut + rubric 阈值（每专题一次）。
2. golden sample（每套视觉语法一次，2–3 分钟）。
3. 专题终审（抽样或异常清单）。

其余走异常上报；不逐帧签字。

---

## 5. 视觉组件

先做 5 个参数化组件：CarFlow（车 + 流场 + 镜头）、MechanismDiagram（粒子/力矢量/公式）、ChartOverlay（书图 + 指针/标注，不重画曲线）、PhotoInsert（照片/文件 + 出处）、FormulaBlock（KaTeX）。3D 单段 ≤30 秒；按段渲染再拼。

DrivAer 几何只用于渲染/展示，不作为数据来源；课程数字仍以书/论文为准，画面标 `render_only`。

---

## 6. 回归与指标

- golden set：3–5 个章节（3D、机制、图表、照片、结论）；改 pipeline 必须跑。
- 指标：claim-source 覆盖率 100%、每门自动通过率、每集人工干预次数（≤1 异常 + 1 终审）、返工次数、每分钟渲染时长。
- 不以镜头数、动画数、文件数作为质量指标。
