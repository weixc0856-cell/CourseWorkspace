# 科学计算/绘图库接入评估（2026-11-08）

- **结论**：先接入 **SymPy + Matplotlib + SciencePlots**；**Manim 沿用**；**Plotly / Seaborn 暂缓**。
- **边界**：它们只产出静态科学资产或动画镜头；不接管 CourseControl 编排，不替代 FormulaSpec/KaTeX。

## 1. 分工

| 能力 | 工具 | 决策 | 理由 |
| --- | --- | --- | --- |
| 符号推导/公式验证 | SymPy | **接入** | 已有 Formula Pipeline 的 `math_problems`；LaTeX 输出；不能替代人工 |
| 科学绘图 | Matplotlib | **接入** | 曲线/等高线/矢量场/SVG/PDF/PNG；Agg 后端可离线 |
| 论文级样式 | SciencePlots | **接入（no-latex）** | `science` 样式需要完整 LaTeX；Windows 生产用 `["science","no-latex"]`，避免硬依赖 |
| 数学动画 | Manim | **沿用** | 公式变换/逐项推导；已有 3 分钟向量动画验证 |
| 交互图表 | Plotly | **暂缓** | 视频消费的是静态帧；交互价值在网页，不在成片 |
| 统计可视化 | Seaborn | **暂缓** | 需要统计课程数据时再加；Matplotlib 已能覆盖大部分 |

## 2. 为什么不是“全都装”

- Plotly 的强项是 hover/缩放；最终视频是固定帧，接入只会增加导出依赖（kaleido）和样式分叉。
- Seaborn 是 Matplotlib 的统计封装；没有统计数据集前不引入。
- SciencePlots 只是样式层；`science` 默认 `text.usetex=True`，没有 LaTeX 会失败，因此生产默认 `no-latex`，需要出版级 LaTeX 时再显式开启。

## 3. 资产契约

```text
ScientificFigures/figures/<name>.py
  → output/<name>.svg / .pdf / .png (>= 2K)
  → Remotion <Img> / FigureProbe
FormulaSpec (LaTeX) → KaTeX/Manim → Remotion
```

- 图脚本是唯一源；数据、参数、随机种子必须可复现。
- 输出 SVG/PDF/PNG；视频合成优先使用高分辨率 PNG 或 SVG 转 PNG。
- 不在 Figure 脚本里做视频编码；编码仍归 Remotion/FFmpeg。
- 中文字体单独配置，不能直接复用 SciencePlots 默认字体。

## 4. POC 结果

- `ScientificFigures/figures/continuity_figure.py`
  - SymPy 推导 1D 连续性方程，输出 `output/continuity_derivation.tex`。
  - Matplotlib + `science/no-latex` 绘制平面 Poiseuille 速度剖面。
  - 输出 `continuity_velocity.svg` / `.pdf` / `.png`（PNG 2239×1406，320 dpi）。
- 运行：`uv run --project ScientificFigures python ScientificFigures/figures/continuity_figure.py`
- 依赖：`matplotlib 3.10.x`、`scienceplots 2.2.2`、`sympy 1.14.0`、`numpy 2.5.x`，均在独立 `ScientificFigures/.venv`。

## 5. 接入 Remotion 的方式

- 静态图：`<Img src={staticFile('figures/continuity_velocity.png')} />`。
- 公式：`<Formula latex={...} />`（KaTeX）。
- 动画：Manim 镜头作为 overlay；不把 Matplotlib 动画当作最终合成器。

## 6. 硬门

1. 图表必须有数据来源/参数/生成脚本。
2. 不允许 AI 直接生成带数据的图当事实图。
3. 最终成片按 1080p/2K/4K 检查字号、线宽、图例、公式清晰度（必要时定位单帧）。
4. `science` 样式若开启 LaTeX，必须显式记录 LaTeX 依赖；默认 `no-latex`。
