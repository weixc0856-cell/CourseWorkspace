# 配色规范（Light Technical Editorial）

日期：2026-11-08
代码：`CourseControl/src/course_control/layout/schema.py`、`ManimSandbox/common/design_system.py`
预览：`build/01-transformer-demo/review/palette-system.mp4`

## 1. 结论

默认主题是**明亮的科技编辑风格**：暖白纸面、石墨正文、橙色品牌重点；蓝 / 青 / 紫只用来表达“输入 / 处理 / 输出”这类语义，不用来装饰。

整体比例：**70% 中性（纸面、留白、灰线）+ 20% 墨色（标题、结构）+ 10% 重点色**。一帧只允许一个橙色重点。

## 2. 检索依据

- 麦肯锡没有公开的品牌手册；流通的色值是第三方近似：Deep Blue `#051C2C`、Electric Blue `#2251FF`、白底、冷浅灰 `#F2F4F6`、边框 `#D9DEE3`、次要文字 `#5A6872`。来源：[McKinsey brand spec（approx）](https://github.com/hugohe3/ppt-master/blob/5e8856be0da8e6bc85c4aa28acc614478f7b7137/skills/ppt-master/templates/brands/mckinsey/templates/design_spec.md)。
- Claude / Anthropic：Clay `#D97757`、Page `#FAF9F5`、Card `#F0EEE6`、Hairline `#E8E6DC`、Ink `#141413`、Blue `#6A9BCC`、Green `#788C5D`。来源：[claudeplot colors](https://github.com/viniciusoike/claudeplot/blob/main/R/colors.R)、[Claude design tokens](https://github.com/beefiker/superloopy/blob/378169a2646b2f8b84dcff0c4fd9f0da9b7d8a32/skills/superloopy-frontend/references/design/claude.md)、[Anthropic palette](https://colorarchive.org/brands/anthropic/)。
- 本方案取两者的“报告感”：麦肯锡的克制结构 + Claude 的暖纸与陶土橙；不复制任何一家的品牌标识或版式。

## 3. Color Tokens

| Token | Hex | 用途 |
| --- | --- | --- |
| `paper` | `#FBFAF7` | 页面背景（暖白，不是纯白） |
| `surface` | `#F3F1EA` | 代码块、图表底、分区底 |
| `ink` | `#252A31` | 标题、结构线 |
| `body` | `#2E3338` | 正文 |
| `muted` | `#6B7280` | 注释、轴标签 |
| `border` | `#E3E0D7` | 分隔线、边框 |
| `orange` | `#E8733B` | 品牌重点、当前焦点、attention 权重 |
| `blue` | `#4A82B8` | 输入、query、数据流 |
| `teal` | `#42A69A` | 处理、key、target、通过 |
| `purple` | `#7A6FB0` | 输出、value、预测分布 |
| `red` | `#C75B55` | 误差、loss、错误 |
| `navy` | `#12324A` | 需要强权威感的标题或结论页（可选） |
| `flow` | `#A8C6DE` | 浅色数据流箭头 |

## 4. 语义色

| 语义 | Token | 例子 |
| --- | --- | --- |
| 核心结论 / 当前焦点 | orange | attention 权重、正在讲解的公式项、结论下划线 |
| 输入 / 查询 | blue | 源句、query 向量、输入箭头 |
| 处理 / 运算 | teal | key、层归一化、target、通过状态 |
| 输出 / 预测 | purple | value、预测分布、输出 token |
| 误差 / 风险 | red | loss、gap、回传、错误 |

Transformer 课程的具体映射：

- Query 蓝，Key 青，Value 紫；
- Attention 权重橙；
- 数据流浅蓝；
- 输出 token 紫；
- Loss / 回传红。

结构框、标题、正文保持墨色；不要给每个模块换一种颜色。

## 5. 对比度

在 `#FBFAF7` 纸面上的 WCAG 对比度：

| 颜色 | 对比度 | 可用位置 |
| --- | ---: | --- |
| Ink `#252A31` | 13.84 | 正文、标题 |
| Body `#2E3338` | 12.22 | 正文 |
| Muted `#6B7280` | 4.63 | 注释（AA 正文） |
| Purple `#7A6FB0` | 4.26 | 图形、≥24 px 粗体标签 |
| Red `#C75B55` | 3.98 | 图形、错误强调 |
| Blue `#4A82B8` | 3.89 | 图形、输入标签 |
| Orange `#E8733B` | 2.90 | 图形、重点，不用于小字 |
| Teal `#42A69A` | 2.81 | 图形、处理标签 |

规则：语义色承担图形与大字，正文只用 ink / body / muted；橙色上不要放小白字。

## 6. 禁止项

- 大面积纯黑、深灰背景作为默认主题；
- 荧光绿、荧光紫、赛博渐变；
- 无意义的发光、粒子、扫描线、网格底纹；
- 卡片套卡片；
- 一页超过两个语义色（橙色重点不算语义色）；
- 为了“科技感”牺牲文字对比度。

暗色主题只作为个别内容的显式例外，不进入默认规范。

## 7. 落地

- 全局 token：`DesignSystem`（`layout/schema.py`）与 `ManimSandbox/common/design_system.py` 保持同名同值。
- 导演层：`VisualStyle.color_semantics` 写入 query / key / value / result / mask / attention / loss / input / process / output。
- 场景：Residual、CrossAttention、Loss 已按新色重做；`palette_preview.py` 是 16:9 的色卡与语义示例。
- 预览：`build/01-transformer-demo/review/palette-system.mp4`（38.6 s，配色页 + 三个应用镜头）。

## 8. 边界

- 4 个早期 Manim 镜头仍是黑底旧色，需要在下一轮统一重做。
- 语义色目前由人工在场景中选择；导演层记录角色，但还没有逐图元的颜色校验。
- 图表色序、代码高亮只定义了语义，还没有组件级色板。
