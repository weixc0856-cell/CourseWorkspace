## 1. 一条教学链

每一集（或一个完整知识段）按下面的顺序组织，不跳步：

```text
问题 → 案例 → 机制 → 推导 → 证据 → 结论
```

- **问题**：观众能听懂的一个具体问题，最好带场景或对象。
- **案例**：一个真实对象、一组具体数字；先具体后抽象。
- **机制**：让观众看见“为什么”，不是只给结论。
- **推导**：公式、变量定义、适用条件；不能只把公式摆出来。
- **证据**：书图、数据、试验；出处可追溯。
- **结论**：回答开场问题，说明现实意义与边界。

不是每集都必须六页，但**只要出现机制或公式，就必须有机制页与推导页**；只给结论的页面不算讲明白。

## 2. 六种标准页面类型

六种是组件，不是六套僵化模板；同一类型在不同集可以有不同构图，但信息职责固定。

| 类型 | 回答什么 | 主视觉 | 不要放 |
| --- | --- | --- | --- |
| **01 开场问题** | 这一集要解决什么 | 一个真实对象/场景 + 一个问题 | 公式、曲线、多个结论 |
| **02 案例** | 现实里发生在谁身上 | 对象照片/实测数字/账单 | 抽象定义、历史综述 |
| **03 机制** | 为什么会这样 | 示意动画/剖面/因果图 | 未解释的公式 |
| **04 推导** | 公式从哪来、何时成立 | 对齐公式 + 变量定义 + 假设 | 只有结论的公式 |
| **05 证据** | 凭什么相信 | 书图/试验/数据，坐标可读 | 无出处截图、过度装饰 |
| **06 结论** | 对观众有什么用 | 2–3 条结论 + 现实联系 | 新概念、新公式 |

## 3. 固定网格（1920 × 1080）

所有页面共用同一组锚点；不同页面只改中部主视觉，不移动页眉、出处与页码。

| 元素 | 锚点 | 规格 |
| --- | --- | --- |
| 页眉（集号 / 页码 / 页面类型） | 左 110，上 70 | 20 px，橙色，全大写 |
| 页面标题 | 左 110，上 128 | Manrope 60–66 px，最多两行 |
| 核心结论 | 左 110，上 232 | 28 px，灰色；关键词加粗 |
| 主视觉 | 左 110，上 330，宽 1700，高 500 | 书图、照片、动画、公式 |
| 辅助解释 | 主视觉内或右侧 | 不进入底部出处区 |
| 出处 | 左 110，底 175，宽 1250 | 19 px，深灰；上方 1 px 分隔线 |
| 页码 | 右 110，底 175 | 19 px，字距 0.16 em |
| 字幕安全区 | 底 0–150 | 只放字幕，不放图、公式、出处 |

- 标题最多两行；两行时核心结论自动下移，不能重叠。
- 主视觉必须落在 330–830 之间；超出就换构图，不缩到坐标读不清。
- 书图优先铺满可用宽度；宁可裁页边，不缩坐标。

## 4. 出处（Source）规范

- **位置固定**：左下角，底 175，宽 1250；不随页面变化。
- **格式**：`Source · 作者/编者, 书名, 版次, 章/节, 图/表号, 页码。`
- **多来源**：分行排列，不把两个来源挤成一行。
- **原创解释**：标 `Schematic · no external source`，不为凑格式虚构出处。
- **延伸阅读**：如需要，单独一行 `Further reading · ...`，不与 Source 混排。
- **可追溯**：观众能按出处找到具体论据；出处不是装饰。

示例：

```text
Source · Schuetz (ed.), Aerodynamics of Road Vehicles, 5th ed., Ch. 1, Fig. 1.67, p. 61. Photos: Daimler AG.
Source · Table 3.1, p. 159; model calculation with ρ = 1.184 kg/m³ at 120 km/h.
Schematic · no external source. Model follows Ch. 3 §3.2.2.
```

## 5. 公式规范

- 用 KaTeX / LaTeX 排版，不用纯文本拼公式。
- 变量斜体，单位正体；下标为标签时正体（如 c_D 的 D）。
- 独立公式成行、等号对齐；不把公式塞进句子中间。
- 推导页必须给：变量定义、每一步变形、适用条件。
- 只有结论的公式页不合格；至少配一页机制或推导。

## 6. 视觉方向

采用三者组合，不混成四种风格：

- **学术课程的信息组织**：问题、定义、推导、证据、结论。
- **咨询报告的版式**：结论先行、层级明确、主视觉服务观点。
- **纪录片的视觉表达**：真实对象优先，画面解释机制，文字只做引导。

禁止：

- 网页卡片堆叠式“设计稿”版式。
- 所有页面套同一模板；六种类型只是组件。
- 从抽象概念/公式/曲线开场。
- 字幕压住坐标轴、图例或公式。
- 出处漂移、页码缺失、来源与图不对应。
