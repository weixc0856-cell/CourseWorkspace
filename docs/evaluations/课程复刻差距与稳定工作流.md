# 课程复刻差距与稳定工作流（2026-11-08）

- **对照对象**：
  - 3Blue1Brown，《Transformers, the tech behind LLMs | Deep Learning Chapter 5》（`wjZofJX0v4M`）
  - Reducible，《The Fast Fourier Transform (FFT): Most Ingenious Algorithm Ever?》（`h7apO7q16V0`）
  - Primer，《Simulating the Evolution of Rock, Paper, Scissors》（`tCoEYFbDVoI`）
- **结论**：当前流水线已经能稳定产出“带旁白、双语字幕、少量动画插入的课程视频”，但距离三者的**动画优先、镜头级叙事、声音设计、风格统一**还有明显差距。差距不在渲染器，而在**镜头设计、剧本节奏、声音与合成层**。

### 3.1 最关键的 G1

三者的画面是**为镜头写的**：一个镜头里只保留当前论证需要的元素，镜头之间有转场语法。当前 `compose.mode=deck` 是“幻灯片为底、动画覆盖”，观众始终能看到项目符号和页面框架，风格上更像录屏课，而不是 3B1B。

要复刻，需要新增 **`compose.mode=scene`**：

```text
NarrationSpec (page/segment timings)
        ↓
ShotSpec per segment (full-frame scene, no slide background)
        ↓
TimelineSpec: scene clips + overlays + captions + music
        ↓
Remotion compose
```

幻灯片只保留 section card / 数据页 / 结尾引用，不再作为每页底图。

### 3.2 G3/G4 声音

- 需要一条**音乐床**（低音量、无版权/可商用）与**转场音效**；当前完全没有。
- 需要**逐句对齐**：现在按页内字符比例分配字幕；3B1B 级需要 ASR/forced alignment 或 TTS 返回词级时间戳。VoxCPM2 是否返回时间戳需验证；否则用 Whisper/`faster-whisper` 做 forced alignment（CPU 可跑，但增加依赖）。
- 需要**响度归一**（LUFS）与**人声/音乐 ducking**；`burn.py` 只做视频，不做混音。

### 3.3 G2 风格包

最少需要：
- 固定色板（背景、主色、强调色、警告色）。
- 固定字体（英文无衬线 + 中文黑体）与字号阶梯。
- 线宽/圆角/阴影/网格规则。
- 转场语法（淡入、追踪、缩放、擦除）与镜头长度。
- Manim/Remotion 共用的 theme 文件，避免每期重写。

### 3.4 G9 视觉 QC

当前 QC 能发现黑帧/定格，但发现不了：
- 文字重叠、越界、字号过小；
- 字幕遮挡主体；
- 动画与口播语义不一致；
- 音乐盖过人声。

建议：完整看片并按时间戳记录问题；音量/响度表可自动化，构图与节奏不靠抽帧评审。HyperFrames 的 `text_below_floor`/对比度 lint 可作为参考。

## 3.5 真实差距（量化）

| 指标 | 旧 deck 版 | 新 scene 版 | 3B1B / Reducible |
| --- | --- | --- | --- |
| 全屏镜头覆盖 | 0%（每页是幻灯片） | 100%（12 页 ScenePage base） | 100% |
| 运动画面时长 | 4 个 Manim 镜头，42.6 s / 1319.8 s = **3.2%** | 100% 全屏运动 + 42.6 s Manim overlay | 几乎 100% |
| 信息单位 | 每页 5–7 条项目符号 | 248 个逐句 beat，约 5 s/beat | 每 3–8 s 一个视觉动作 |
| 画面主体 | 文字列表 | 大字陈述 + 公式 + 流线背景 | 连续图解/变换 |
| 声音 | 人声 | 人声（新英文录音待重跑） | 人声 + 音乐 + 音效 |
| 对齐 | 页级 | beat 估算（按词数分配） | 句级/词级 |

结论：scene 模式解决“PPT 展示”，但没有解决“连续图解”。下一阶段必须把 ScenePage 的纯文字 beat 替换为**每拍对应的图解组件**（矢量图、公式变换、流场/3D），否则仍只是“会动的字幕卡”。

## 4. 稳定工作流（目标态）

```text
0. Research      URL/PDF/书 → sources.yaml → digest（稳定引用）
1. Brief         受众/目标/边界/时长 → 人工确认
2. Outline       章节/页码/每秒预算/视觉类型 → 人工确认
3. Script        英文口播（140–150 wpm）+ 情绪/停顿 + 引用
4. Storyboard    每个 segment 一个镜头；engine 由内容决定
5. Style kit     色板/字体/线宽/转场/音乐主题
6. Assets        Manim/Blender/CodeVideo/图表；单镜头可重建
7. Voice         VoxCPM2 逐段缓存 → 响度归一 → 人工试听
8. Subtitles     英上中下；1–6s/条；CPS/行宽校验
9. Compose       scene/deck 两种模式；音乐/音效/ducking
10. QC           Contact Sheet + 响度 + 时长 + 字幕 + must-have
11. Delivery     clean + captioned + SRT/ASS/VTT + report + references
```

硬门：
- 剧本未批准不跑整课 TTS。
- 每个镜头有 SPEC/来源/时长；缺证据写 `blocked`，不写 pass。
- 声音/画面/字幕任一失败，最终 verdict 不得 pass。
