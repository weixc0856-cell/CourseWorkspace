# 复盘：T1-01 视觉生产（2026-11-15）

- **状态**：生效。本文记录 T1-01 v1 被拒收的根因、整改规则与验证门槛；与 `课程页面系统.md` 并用。
- **范围**：课程/主题视频的画面生产，不涉及内容事实口径与交付打包规范。
- **结论**：失败不是“工具不会动画”，而是**把流程通过当成了画面成立**。后续视觉任务先做 20–30 秒动态验证，帧不过不铺全片。

---

## 1. 发生了什么

1. T1-01 v1 用 15 页静态纸白 deck + 两个 Manim 切入 + 12 分钟旁白交付。构建、校验、打包全过，owner 看片后拒收：版式模板化、字幕压坐标轴、机制没讲透、旁白平。
2. 之后连续几轮在同一个介质里改：换版式、换字幕、试 V1–V6 配音、做六页 HTML deck。每轮都“更像样”，但没有换方法。
3. owner 指出根因：工具只能做 PPT 是误判；真正的问题是动画没被当主路径。
4. 最后用 30 秒纯动画样片（Remotion + R3F + three）验证：连续镜头、无文字页、流线/尾流/功率数字。画面仍有限（风格化车模、无真实涡量），但证明方向可行。

---

## 2. 根因

| # | 根因 | 表现 |
| --- | --- | --- |
| R1 | 目标错位：优化“能过流程”，不是“画面成立” | 静态页最容易过校验，于是反复做静态页；构建绿 = 交付 |
| R2 | 介质默认错：没有先确认“片子还是课件” | 把 PPT 当目标，而不是 fallback；在 deck 里反复打磨 |
| R3 | 参考与迭代错：靠印象改版式，不逐帧看参考 | 没先写镜头表、没先做 30 秒验证；改字号/颜色/卡片 |
| R4 | 反馈回路错：用“再做一版”代替换方法 | 同一介质出多个变体；TTS 在同一个模型上盲试 V1–V6 |
| R5 | 质量判定错：把 `build`/`verify` pass 当质量 | 没有以“任选一帧是否成立、镜头是否解释机制”做门 |

---

## 3. 整改规则

1. **先验证介质，再铺量。** 视觉任务先出 20–30 秒动态样片；样片不过，不做整集、不建大库、不写更多规范。
2. **片子与课件分开。** 课件是独立交付物；没有被明确要求时，不把 deck 当视频交。PPT 只作为 fallback，不作为默认。
3. **先镜头表，再渲染。** 每个镜头写清：观众要懂什么、什么在动、为什么动、进出方式、静帧是否成立、引擎与资产。
4. **逐帧验收。** 质量门是看帧/看片：构图、空间连续、运动是否解释机制、是否出现文字页/模板转场/死帧；构建通过只是必要条件。
5. **拒绝后换方法，不换皮。** 同一问题连续两次被拒，停止同介质变体；换介质、换镜头设计或停下来问清根因。
6. **参考必须落到帧。** 参考研究输出时间戳、关键帧、构图/镜头/材料分析；没有取到的画面不写分析。
7. **配音不靠猜。** 不做整轨 atempo；不用 style 词拼正文；先做 2–3 条短试音，仍不过就说明本地模型到顶，给出录音/云端克隆/换模型三条路。
8. **临时文件归位。** 临时产物只写 `<内容根>/build/<slug>/` 与各工程运行时目录；最终只写 `<内容根>/deliver/<slug>/`。仓库内不放渲染产物、参考视频、模型权重。
9. **熔断。** 同一构建/渲染/推送问题最多 3 次；第三次仍失败，记录证据并停，不用重跑代替定位。

---

## 4. 视觉样片验收门槛（30 秒）

- 一个连续空间或明确的空间转换，不靠页面切换/淡入淡出/模板转场。
- 镜头有任务：建立、推进、揭示、收束；不是无意义环绕。
- 动画解释机制：流线、压力、分离、装配、数据变化至少有一项真正被看懂。
- 任选一帧暂停成立：主体、层次、光源、标注不散。
- 文字只做标注；没有整页文字/逐条弹字。
- 真实/示意可区分；没有把示意图说成 CFD/实测。
- 有明确的“不过就停”条件，不自动扩成整集。
