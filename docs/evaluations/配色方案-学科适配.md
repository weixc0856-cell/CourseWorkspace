日期：2026-11-09
代码：`ManimSandbox/common/palettes.py`、参考图 `build/palette-preview/media/images/palette_preview/PalettePreview_ManimCE_v0.22.0.png`
上游：中国古画 7 组四色方案（用户提供）；对比度与学科建议来自 WCAG 2.1 与数据可视化/教育设计的公开实践。

## 1. 结论

- 7 组古画配色**不直接当主题用**，而是作为"色族"：程序从每组里推导出可访问的 `paper / ink / focus / support / muted / divider / surface` 角色。
- 学科只决定**色族与角色映射**，不改变版式与字号；同一门课必须始终用同一组。
- 所有配色都通过统一门禁：正文 ≥7:1、图形 ≥3:1、次要文字 ≥4.5:1（对纸面）。当前 8 组全部通过。

## 3. 学科 → 色族

| 内容类型 | 推荐 | 角色建议 | 理由 |
| --- | --- | --- | --- |
| AI / 机器学习 | qinglv | focus=石青（注意力/查询）、support=石绿（键）、ink=墨青 | 冷色矿物感贴合"技术解释"，蓝-青不依赖红绿 |
| 数学 / 理论 | editorial 或 yebo | focus=一个强调色，其余墨色 | 公式与几何需要最高对比、最少色相 |
| 系统 / 代码 / 工程 | yebo 或 editorial | focus=深蓝，support=浅灰蓝变体 | 深蓝+月白接近编辑器习惯，长时间看不累 |
| 经济 / 金融 | qiushan 或 editorial | 涨跌用**蓝-橙发散**；focus=赭石 | 红绿是色盲高风险对；赭石/枫褐提供编辑感 |
| 自然科学 / CFD | qinglv | 单色相顺序色阶（石青→墨青） | 顺序数据用单色相；避免彩虹色图 |
| 人文 / 历史 / 文学 | yanlan 或 qiushan | focus=远山褐/赭石，support=墨茶 | 暖褐低饱和，符合纸张与档案气质 |
| 心理 / 健康 / 生活方式 | taohua | focus=胭脂粉变深，support=春水青变深 | 低饱和、柔和，避免强刺激 |
| 新闻 / 纪录片 | yanlan 或 yebo | 中性底 + 单一强调 | 信息优先；图形与文字保持中性 |
| 入门 / 少儿 | hetang 或 taohua | focus=荷叶碧，support=水纹青 | 明快但不刺眼，绿色/青色友好 |
| 艺术 / 设计 | qiushan + taohua | 两页一组，focus 各一色 | 暖冷对照，适合作品与风格对比 |

选择顺序：**先定内容类型 → 再定唯一 focus → 最后检查对比度**。不要在同一门课里混用两个色族。

## 4. 硬规则

1. 纸面 70%、墨色 20%、重点 10%；一页最多两个语义色。
2. 正文 ≥7:1、图形 ≥3:1、次要文字 ≥4.5:1（对纸面）；`beats-validate` 会拦。
3. 不靠颜色单独传意：加形状、线型、标签或图案（WCAG 1.4.1）。
4. 避免红-绿对立；需要发散时用蓝-橙或紫-绿（色盲安全）。
5. 顺序数据用单色相；不要用彩虹/ROYGBIV 色图（会扭曲数值且失败于色觉缺陷）。
6. 全片白平衡与配色一致；不在镜头之间换纸面。
7. 灰度打印/截图仍能读出层次：先把成片转灰度看一遍。

## 5. 落地

- 代码：`ManimSandbox/common/palettes.py`，`palettes.palette("qinglv")` 返回角色；`palettes.report(key)` 返回对比度。
- 节拍表：`palette: qinglv`（`beats-validate` 校验存在性与对比度）。
- 参考图：`00-palette-system/palette_preview.py`，一条命令出 8 组色卡与对比度。
- 测试：`ManimSandbox/tests/test_palettes.py` 固定住四色、对比度与角色唯一性。
