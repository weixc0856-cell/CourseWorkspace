## 2. 项目现状（事实）

- 动画：`ManimSandbox` 固定 Manim CE 0.22 + LaTeX，CPU 渲染；`CourseControl` 以 `render:manim` 接入。
- 合成：Remotion + FFmpeg 已有；Code2Video、MotionStudio、BlenderStudio 是并列能力，不新增引擎。
- 口播：`<AI_ROOT>\VoxCPM-Runtime` 的 FastAPI（50000），CPU，RTF 约 16；音色参考已验证。
- 接口差异：本机服务同时支持
  - `prompt_wav` + `prompt_text` → Hi-Fi Cloning（音色更像，但风格指令会被忽略）；
  - 仅 `reference_wav` → Controllable Voice Cloning（可用括号风格指令控制语气）。
- 现状：本片 11 段旁白走的是 Hi-Fi 路径，所以没有风格指令；下一轮才切到可控克隆并试听。

## 3. 逐项评估

### 3.1 动画引擎：CE 与 ManimGL 的关系

ManimGL 是 3B1B 自用的 OpenGL 分支，Manim CE 是社区分支。两者 API、依赖和安装包（`manimgl` vs `manim`）都不同，不能混用。

判断：**先 POC，不动生产链**。本片的问题主要是对象连续性和镜头设计，换引擎不会自动解决。POC 见 §5.1。

### 3.2 对象连续性：复用 Manim，而不是自研

`Transform`、`AnimationGroup`、`ValueTracker`、`always_redraw`、`MovingCameraScene` 已经能覆盖本片需要的“同一对象跨镜头变形”。真正值得沉淀的是教学组件，而不是通用框架：

- `ProjectionGuide`：向量投影、虚线、阴影带、实时点积读数；
- `AttentionMatrix`：行列标签、单元格强度、因果遮罩；
- `TokenFlow`：句子 token 的持续存在与变形；
- `VectorFan` / `WeightedSum`：value 向量扇与首尾相接；
- `CameraPreset`：推近、平移、安全区约束。

这些放 `ManimSandbox/common/`，按需抽取，不预先建大而全的库。

### 3.3 口播：保留 VoxCPM2，先验证表达控制

不换模型。下一轮只改两件事：

1. 请求改走 `reference_wav`（可控克隆），不要同时给 `prompt_wav` + `prompt_text`，否则进入 Hi-Fi 模式、风格指令失效。
2. 每段文本前加一句短指令，按段落统一，不逐句换风格。例如：
   `(Speak in a natural, calm and clear explanatory style. Conversational pace, restrained emphasis.)`

验收：同一参考音色下生成 A（现状）/ B（平稳讲解）/ C（重点强调）/ D（设问）/ E（结论）五组，盲听比较；音色不退化、情绪听得出、不播音腔。没有试听结论前不改生产默认值。

`pace`、`emphasis` 等字段是上层语义，不虚构 VoxCPM2 不存在的原生参数。

### 3.4 词级对齐：WhisperX，而不是 Manim Voiceover

本片已有 `timing.json`（镜头级）。下一层需要词级时间戳时，用 WhisperX 对**已生成的音频**做强制对齐，输出 `word_timestamps.json`，再由时间轴消费。这样 TTS 引擎与对齐解耦，也不绑死某个语音服务。

Manim Voiceover 把配音和动画绑在一个工作流里，与现有 VoxCPM2 资产重复，暂不引入。

### 3.5 后期与 BGM

- 光晕、模糊、运动模糊用 FFmpeg/Remotion 做，先保证文字锐度；本片没有加。
- BGM 不是渲染完随手铺一条。没有明确商用授权前不加；即使有，也不是每一秒都需要音乐。
- 曲库优先级：YouTube Audio Library → Incompetech → Audionautix；FMA/Musopen 逐曲核对；保留授权页与下载日期。
- 3B1B 的音乐不等于“钢琴小调模板”，不按音色模仿；按教学功能分四类（思考/探索/叙事/结构）+ 静默策略。

### 3.6 响度与 EQ

- Integrated LUFS、dBFS、dBTP 是三个概念，不互相换算。
- 本机成片目标定为 **-16 LUFS、True Peak ≤ -1 dBTP**，作为可配置的交付目标，不宣称平台强制。
- 不做固定 EQ 和固定侧链参数；需要时先听，再决定。

## 4. 本片实际执行（Attention 样片）

- 画面：Manim CE，11 个镜头，1920×1080/60fps，对象以变换为主；第 2→3 镜头由同一支向量复制分发。
- 旁白：VoxCPM2 Hi-Fi 克隆（现状路径），11 段，镜头边界与音频共用 `timing.json`。
- 旁白时长 123.4 s（2 分 03 秒）。
- 混流：FFmpeg，按时间轴铺旁白 + `loudnorm`（-16 LUFS / -1 dBTP），无 BGM。
- 验收：完整看片；不设抽帧关卡。

## 6. 暂缓项与理由

- 自研 SceneGraph / 相机系统 / 音频框架：Manim 与 FFmpeg 已覆盖，重复建设不改善成片。
- 自动呼吸声、全轨白噪声、随机语速扰动：容易产生不自然感。
- 固定 EQ 参数、固定侧链深度：依赖素材与录音，不作为生产默认。
- 直接使用 3B1B 的音乐：授权不允许，购买专辑不等于同步授权。
