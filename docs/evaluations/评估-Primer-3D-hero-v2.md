# 评估：Primer 式 3D hero world v2（30 秒）

日期：2026-11-09
参考：Primer《Simulating the Evolution of Aging》<https://www.youtube.com/watch?v=1_JbJTeLZJs>
产物：`CodeVideoStudio/shots/primer-hero/out/hero-1080.mp4`（1920×1080 / 30 fps / 30 s / 900 帧）
源码：`CodeVideoStudio/shots/primer-hero/`（Three.js r160 + 离线逐帧捕获）
基线：`primer-rps` POC（720p、平面背景、无阴影/后处理）

## 1. 目标：参考片的“效果”拆解

Primer 的模拟片不是写实 3D，而是**低多边形、暗色电影感、信息优先**的模拟世界：

1. 暗色背景 + 渐变天穹 + 雾；世界像一块悬浮的样本，而不是摄影棚。
2. 低多边形生物（身体 + 眼睛）+ 接触阴影；生物朝向镜头、轻微呼吸/浮动。
3. 有动机的相机：先全景建立，再推近细节，最后缓慢收束；没有无意义抖动。
4. 后期质感：色调映射、柔和阴影、暗角、尘埃/颗粒；不是纯平光。
5. 叠加层（图表、标注、旁白）由合成层负责，世界只提供干净的底。

## 2. v2 相对基线的变化

| 维度 | `primer-rps` POC | `primer-hero` v2 |
| --- | --- | --- |
| 分辨率/帧率 | 720p30 | 1080p30 |
| 色调 | NoToneMapping | ACES Filmic + 1.12 曝光 |
| 背景 | 纯色 + 线性雾 | 渐变天穹 + 指数雾 |
| 地面 | 无 | 暗色圆盘地面 + 接触阴影 |
| 阴影 | 贴片假阴影 | PCFSoft 2048 阴影贴图 + 接触阴影 |
| 灯光 | 半球 + 主光 + 补光 | 半球 + 暖主光 + 冷轮廓光 |
| 生物 | 缩放/浮动 | 呼吸 + 朝向镜头 + 投影 |
| 相机 | 固定半径慢绕 | 全景 → 推近 → 收束（smoothstep 分段） |
| 后期 | 无 | 相机暗角 + 尘埃粒子 |
| 确定性 | 同 seed 一致 | 种子化 PRNG；两次捕获 sha256 一致 |

## 3. 实测

| 项 | 结果 |
| --- | --- |
| 捕获（1080p30） | 900 帧，约 140–155 ms/帧，总时长约 2.3 分钟（SwiftShader） |
| 捕获（960×540 测试） | 90 帧，约 55 ms/帧 |
| 输出 | H.264 / yuv420p / 1920×1080 / 30 fps / 30.000 s / 900 帧 |

| 依赖 | 浏览器 Playwright + 本地 `three.module.js`；无网络请求 |

## 4. 与参考片的差距

1. **生物**：目前是“球 + 眼睛”，参考片有更完整的身体、肢体与动作；需要低模资产或程序化 rig。
2. **地形**：目前是六边形样本台；参考片有地形、植被、水面等生物群系。
3. **后处理**：没有景深、泛光、色调分级；这些是“电影感”的重要来源。
4. **动作多样性**：只有呼吸与朝向；参考片有移动、觅食、繁殖等行为。
5. **模拟内容**：本片是世界 plate，不是 aging 模拟；衰老/选择压力需要新的 `SimulationSpec` 与规则。
6. **叠加与音频**：图表、标注、旁白、音乐都在 Remotion/音频层，尚未接入。

## 5. 路线

1. **长序列继续用 Three.js**（实时捕获，约 0.14 s/帧@1080p），Blender 只做 hero 特写与材质/灯光。
2. **下一步三项**：低模生物资产（身体/肢体）、地形与生物群系、后处理（DOF/Bloom/色调分级）。
3. **aging 模拟**：新 `SimulationSpec`（基因、年龄、选择压力、繁殖），复用 `simulation-run` 数据链路。
4. **叠加层**：Remotion 负责图表/标注/字幕，世界保持干净。
5. **验收**：沿用 `beats.yaml`、字幕安全区、`media-qc` 与 `animation-score`；三维镜头额外检查渲染时间与确定性。

## 6. 边界

- 这是**世界质感 POC**，不是完整课程；不含旁白、字幕、图表与音乐。
- 不是写实 3D；目标是 Primer 的低多边形电影感。
- 生物行为与 aging 规则需要领域内容与人工审核，不能由渲染层替代。
