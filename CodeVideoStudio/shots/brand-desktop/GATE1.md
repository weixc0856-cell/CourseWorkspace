## 1. 这一版是什么

- 1920×1080 / 30 fps / 360 帧 / 12.0 s / 无音轨。
- 纯色块：无纸纹、无阴影、无景深、无泛光、无暗角、无胶片颗粒、无音乐。
- 一条连续长镜头，四个阶段（settle-in / work / result / brand），无切点、无淡入淡出。
- A/B 两版共用同一场景与时间轴，只替换指针与收尾方式。
- 渲染：SwiftShader，65–77 ms/帧，每版约 25 s。

## 2. 工程核验

| 项 | 结果 | 证据 |
| --- | --- | --- |
| 格式 | pass | `ffprobe`：1920×1080 / 30/1 / yuv420p / 360 帧 / 12.000000 s / 无音轨 |
| 每帧是 `t` 的纯函数 | pass | 无 `Math.random`、无 wall-clock；同路径两次捕获 sha256 一致 |
| 确定性 | pass | `gate1-a.mp4` 与 `det-a2.mp4` 均为 `5CDB973CBBB65803C2F535786B7C8FBBC1F3F33B1B47A51F41154CA25773140E` |
| 事件落点 | pass（±2） | 帧差峰值：卡片 f30、备注 f46、点击 f104、变形 f120、回车 f210、曲线完成 f240、拉远 f271、W 起笔 f301、W 完成 f330、电流 f343 |
| 屏幕文字 | pass | 全英文；终端行约 32 px，标签 44–48 px，WAYNE 72 px；均在 96 px 安全边距内 |
| W 路径 | pass | `W_PATH` / `CURRENT_PATH` 逐字取自 `RemotionStudio/src/brand/BrandMark.tsx`；按 0.60 m / 192 units 映射 |
| 橙色单一焦点 | 基本通过 | 按 §2.3 排班；唯一重叠在 f210–f224：回车涟漪与曲线末端点同为橙色（同一"结果"焦点族），记录在案 |
| 后处理/材质 | pass | 未启用任何 addons；仅 `MeshStandardMaterial` 纯色 |

三条偏差需要知道：

- 打字首字符的帧差峰值在 **f148**（预期 f150），是进入打字位前的指针位移；属于 ±2 内。
- 电流亮起的峰值在 **f343**（预期 f345），来自相机微动与最后一笔收尾的重叠；±2 内。
- 起始 0–0.5 s 完全静止，第一个帧差峰值在 f16；"第一秒抓住人"这件事只能靠后续的指针入场，目前很弱。

## 3. 迭代记录（每一轮都是粗剪暴露出来的）

| 轮次 | 现象 | 原因 | 处理 |
| --- | --- | --- | --- |
| 1 | 整帧发白，卡片像米粒，桌面露出六边形边缘 | 半球光过曝；相机太远；桌板 2.4×1.5 太窄 | 降低半球光、加 ACES、相机拉近 35%、桌面 8×6、网格扩到画外 |
| 2 | 收尾 W 被转了 90° 并出画 | 相机接近正俯视时 `up=(0,1,0)` 与视线平行，画面滚转 | 收尾改为与桌面法线 30°，设计稿同步修正（§6 注） |
| 3 | W 像四根圆棒浮在纸上 | 用 `CylinderGeometry` 画笔画，直径 40 mm | 改为 2.5 mm 厚的扁平带（`BoxGeometry`），躺在纸面 |
| 4 | W 只剩四段短线 | 扁带的显现用 `scale.y`（厚度轴），不是长度轴 | 改 `scale.z`；同时修正末端点应跟随已画出的曲线头，而不是固定终点 |
| 5 | 角色背对镜头、站在图表上挡住曲线 | 朝向 target 导致背对；驻留点在面板内部 | 朝向改为"朝相机 + 55% 偏转看目标"；驻留点移到面板外侧；整体缩小 23% |

## 4. 结论与未解决的问题

**成立的部分**

1. 一条连续长镜头走得通：从空桌到品牌，没有一次切点，观感是"一件事"。
2. 阶跃响应作为"结果"可读：坐标轴、过冲、回落、末端点，缩到 320 px 宽仍能看出是计算结果。
3. 收尾的空间关系成立：W 躺在纸面上、与桌面共用透视，30° 视角下不像贴上去的 UI。
4. 因果链清楚：发现 → 点击 → 变形 → 执行 → 结果 → 品牌，五步没有跳。

**A/B 的差别（需要人眼判断）**

- A（PIP）：全尺寸下能读出眼睛、天线、单臂；**缩到 1/8 就是一个方块加一根棍**。它现在更像"设备"而不是"角色"，这一点既可能是缺点（不够可爱），也可能是优点（不幼稚）。
- B（点）：克制、像光标，全程不抢戏；收尾时点收进 W 第一笔的动作在 12 秒里几乎看不见，需要慢放才成立。
- 两版的构图、节奏、收尾完全一致，所以盲看时可以用同一套问题问："这是工具还是玩具？"

**未解决**
