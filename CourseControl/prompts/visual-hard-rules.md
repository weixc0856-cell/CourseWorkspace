# 视觉与动画硬规则（会话启动/压缩后自动注入；细则见各来源文档）

总纲：遵守 CLAUDE.md 红线 A3–A6 / B7–B12（原图零篡改、全英文、display/tts 分离、视觉事件、单闸门等）。

## 页面结构（EVDS规范 / 版式系统 / 课程页面系统）
- 按知识属性选六原型：slide--hero / editorial / annotated / comparison / process / data；禁一套左文右图跑全场。
- 三层阶梯：Headline 必须是观点/问题/矛盾（非目录章节名）→ Visual 承担证明 → 文字只解因果，不照搬口播。
- 教学链：问题→案例→机制→推导→证据→结论；有机制/公式必有机制页与推导页；不从抽象概念/公式开场。
- 固定网格 1920×1080：页眉左110上70；标题左110上128（≤2行）；主视觉 y330–830 宽1700；出处左110底175；页码右110底175；锚点不随页移动。
- 安全边距≥96px；每页一个主张；bullet≤5；主视觉不低于模板面积下限；书图宁裁页边不缩坐标。

## 书图与引用（课程页面系统§4 / EVDS规范）
- 书图铺满可用宽度，置暖白纸面板 #EDE7DA + 细边框 + 投影；原图像素零篡改。
- 出处固定左下：`Source · 作者, 书名, 版次, 章/节, 图/表号, 页码.`；多来源分行；原创标 `Schematic · no external source`，不虚构。
- 每张书图页必含非空 .slide-footer .source 引用行；来源与图对应，不漂移、不缺页码。
- 对比页物理同构：锁定视角/比例/云图标尺；下方两行定量指标收敛。
- 数据页轴标签与单位完整；无来源数据不上屏；禁 3D 装饰图表。

## 配色与字号（配色规范 / 版式系统§9）
- 默认 editorial_science 暖白 #FBFAF7；70%中性+20%墨+10%重点；一帧一个橙 #E8733B 焦点；一页语义色≤2。
- 正文只用 ink/body/muted；橙上不放小白字；禁荧光/渐变/发光/粒子/卡片套卡片。
- 字号：页标题 56–72 / 正文 30–36（≥24）/ 标签 24–28 / 来源 18–22；公式 KaTeX，变量斜体单位正体，推导页给变量定义+变形+适用条件。
- 深色 deep_space 须镜头显式声明且有内容理由；切换在镜头边界；不对成片叠统一滤镜。

## 动画（动画视觉导演规范）
- 先写 AnimationDirection 过 direction-validate 再写代码；一镜一个视觉中心；公式放负空间。
- 原语 draw/trace/transform/camera/hold/highlight；禁淡入冒充变换、禁每元素发光/每镜缩放/装饰粒子；一镜≤1 主运镜。
- 视觉事件必须服务某句话（淡入/展示图片不算）；机制图必须 base_image 或枚举理由；动机制，不给静图贴标签。
- 标签不压箭头；公式不压轴线；字幕不压坐标/图例/公式/证据；字幕安全区底 150px。
- 静帧运镜 scale 1.04–1.15、pan≤1.2%；硬切；标题/出处/页码只在页面层画一次，引擎内不重画。

## 验收
- 两道门：设计门（direction 校验）+ 视觉门（完整看成片、按时间点定位单帧；渲染成功≠pass）。
- 稳定页必须有证据大图+注记+来源，不是稀疏模板页；缺证据写 blocked/not_run，不写 pass。
